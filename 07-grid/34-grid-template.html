CSS Урок 34. Колонки и строки

1. Два главных свойства

Свойство Что задаёт
grid-template-columns Колонки — сколько и какой ширины
grid-template-rows Строки — сколько и какой высоты 
.container {
    display: grid;
    grid-template-columns: 200px 1fr 200px;
    grid-template-rows: 100px 1fr 100px;
}

3. fr — доли

fr (fraction) — «доля свободного места». Главная единица Grid. 

grid-template-columns: 1fr 1fr 1fr;   /* 3 равные колонки */
grid-template-columns: 1fr 2fr 1fr;   /* средняя в 2 раза шире */
grid-template-columns: 200px 1fr;     /* фикс + растягивающаяся */
grid-template-columns: 2fr 1fr;       /* 2/3 + 1/3 */

fr — это доля от свободного места (после вычета фиксированных размеров и gap). 1fr 2fr 1fr = 25% + 50% + 25% от свободного места.

4. repeat() — повторение

Сокращает запись повторяющихся значений:

grid-template-columns: repeat(3, 1fr);        /* 1fr 1fr 1fr */
grid-template-columns: repeat(2, 100px 1fr);  /* 100px 1fr 100px 1fr */
grid-template-columns: 200px repeat(3, 1fr);   /* 200px + 3 колонки */

5. minmax() — минимальный и максимальный размер

minmax(min, max) — задаёт диапазон размера колонки: от min до max. 

grid-template-columns: minmax(100px, 1fr) minmax(100px, 1fr);
minmax(100px, 1fr) — не меньше 100px, но растягивается:

2
3

Где minmax полезен

  • Адаптивные карточки: не меньше 200px, но растягиваются.
  • Сайдбар: minmax(200px, 300px) — от 200 до 300px.
  • Контент: minmax(0, 1fr) — чтобы текст не «ломал» сетку.

6. auto-fit и auto-fill — адаптивные сетки

Магия адаптива. Позволяет сетке самой решать, сколько колонок поместится. 

grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

«Создай столько колонок, сколько поместится, но каждая — не меньше 200px, и растягивай их равномерно».

auto-fit vs auto-fill

auto-fit auto-fill

Когда использовать Карточки, галереи Когда важно сохранить сетку
На практике чаще используют auto-fit — он «схлопывает» пустые колонки, и элементы растягиваются.

7. grid-template-rows — строки

Аналогично колонкам — но для строк:

grid-template-rows: 100px 200px 100px;   /* 3 строки */
grid-template-rows: auto 1fr auto;        /* шапка / контент / подвал */
grid-template-rows: 60px 120px 60px:
60px
120px

Автоматические строки

Если строк больше, чем задано в grid-template-rows — остальные создаются автоматически (высота по содержимому). 

.container {
    grid-template-rows: 100px;   /* только первая строка 100px */
    /* остальные — автоматические */
}

Для настройки автоматических строк — grid-auto-rows (урок 37).

10. Частые ошибки

Ошибка Почему плохо
repeat(3, 1fr) vs 1fr 1fr 1fr — одно и то же Не ошибка, но repeat короче
Забыть box-sizing: border-box Padding «ломает» размеры
minmax(200px, 1fr) без auto-fit Не адаптируется — всегда 3 колонки
Использовать auto-fill вместо auto-fit Остаются пустые колонки
Забыть gap Элементы «слипаются»
1fr в grid-template-rows без height Не работает — нет свободного места

11. Что запомнить из урока

  • grid-template-columns — колонки.
  • grid-template-rows — строки.
  • fr — доля свободного места. Главная единица Grid.
  • repeat(3, 1fr) = 1fr 1fr 1fr.
  • minmax(min, max) — диапазон размера.
  • repeat(auto-fit, minmax(200px, 1fr)) — адаптивная сетка.
  • auto-fit — пустые колонки схлопываются.
  • auto-fill — пустые колонки остаются.
  • Автоматические строки — если не задано grid-template-rows.
  • 1fr в строках требует height у контейнера.

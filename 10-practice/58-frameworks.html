CSS Урок 58. CSS-фреймворки

1. Что такое CSS-фреймворк

CSS-фреймворк — это готовая библиотека CSS-классов и компонентов. Подключаешь — и получаешь готовые кнопки, карточки, сетки, формы. 

<link rel="stylesheet" href="bootstrap.css">

<button class="btn btn-primary">Кнопка</button>
Аналогия: фреймворк — как конструктор LEGO. Не нужно делать кирпичики самому — берёшь готовые и собираешь.

2. Зачем фреймворки

Плюсы Минусы
Быстро — не пишешь CSS с нуля Одинаковый вид — «все на Bootstrap»
Адаптивность из коробки Большой размер — 200+ КБ
Кроссбраузерность — протестировано Сложно кастомизировать — переопределять
Готовые компоненты — модалки, формы Нужно учить классы фреймворка
Документация — примеры Не для всех — маленькие проекты

3. Два подхода: компонентный vs утилитарный

Bootstrap (компонентный) Tailwind (утилитарный)
Идея Готовые компоненты Утилитарные классы
Пример class="btn btn-primary" class="bg-blue-500 px-4 py-2 rounded"
Стиль Готовый Собираешь сам
Размер 200+ КБ Маленький (только используемые классы)
Гибкость Средняя Высокая
Порог входа Низкий Средний

4. Bootstrap — компонентный

Bootstrap — самый популярный CSS-фреймворк. Готовые компоненты: кнопки, карточки, формы, модалки, навигация.

Подключение

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">

Кнопки

<button class="btn btn-primary">Primary</button>
<button class="btn btn-secondary">Secondary</button>
<button class="btn btn-success btn-lg">Large Success</button>
Bootstrap-подобные кнопки:

5. Tailwind CSS — утилитарный

Tailwind CSS — не даёт готовых компонентов. Даёт утилитарные классы: каждый класс делает одно дело. Ты собираешь компонент сам.

Подключение

<link href="https://cdn.tailwindcss.com" rel="stylesheet">

Кнопка

<button class="bg-blue-500 text-white px-4 py-2 rounded">
    Кнопка
</button>
Tailwind-подобная кнопка:

Карточка

    <p class="text-gray-600 text-sm">Описание карточки.</p>

8. Когда использовать

Ситуация Фреймворк?
Учебный проект Нет — учи CSS
Маленький сайт (1–3 страницы) Не нужен
Админка, дашборд Bootstrap
Прототип Bootstrap / Tailwind
Кастомный дизайн Tailwind
Большой проект Свой CSS / Tailwind
Лендинг Tailwind
Не начинай с фреймворка!
  • Сначала освой чистый CSS.
  • Пойми, как работает каскад, Flexbox, Grid.
  • Потом — фреймворк. Иначе — «магия» без понимания.

9. Проблемы фреймворков

Проблема Что делать
Одинаковый вид Кастомизировать через переменные
Большой размер Tailwind / сборка только нужного
Сложно переопределить CSS-переменные, !important
Зависимость от версии Фиксировать версию в package.json
Долго учить классы Документация + практика

10. Практика: сравни

Сделай одну и ту же кнопку тремя способами:

Чистый CSS

.btn {
    padding: 8px 16px;
    background: #1565c0;
    color: white;
    border: none;
    border-radius: 6px;
    cursor: pointer;
}

Bootstrap

<button class="btn btn-primary">Кнопка</button>

Tailwind

<button class="bg-blue-500 text-white px-4 py-2 rounded">
    Кнопка
</button>
Сравни: чистый CSS — контроль, Bootstrap — короткий HTML, Tailwind — длинный HTML, но гибкий.

11. Частые ошибки

Ошибка Почему плохо
Учить фреймворк до CSS Не поймёшь, как работает
Использовать Bootstrap для всего «Все сайты одинаковые»
Не кастомизировать Сайт «как у всех»
Подключать весь Bootstrap 200+ КБ — медленно
Tailwind без сборки Все классы — большой файл
Смешивать фреймворки Конфликты стилей

12. Что запомнить из урока

  • Фреймворк — готовая библиотека CSS-классов.
  • Bootstrap — компонентный. Готовые кнопки, карточки, сетка.
  • Tailwind — утилитарный. Каждый класс = одно свойство.
  • Bootstrap: короткий HTML, готовый вид. Для админок, прототипов.
  • Tailwind: длинный HTML, гибкий. Для кастомных дизайнов.
  • Не начинай с фреймворка — сначала чистый CSS.
  • Кастомизируй — иначе «как у всех».
  • Не подключай весь Bootstrap — 200+ КБ.
  • Для лендингов — Tailwind. Для админок — Bootstrap.

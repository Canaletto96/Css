CSS Урок 37. Автоматическая сетка

1. Что такое автоматическая сетка

Автоматическая сетка — это как Grid размещает элементы, которые не указаны в grid-template-*.

Три свойства управляют этим:

Свойство Что задаёт
grid-auto-flow Как заполнять (по строкам / колонкам / dense)
grid-auto-rows Высота автоматических строк
grid-auto-columns Ширина автоматических колонок

2. grid-auto-flow — направление

Значение Что делает
row (по умолчанию)Заполняет по строкам
columnЗаполняет по колонкам
row denseЗаполняет по строкам, «уплотняя» дыры
column denseЗаполняет по колонкам, «уплотняя» дыры

3. grid-auto-flow: dense — «уплотнение»

Если есть большие элементы (через span), они могут оставить «дыры» в сетке. dense пытается заполнить эти дыры маленькими элементами. 

.container {
    grid-auto-flow: row dense;
}

Осторожно с dense: меняет визуальный порядок. Screen reader читает в HTML-порядке. Может быть несоответствие. Используй только для галерей, где порядок не важен.

4. grid-auto-rows — высота строк

Задаёт высоту автоматических строк (которые не в grid-template-rows).

    grid-auto-rows: 100px;   /* каждая автоматическая строка — 100px */

grid-auto-rows: minmax()

5. grid-auto-columns — ширина колонок

Аналогично — для автоматических колонок. Работает только с grid-auto-flow: column.

    grid-auto-flow: column;
    grid-auto-columns: 100px;
}

7. Практика: masonry-подобная сетка

.masonry {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-auto-rows: 10px;
    gap: 16px;
}

.item-1 { grid-row: span 20; }   /* высокая */
.item-2 { grid-row: span 12; }   /* средняя */
.item-3 { grid-row: span 16; }   /* низкая */

8. Что выбрать

Задача Свойство
Обычная сетка grid-template-columns + grid-auto-rows
Автоматическое размещение grid-auto-flow: row (по умолчанию)
Заполнение «дыр» grid-auto-flow: dense
Masonry grid-auto-rows: 10px + span
Горизонтальная сетка grid-auto-flow: column

9. Частые ошибки

Ошибка Почему плохо
grid-auto-rows: 1fr без height контейнера Не работает — нет свободного места
Использовать dense без причины Ломает визуальный порядок, плохо для a11y
Забыть grid-auto-flow По умолчанию row — может быть не тем
grid-auto-rows: 100px с длинным контентом Контент «обрежется». Лучше minmax(100px, auto)
grid-auto-columns без grid-auto-flow: column Не работает

10. Что запомнить из урока

  • grid-auto-flow — как заполнять: row, column, dense.
  • grid-auto-rows — высота автоматических строк.
  • grid-auto-columns — ширина автоматических колонок.
  • row (по умолчанию) — по строкам.
  • column — по колонкам (нужен grid-template-rows).
  • dense — «уплотнить» дыры. Осторожно с a11y.
  • grid-auto-rows: minmax(100px, auto) — минимум 100px.
  • grid-auto-rows: 1fr — равные строки, но нужна height.
  • Masonry — grid-auto-rows: 10px + span N.

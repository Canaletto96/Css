CSS Урок 16. Переполнение

1. Что такое переполнение

Переполнение (overflow) — ситуация, когда содержимое больше размеров блока (по ширине или высоте). 

.box {
    width: 200px;
    height: 80px;
    /* контент больше — что делать? */
}

По умолчанию браузер показывает контент, даже если он вылезает за границы блока:

Без overflow — контент вылезает:
Этот текст очень длинный и не влезает в блок 200×80. Он вылезает за границы.

2. Свойство overflow

Управляет тем, что делать с переполнением:

Значение Что делает
visible (по умолчанию)Показывает всё, даже за границами
hiddenОбрезает всё, что не влезает
scrollВсегда показывает скроллбары
autoСкроллбары, только если нужно
clipОбрезает без возможности скролла (новое)

3. overflow: visible — по умолчанию

Контент вылезает за границы блока. Может наезжать на соседние элементы.

overflow: visible:
Этот текст очень длинный и не влезает в блок. Он вылезает за границы и наезжает на другие элементы.

4. overflow: hidden — обрезать

Всё, что не влезает — обрезается. Прокрутки нет.

.box {
    overflow: hidden;
}
overflow: hidden:
Этот текст очень длинный и не влезает в блок. Он обрезается, и его нельзя увидеть.

Где использовать hidden

  • Скруглённые углы — обрезать контент по border-radius.
  • Картинки — обрезать по контейнеру.
  • Скрыть горизонтальный скролл — если он не нужен.
  • Создать BFC — overflow: hidden создаёт новый контекст форматирования.
Осторожно: overflow: hidden может обрезать box-shadow и outline — они не входят в размер блока. Если нужна тень, добавь padding или используй overflow: clip с overflow-clip-margin.

5. overflow: scroll — всегда скроллбары

Скроллбары всегда видны, даже если контент влезает.

overflow: scroll:
Этот текст очень длинный и не влезает в блок. Появились скроллбары.

Недостаток: даже если контент маленький, скроллбары занимают место.

6. overflow: auto — скроллбары по необходимости

Скроллбары появляются только если нужно. Это самый популярный вариант.

.box {
    overflow: auto;
}
overflow: auto — есть переполнение:
Этот текст очень длинный и не влезает в блок. Появился скроллбар, но только потому что нужно.
overflow: auto — нет переполнения (скроллбара нет):
Короткий текст.

7. overflow-x и overflow-y

Управляют переполнением отдельно по осям:

.box {
    overflow-x: auto;   /* горизонталь */
    overflow-y: hidden; /* вертикаль */
}
Свойство Что контролирует
overflow-xГоризонтальное переполнение
overflow-yВертикальное переполнение
overflow-x: auto, overflow-y: hidden:
Этот текст очень длинный и не влезает в блок по горизонтали. Появился горизонтальный скроллбар.

Частый приём: горизонтальная прокрутка таблиц

.table-wrapper {
    overflow-x: auto;
}

table {
    min-width: 600px;   /* таблица шире контейнера */
}

8. overflow: clip — современное обрезание

Похоже на hidden, но не создаёт скролл-контейнер и не может быть прокручено даже программно. Можно задать отступ обрезания. 

.box {
    overflow: clip;
    overflow-clip-margin: 10px;   /* обрезать на 10px дальше границы */
}
Разница hidden и clip:
  • hidden — можно программно прокрутить (element.scrollTop = 100).
  • clip — нельзя прокрутить вообще.
  • clip поддерживается в современных браузерах (Chrome 90+, Firefox 81+).

9. overflow-clip-margin

Позволяет «отпустить» обрезание на несколько пикселей — полезно для теней.

.box {
    overflow: clip;
    overflow-clip-margin: 20px;
}
overflow: clip с отступом для тени:
Тень видна благодаря overflow-clip-margin

10. Скрыть скроллбар

Иногда нужна прокрутка, но без видимого скроллбара:

.scroll {
    overflow: auto;
    scrollbar-width: none;   /* Firefox */
}

.scroll::-webkit-scrollbar {
    display: none;   /* Chrome, Safari, Edge */
}
Осторожно: скрывать скроллбар — плохо для доступности. Пользователь может не понять, что контент прокручивается. Показывай хотя бы индикатор.

11. overflow и border-radius

Если у блока border-radius, а содержимое вылезает — overflow: hidden обрежет по скруглённым углам. 

.box {
    border-radius: 50%;
    overflow: hidden;
}

.box img {
    width: 100%;
    height: 100%;
    object-fit: cover;
}

12. overflow и box-shadow

Проблема: overflow: hidden обрезает box-shadow и outline — они не входят в размер блока.
overflow: hidden обрезает тень:
Тень обрезана

Решения:

  • Добавить padding вокруг блока — тень не обрежется.
  • Использовать overflow: clip с overflow-clip-margin.
  • Поместить тень на родителя, а не на сам блок.

13. overflow и position: sticky

position: sticky не работает, если у любого родителя стоит overflow: hidden, auto или scroll. Это частая проблема.

Правило: если position: sticky не работает — проверь, нет ли у родителей overflow. Даже невидимый overflow: hidden ломает sticky.

14. Практика: карточка с обрезанным текстом

.card {
    width: 300px;
    padding: 16px;
    border: 1px solid #ddd;
    border-radius: 8px;
    overflow: hidden;   /* обрезать длинный текст */
}

.card p {
    display: -webkit-box;
    -webkit-line-clamp: 3;   /* максимум 3 строки */
    -webkit-box-orient: vertical;
    overflow: hidden;
}
Обрезка текста через -webkit-line-clamp:

Заголовок

Этот текст очень длинный и не влезает в 3 строки. Он обрезается многоточием. Это удобно для карточек, где нужно показать только часть текста. Остальное пользователь увидит на странице статьи.

-webkit-line-clamp — нестандартное свойство, но работает во всех современных браузерах. Обрезает текст по количеству строк с многоточием.

15. Частые ошибки

Ошибка Почему плохо
Забыть overflow — контент вылезает Ломает layout, наезжает на соседей
overflow: hidden на родителе sticky Sticky не работает
overflow: hidden без учёта тени Тень обрезается
Скрывать скроллбар без причины Плохо для доступности
overflow: scroll без переполнения Скроллбар занимает место зря
overflow-x: hidden + абсолютные элементы Обрезает выпадающие меню

16. Что запомнить из урока

  • overflow — что делать с контентом, который не влезает.
  • visible — показывать (по умолчанию).
  • hidden — обрезать.
  • scroll — всегда скроллбары.
  • auto — скроллбары по необходимости. Рекомендую.
  • clip — обрезать без возможности прокрутки (новое).
  • overflow-x / overflow-y — по осям.
  • Горизонтальная прокрутка таблиц — overflow-x: auto на обёртке.
  • overflow: hidden обрезает box-shadow и outline.
  • overflow: hidden ломает position: sticky у детей.
  • border-radius + overflow: hidden — обрезка по скруглённым углам.
  • -webkit-line-clamp — обрезка текста по строкам.

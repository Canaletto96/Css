CSS Урок 40. Адаптивность — введение

1. Что такое адаптивность

Адаптивность (responsive design) — это способность сайта подстраиваться под размер экрана: мобильный, планшет, десктоп.

Один и тот же HTML, но разные стили для разных ширин.

Зачем:
  • 60% трафика — мобильные.
  • Google ранжирует по mobile-first (с 2021).
  • Неадаптивный сайт = плохой UX = потеря пользователей.

3. meta viewport

Первое, что нужно для адаптивности — meta viewport в <head>. 

<meta name="viewport" content="width=device-width, initial-scale=1.0">
Часть Что означает
width=device-width Ширина страницы = ширина экрана
initial-scale=1.0 Начальный масштаб 100%
Без viewport мобильный браузер покажет «десктопную» версию, сжатую до размера экрана. Текст будет микроскопическим.

4. Два подхода: mobile-first vs desktop-first

Mobile-first Desktop-first
С чего начинать С мобильного С десктопа
Базовые стили Мобильные Десктопные
Media queries min-width max-width
Сложность Проще Сложнее
Производительность Лучше (меньше CSS на мобильных) Хуже (много CSS на мобильных)
Рекомендация Да Для legacy-проектов

5. Mobile-first

Базовые стили — для мобильных. Потом через @media (min-width: ...) добавляем стили для больших экранов. 

/* Базовые стили — мобильные */
.container {
    padding: 16px;
}

.cards {
    display: grid;
    grid-template-columns: 1fr;   /* одна колонка */
    gap: 16px;
}

/* Планшет */
@media (min-width: 768px) {
    .cards {
        grid-template-columns: repeat(2, 1fr);   /* две колонки */
    }
}

/* Десктоп */
@media (min-width: 1024px) {
    .container {
        padding: 32px;
    }
    .cards {
        grid-template-columns: repeat(3, 1fr);   /* три колонки */
    }
}
Логика: мобильные — «по умолчанию». Потом добавляем стили для больших экранов. min-width означает «от этого размера и больше».

6. Desktop-first

Базовые стили — для десктопа. Потом через @media (max-width: ...) — для меньших. 

/* Базовые стили — десктоп */
.cards {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
}

/* Планшет */
@media (max-width: 1023px) {
    .cards {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* Мобильный */
@media (max-width: 767px) {
    .cards {
        grid-template-columns: 1fr;
    }
}
Не рекомендуется: на мобильных грузится много CSS, который не используется. Плюс сложнее поддерживать. Используй только для legacy-проектов.

7. Как выбрать брейкпоинты

Не подгоняй под конкретные устройства (iPhone, Samsung). Подгоняй под контент: когда вёрстка «ломается» — ставь брейкпоинт. 

/* Не так: */
@media (max-width: 375px) { }   /* iPhone SE */
@media (max-width: 414px) { }   /* iPhone Pro Max */

/* А так: */
@media (min-width: 768px) { }   /* планшет */
@media (min-width: 1024px) { }  /* десктоп */
Правило: открой DevTools → сузь окно. Когда вёрстка «ломается» — это твой брейкпоинт.

10. Что НЕ адаптивность

Плохие способы:
  • Отдельный сайт для мобильных (m.site.com) — устарело, плохо для SEO.
  • Фиксированная ширина 1200px — горизонтальный скролл на мобильных.
  • Уменьшение всего через transform: scale() — не работает для текста.
  • Скрытие контента на мобильных — плохо для SEO.
  • Только meta viewport без media queries — недостаточно.

11. Частые ошибки

Ошибка Почему плохо
Забыть meta viewport Мобильный браузер покажет «десктопную» версию
Фиксированные width в px Горизонтальный скролл
Использовать max-width для mobile-first Путаница. Для mobile-first — min-width
Подгонять под конкретные устройства Устройств тысячи. Подгоняй под контент
Слишком много брейкпоинтов Сложно поддерживать. 3–5 хватает
Скрывать контент на мобильных Плохо для SEO и UX

12. Что запомнить из урока

  • Адаптивность — сайт подстраивается под экран.
  • meta viewport — обязательна. width=device-width, initial-scale=1.0.
  • Mobile-first — базовые стили для мобильных, min-width для десктопа. Рекомендую.
  • Desktop-first — базовые для десктопа, max-width для мобильных. Legacy.
  • Брейкпоинты — под контент, не под устройства.
  • Стандартные: 576, 768, 992, 1200px.
  • Не используй отдельный сайт для мобильных.
  • Не скрывай контент на мобильных.
  • Проверяй в DevTools — сузь окно.

CSS Урок 2. Способы подключения CSS

1. Обзор: 4 способа

Способ Где пишется Когда использовать
Внешний файл Отдельный .css, подключён через <link> Основной способ — 99% случаев
<style> Внутри <head> Прототипы, email-письма, один файл
style="" Атрибут тега Тест, динамика через JS
@import Внутри CSS Редко — модульность

2. Способ 1: внешний файл (рекомендуется)

CSS лежит в отдельном файле .css, а HTML подключает его через тег <link>.

Структура

my-site/
├── index.html
└── style.css    ← отдельный файл

HTML

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Мой сайт</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>Заголовок</h1>
</body>
</html>

CSS

/* style.css */
h1 {
    color: blue;
    font-size: 32px;
}

Плюсы

  • ✅ Один файл для всех страниц — переиспользование.
  • ✅ Браузер кеширует — быстрее загрузка.
  • ✅ HTML остаётся чистым.
  • ✅ Легко поддерживать и менять.

Минусы

  • ❌ Нужен отдельный файл — чуть сложнее структура.
  • ❌ При локальном открытии (file://) может быть проблема с путями.

Как работает <link>

<link rel="stylesheet" href="style.css">
Атрибут Что означает
rel="stylesheet" Тип связи — «таблица стилей». Обязателен.
href="style.css" Путь к CSS-файлу (см. урок 25 HTML-курса)
Путь к файлу: если style.css лежит рядом с index.html — href="style.css". Если в папке css/ — href="css/style.css".

3. Способ 2: <style> внутри HTML

CSS пишется прямо в HTML, внутри тега <style> в <head>. 

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Мой сайт</title>
    <style>
        h1 {
            color: blue;
            font-size: 32px;
        }
    </style>
</head>
<body>
    <h1>Заголовок</h1>
</body>
</html>

Плюсы

  • ✅ Один файл — удобно для прототипов.
  • ✅ Не нужно настраивать пути.
  • ✅ Работает в email-письмах (там <link> часто не работает).

Минусы

  • ❌ Не кешируется — грузится с каждым HTML.
  • ❌ Смешивает HTML и CSS — сложнее читать.
  • ❌ Только для одной страницы.
  • ❌ Не работает для нескольких HTML-файлов.

Где писать <style>

  • В <head> — рекомендуется. Стили применяются до отрисовки.
  • В <body> — технически работает, но может «мигнуть» контент.

4. Способ 3: инлайн-стили (style="")

CSS пишется прямо в атрибуте тега style. 

<h1 style="color: blue; font-size: 32px;">Заголовок</h1>
<p style="margin-top: 20px; color: gray;">Текст</p>
Результат:

Заголовок

Текст с инлайн-стилем

Плюсы

  • ✅ Быстро — можно проверить «на лету».
  • ✅ Работает везде, включая email.
  • ✅ Используется для динамики через JS (element.style.color = 'red').

Минусы

  • ❌ Высокая специфичность — сложно переопределить.
  • ❌ Не кешируется.
  • ❌ HTML превращается в «кашу».
  • ❌ Не работает для :hover, медиа-запросов.
Правило: style="" — только для теста или динамики через JS. В основном коде — не используй.

5. Способ 4: @import

CSS-файл может подключать другой CSS-файл через @import. Это не «четвёртый способ подключения к HTML», а внутри CSS. 

/* style.css */
@import url('reset.css');
@import url('typography.css');

h1 {
    color: blue;
}

Плюсы

  • ✅ Модульность — разбить CSS на части.
  • ✅ Один <link> в HTML — остальное внутри.

Минусы

  • ❌ Замедляет загрузку — файлы грузятся последовательно, а не параллельно.
  • ❌ Не работает в старых браузерах (IE).
  • ❌ Сложно отлаживать — не видно, откуда пришёл стиль.
Современная альтернатива: несколько <link> в HTML работают лучше, чем @import: 
<link rel="stylesheet" href="reset.css">
<link rel="stylesheet" href="typography.css">
<link rel="stylesheet" href="style.css">
Они грузятся параллельно.

Синтаксис @import

@import url('style.css');           /* с url() */
@import 'style.css';                 /* без url() — тоже работает */
@import url('style.css') screen;    /* только для экрана */
Важно: @import должен быть в самом верху CSS-файла, до любых других правил. Иначе не сработает.

6. Сравнение всех способов

Внешний файл <style> style="" @import
Переиспользование ✅ Все страницы ❌ Одна ❌ Один тег ✅ Все
Кеширование ✅ Да ❌ Нет ❌ Нет ✅ Да
Скорость загрузки ✅ Параллельно ✅ Быстро ✅ Быстро ❌ Последовательно
Чистота HTML ✅ Да ⚠️ Смешивается ❌ Очень смешивается ✅ Да
Специфичность Обычная Обычная ⚠️ Высокая Обычная
Когда использовать Основной Прототипы, email Тест, JS Редко — модульность

7. Можно ли комбинировать?

Да, и это нормально. Например:

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Мой сайт</title>
    <link rel="stylesheet" href="style.css">
    <style>
        /* Специфичные стили только для этой страницы */
        .hero { background: #f0f0f0; }
    </style>
</head>
<body>
    <h1 style="color: red;">Тест</h1>
    <section class="hero">...</section>
</body>
</html>

Порядок применения (по каскаду):

  1. Браузерные стили (user agent).
  2. Внешний файл (style.css).
  3. <style> в HTML.
  4. style="" — самый высокий приоритет (если нет !important).

8. Как проверить, какой стиль применился

DevTools (F12) → Elements → выбери элемент → справа увидишь все CSS-правила, которые к нему применились.

Ты увидишь:

  • Откуда правило (файл + строка).
  • Какие правила перебиты (зачёркнуты).
  • Какое правило победило.

9. Что запомнить из урока

  • 4 способа: внешний файл, <style>, style="", @import.
  • Основной способ — внешний файл через <link rel="stylesheet" href="...">.
  • <style> — для прототипов и email-писем.
  • style="" — для теста и JS-динамики. Не для основного кода.
  • @import — внутри CSS. Замедляет загрузку. Используй редко.
  • Можно комбинировать. Порядок: user agent → внешний → <style> → style="".
  • rel="stylesheet" — обязательный атрибут <link>.
  • @import — только в начале CSS-файла.
  • Проверяй в DevTools — какой стиль применился.

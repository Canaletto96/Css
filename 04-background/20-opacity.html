CSS Урок 20. Прозрачность

1. Два способа сделать прозрачность

Свойство Что делает прозрачным Наследуется детьми?
opacity Всё: фон, текст, рамки, детей Да
rgba() Только цвет (фон или текст) Нет
Главное отличие:
  • opacity — «сделать весь элемент полупрозрачным». Дети тоже станут прозрачными.
  • rgba() — «сделать цвет полупрозрачным». Фон или текст — но не детей.

2. opacity — прозрачность всего блока

Значение от 0 до 1:

Значение Что означает
1Полностью непрозрачный (по умолчанию)
0.880% непрозрачности (20% прозрачности)
0.550% (половина прозрачности)
0Полностью прозрачный (не виден)
 
.box {
    opacity: 0.5;
}
Разные значения opacity:

opacity влияет на детей

Если у родителя opacity: 0.5 — все дети тоже станут полупрозрачными. Даже если у ребёнка стоит opacity: 1 — он не «восстановится». 

.parent {
    opacity: 0.5;   /* ← все дети тоже станут прозрачными */
}

.child {
    opacity: 1;    /* ← НЕ работает: opacity перемножается */
}
opacity 0.5 на родителе — дети тоже прозрачные:

Это родитель с opacity: 0.5

А это ребёнок с opacity: 1 — но он тоже полупрозрачный!

Почему так: opacity — это не «сделать цвет прозрачным», а «сделать весь элемент (включая детей) прозрачным». Ребёнок с opacity: 1 внутри opacity: 0.5 — это 0.5 × 1 = 0.5.

3. rgba() — прозрачность цвета

rgba() — это rgb() с альфа-каналом (прозрачностью) от 0 до 1. 

.box {
    background: rgba(21, 101, 192, 0.5);   /* синий фон, 50% прозрачности */
    color: rgba(0, 0, 0, 0.8);              /* чёрный текст, 80% непрозрачности */
}

4. Когда что использовать

Задача Что использовать
Полупрозрачный фон (дети непрозрачные) background: rgba(...)
Полупрозрачный текст (фон непрозрачный) color: rgba(...)
Полупрозрачный блок целиком (с детьми) opacity
Полупрозрачная картинка opacity (или filter: opacity())
Полупрозрачная кнопка с текстом background: rgba(...) + color: #fff

5. filter: opacity() — альтернатива

Функция opacity() внутри filter работает так же, как opacity, но не наследуется детьми. 

.box {
    filter: opacity(0.5);
}
Разница:
  • opacity: 0.5 — весь элемент и дети полупрозрачные.
  • filter: opacity(0.5) — весь элемент и дети тоже полупрозрачные (визуально — как opacity).
На самом деле, filter: opacity() не наследуется в CSS-смысле, но визуально блок с детьми всё равно выглядит полупрозрачным. Разница тонкая — на практике используют opacity.

6. Комбинирование

Можно комбинировать opacity и rgba:

.box {
    opacity: 0.8;                              /* весь блок 80% */
    background: rgba(21, 101, 192, 0.5);        /* фон 50% от 80% = 40% */
}
opacity 0.8 + rgba 0.5 (фон становится «двойной прозрачности»):

opacity: 0.8 + rgba 0.5

Формула: итоговая прозрачность = opacity × альфа. Например, opacity: 0.8 и rgba(..., 0.5) = 0.8 × 0.5 = 0.4 (60% прозрачности).

7. Практика: карточка с overlay

.card {
    position: relative;
    overflow: hidden;
    border-radius: 12px;
}

.card-image {
    display: block;
    width: 100%;
    height: 200px;
    object-fit: cover;
}

.card-overlay {
    position: absolute;
    inset: 0;
    background: rgba(0, 0, 0, 0.5);
    display: flex;
    align-items: center;
    justify-content: center;
    color: white;
    opacity: 0;                    /* ← скрыт */
    transition: opacity 0.3s;
}

.card:hover .card-overlay {
    opacity: 1;                    /* ← появляется при hover */
}

8. Практика: disabled-состояние

.btn:disabled {
    opacity: 0.5;   /* ← визуально «отключённая» кнопка */
    cursor: not-allowed;
}
Кнопки с opacity для disabled:
Важно: opacity: 0.5 для disabled — не заменяет disabled. Атрибут disabled отключает кнопку (не кликается), opacity — только визуально. Используй оба.

9. Частые ошибки

Ошибка Почему плохо
Использовать opacity для полупрозрачного фона Дети тоже станут прозрачными. Лучше rgba()
Использовать rgba() для картинки Не работает. Для картинки — opacity или filter: opacity()
opacity: 0 + клик Элемент невидим, но кликабельный. Для «скрыть» — display: none или visibility: hidden
Анимация opacity без transition Резко «прыгает»
Забыть про «двойную прозрачность» opacity × rgba = ещё прозрачнее

10. Что запомнить из урока

  • opacity — прозрачность всего блока, включая детей.
  • rgba() — прозрачность цвета (фон, текст), детей не трогает.
  • Значения: 0 (прозрачный) — 1 (непрозрачный).
  • Для полупрозрачного фона — background: rgba(...).
  • Для полупрозрачного блока целиком — opacity.
  • Для картинок — opacity или filter: opacity().
  • opacity × rgba = «двойная прозрачность».
  • Disabled — opacity: 0.5 + атрибут disabled.
  • Overlay — rgba + opacity + transition.

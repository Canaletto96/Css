CSS Урок 25. float и clear

1. Что такое float

float — «обтекание». Элемент выходит из потока и прижимается к левому или правому краю родителя. Остальной контент обтекает его. 

.image {
    float: left;    /* прижать влево, текст обтекает справа */
}

.sidebar {
    float: right;   /* прижать вправо */
}
Значение Что делает
leftПрижать влево, обтекание справа
rightПрижать вправо, обтекание слева
none (по умолчанию)Не обтекать

2. Базовый пример: картинка + текст

<img src="photo.jpg" class="float-left" alt="Фото">
<p>Длинный текст, который будет обтекать картинку...</p>
.float-left {
    float: left;
    margin: 8px 12px 8px 0;
}
float: left — текст обтекает:
float: left

Это длинный текст, который обтекает картинку. Так раньше делали обтекание картинок в статьях. Текст идёт справа от картинки, а потом под ней, когда картинка заканчивается. Этот приём использовался ещё в 90-е и до сих пор работает.

3. Проблема: родитель «схлопывается»

Если все дети элемента float — родитель теряет высоту. Он «не видит» float-детей. 

.parent {
    background: #f0f0f0;
    /* height не задан */
}

.child {
    float: left;
}
/* Родитель «схлопнется» до нулевой высоты */
Родитель «схлопнулся» — нет высоты:

Красная рамка — родитель. У него нет высоты, потому что дети float.

4. clear — «очистка»

clear говорит: «этот элемент не может обтекать float-элементы». Он сдвигается под float.

Значение Что делает
leftНе обтекает float: left
rightНе обтекает float: right
bothНе обтекает ни left, ни right
none (по умолчанию)Обтекает
 
.clear {
    clear: both;   /* сдвинуть под все float */
}
clear: both — блок сдвинут под float:
float: left

Текст обтекает картинку.

clear: both — этот блок под float

5. Clearfix — «лечение» схлопывания родителя

Классическая проблема: родитель «схлопывается», потому что дети float. Решение — clearfix — псевдоэлемент ::after, который «очищает» float. 

.clearfix::after {
    content: "";
    display: table;
    clear: both;
}
clearfix — родитель «видит» детей:

Зелёная рамка — родитель. Теперь у него есть высота.

Как работает clearfix

  1. ::after — создаёт псевдоэлемент после содержимого.
  2. content: "" — пустой.
  3. display: table — чтобы работало в старых браузерах.
  4. clear: both — сдвигает псевдоэлемент под float, растягивая родителя.
Современная альтернатива: display: flow-root на родителе — создаёт BFC, родитель «видит» float-детей. Проще и без псевдоэлементов. 
.parent {
    display: flow-root;   /* ← современный clearfix */
}

6. Float для раскладки (legacy)

До Flexbox и Grid float использовали для сеток: колонки прижимались друг к другу. 

.column {
    float: left;
    width: 33.33%;
}
3 колонки через float:
33.33%
33.33%
33.33%
Не используй float для раскладки! Это legacy. Flexbox и Grid — современные способы, проще и мощнее. Float — только для обтекания текста вокруг картинки (это его прямое назначение).

7. Float и строчные элементы

Float работает только для блочных элементов. Если применить к строчному (<span>, <a>) — браузер сделает его block автоматически. 

span {
    float: left;   /* станет блочным */
}

8. Float и display

Важно: если у элемента задан float, то display игнорируется (кроме none). Браузер сам делает элемент block (или inline-block).

9. Практика: картинка с обтеканием

*, *::before, *::after {
    box-sizing: border-box;
}

.article {
    display: flow-root;   /* ← современный clearfix */
}

.article img {
    float: left;
    width: 200px;
    margin: 0 16px 8px 0;
    border-radius: 8px;
}

.article p {
    margin: 0 0 12px 0;
}
Картинка + текст (float: left):
ФОТО

Это длинный текст, который обтекает картинку слева. Так делают в статьях, блогах, новостях. Картинка прижата влево, текст идёт справа, а потом под ней.

Второй параграф тоже обтекает картинку. Когда картинка заканчивается — текст занимает всю ширину.

10. Практика: две колонки (legacy)

.container {
    display: flow-root;
}

.sidebar {
    float: left;
    width: 250px;
}

.content {
    float: left;
    width: calc(100% - 250px);
}
Две колонки через float (legacy):
Sidebar
30%
Content
70%

Так делали до Flexbox и Grid. Сейчас — display: grid или display: flex.

11. Частые ошибки

Ошибка Почему плохо
Использовать float для сеток Legacy. Flexbox/Grid проще
Забыть clearfix Родитель «схлопывается»
Float для всех элементов Ломает поток, сложно управлять
Float внутри Flexbox Игнорируется — flex-элементы ведут себя иначе
Float + display: flex Flexbox «отменяет» float
Float без ширины Элемент «схлопнется» до содержимого

12. Когда float актуален

  • Обтекание картинки текстом — прямое назначение.
  • Старый код — читать, понимать, но не писать.
  • Очень простые случаи — обтекание в статье.

Для всего остального:

Задача Современный способ
Ряд элементовdisplay: flex
Сеткаdisplay: grid
Колонкиgrid-template-columns
Обтекание картинкиfloat (всё ещё актуален)

13. Что запомнить из урока

  • float — «обтекание». left, right, none.
  • Родитель «схлопывается», если все дети float.
  • clear — «не обтекать». left, right, both.
  • Clearfix — ::after { content: ""; display: table; clear: both; }.
  • Современный clearfix — display: flow-root на родителе.
  • Float — legacy для раскладки. Используй Flexbox/Grid.
  • Float актуален для обтекания картинки текстом.
  • Float + display: flex — float игнорируется.
  • Float без ширины — элемент схлопывается до содержимого.

CSS Урок 12. box-sizing

1. Проблема, которую решает box-sizing

В прошлом уроке мы выяснили:

.box {
    width: 200px;
    padding: 20px;
    border: 5px solid;
}

Какая общая ширина блока? Не 200px, а 250px: 

200 (content) + 20 (padding-left) + 20 (padding-right) + 5 (border-left) + 5 (border-right) = 250px
Box с width: 200px, padding: 20px, border: 5px (по умолчанию):
content: 200px
+ padding: 40px
+ border: 10px
= 250px
Измерь через DevTools: 250px (а не 200px!)

Это главная боль новичков. Ты пишешь width: 200px, а блок получается 250px. Если у тебя сетка из 3 колонок по 33.33% — они не поместятся в ряд из-за padding.

2. Решение: box-sizing: border-box

Свойство box-sizing меняет способ подсчёта размеров.

Значение Что означает
content-box По умолчанию. width = только content. Padding и border добавляются
border-box width = content + padding + border. Padding и border «входят» в ширину

3. Сравнение

Одинаковый код, разный box-sizing:

content-box (по умолчанию)

width: 200px
Общая: 250px

border-box

width: 200px
Общая: 200px

С border-box:

общая ширина = width (200px)
content = 200 - padding (40) - border (10) = 150px

Браузер «съедает» padding и border внутри 200px. Content становится меньше, но общая ширина ровно 200px.

4. Почему это спасает вёрстку

Классический пример: сетка из 3 колонок.

С content-box — ломается

.column {
    width: 33.33%;
    padding: 16px;
    border: 1px solid #ddd;
}

Каждая колонка = 33.33% + 32px + 2px 33.33%. Три колонки не поместятся в ряд — третья «упадёт» на новую строку.

3 колонки по 33.33% с padding (content-box) — ломается:
33.33%
33.33%
33.33% — упала

Третья колонка не поместилась в ряд.

С border-box — работает

* {
    box-sizing: border-box;
}

.column {
    width: 33.33%;
    padding: 16px;
    border: 1px solid #ddd;
}

Каждая колонка = ровно 33.33%. Всё влезает.

3 колонки по 33.33% с border-box — работает:
33.33%
33.33%
33.33%

Все три колонки в ряду.

Именно поэтому border-box стал стандартом в современной вёрстке. Без него любая сетка требует «вычитаний» из ширины (width: calc(33.33% - 32px)), что неудобно и легко ломается.

5. Универсальный сброс

Стандартная практика — применить border-box ко всем элементам в начале CSS: 

*, *::before, *::after {
    box-sizing: border-box;
}

Почему ::before и ::after

Псевдоэлементы ::before и ::after — это «невидимые» элементы, которые часто используются для декора (иконки, фоны). Если у них не будет border-box, они могут сломать layout.

Поэтому полный сброс:

*, *::before, *::after {
    box-sizing: border-box;
}

Это 3 селектора, которые покрывают всё.

Можно ли сделать это на html? 
html {
    box-sizing: border-box;
}
*, *::before, *::after {
    box-sizing: inherit;
}
Это лучший вариант — если компонент захочет content-box для себя, он может «переопределить» через box-sizing: content-box, и дети унаследуют. Но на практике хватает простого *.

6. Исключения: когда оставить content-box

border-box — почти всегда правильный выбор. Но есть редкие случаи, когда нужен content-box:

  • Готовые компоненты, которые написаны под content-box (например, старые библиотеки).
  • Точный контроль content — когда важно, чтобы content был ровно 200px, независимо от padding.
  • Некоторые стили форм (редко).
Правило: border-box — по умолчанию для всего. content-box — точечно, если точно знаешь, зачем.

7. Влияние на width и height

content-box border-box
width: 200px content = 200px content + padding + border = 200px
padding: 20px добавляется к 200px → 240px «входит» в 200px → content = 160px
border: 5px добавляется → 250px «входит» → content = 150px
Общая ширина 250px 200px

8. min-width, max-width и box-sizing

box-sizing влияет и на min-width, max-width, min-height, max-height. 

.box {
    box-sizing: border-box;
    width: 100%;
    max-width: 600px;
    padding: 20px;
}

/* Общая ширина = не больше 600px, включая padding */

С content-box было бы: content до 600px, а общая — до 640px. С border-box — общая ровно 600px.

9. Практика: карточка товара

*, *::before, *::after {
    box-sizing: border-box;
}

.card {
    width: 300px;
    padding: 20px;
    border: 1px solid #ddd;
    border-radius: 8px;
}

/* Общая ширина = ровно 300px, включая padding и border */
Карточка 300px (border-box):

Карточка

width: 300px. С border-box общая ширина ровно 300px.

10. Частые ошибки

Ошибка Почему плохо
Не использовать border-box глобально Сетки ломаются, приходится вычитать padding
Забыть ::before/::after в сбросе Псевдоэлементы остаются с content-box — могут ломать
Пытаться «вычесть» padding вручную width: calc(33% - 20px) — хрупко и не нужно с border-box
Думать, что border-box меняет margin Margin не входит в размер при любом box-sizing
Использовать content-box «по привычке» Устаревший подход, ломает адаптив

11. Что запомнить из урока

  • box-sizing — определяет, как считаются размеры.
  • content-box (по умолчанию) — width = только content. Padding и border добавляются.
  • border-box — width = content + padding + border. Padding и border входят в ширину.
  • С border-box width: 200px = ровно 200px, независимо от padding/border.
  • Глобальный сброс: *, *::before, *::after { box-sizing: border-box; }.
  • border-box — стандарт в современной вёрстке.
  • Сетки работают только с border-box (без вычитаний).
  • margin не входит в размер при любом box-sizing.
  • content-box — точечно, если точно знаешь, зачем.

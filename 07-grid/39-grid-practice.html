CSS Урок 39. Практика Grid

1. Что будем делать

В этом уроке — практика. Никакой новой теории. Собираем реальные макеты на Grid:

Макет Что тренируем
Макет страницыgrid-template-areas, 1fr, min-height
Галереяrepeat(auto-fit, minmax()), aspect-ratio
DashboardСложная сетка с span
Карточки товаровАдаптивная сетка
Masonrygrid-auto-rows: 10px + span

2. Макет страницы

Задача: шапка, сайдбар, контент, подвал. Классический макет сайта.

*, *::before, *::after {
    box-sizing: border-box;
}

.layout {
    display: grid;
    grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
    grid-template-columns: 200px 1fr;
    grid-template-rows: auto 1fr auto;
    gap: 16px;
    min-height: 100vh;
    padding: 16px;
    background: #fafafa;
}

.header { grid-area: header; background: #1565c0; color: white; padding: 16px; }
.sidebar { grid-area: sidebar; background: #e3f2fd; padding: 16px; }
.main { grid-area: main; background: #fff; padding: 16px; }
.footer { grid-area: footer; background: #333; color: white; padding: 16px; }

Что важно: grid-template-areas — «карта». min-height: 100vh — на всю высоту. 1fr в строке — контент растягивается.

8. Практическое задание

Задание 1. «Макет страницы»

Создай файл 39-practice.html. Сделай страницу с макетом:

  • Header на всю ширину.
  • Sidebar слева (200px).
  • Main справа (1fr).
  • Footer на всю ширину.
  • min-height: 100vh.

Задание 2. «Галерея»

  • Адаптивная галерея: repeat(auto-fit, minmax(150px, 1fr)).
  • Картинки aspect-ratio: 1/1; object-fit: cover.
  • gap: 16px.

Задание 3. «Карточки товаров»

  • Сетка карточек: repeat(auto-fit, minmax(220px, 1fr)).
  • Каждая карточка — display: flex; flex-direction: column.
  • Картинка, заголовок, цена, кнопка.
  • Кнопка прижата к низу.

Задание 4. «Dashboard»

  • Боковая панель + виджеты разного размера.
  • grid-template-areas.
  • grid-template-columns: 200px 2fr 1fr.

Задание 5. «Собери всё»

  • Шапка + hero + сетка карточек + подвал.
  • Используй grid-template-areas для макета.
  • Используй auto-fit для карточек.
  • Проверь в DevTools — всё ли правильно.

9. Что запомнить из урока

  • Макет страницы — grid-template-areas + min-height: 100vh.
  • Галерея — repeat(auto-fit, minmax(150px, 1fr)) + aspect-ratio: 1/1.
  • Карточки — repeat(auto-fit, minmax(220px, 1fr)) + flex-direction: column.
  • Dashboard — grid-template-areas с разными размерами.
  • Masonry — grid-auto-rows: 10px + span.
  • Всегда box-sizing: border-box — в начале CSS.
  • Всегда gap — вместо margin.
  • aspect-ratio + object-fit: cover — для картинок.
  • min-height: 100vh — для полноэкранных макетов.

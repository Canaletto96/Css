CSS Урок 50. Анимации

1. Что такое animation

Animation — это сложная анимация с несколькими ключами (keyframes). В отличие от transition (только между двумя состояниями), animation может проходить через много состояний.

transition animation
Состояний2 (начало / конец)Много
ТриггерИзменение свойстваЗапускается сама
ЦиклыНетДа (infinite)
НаправлениеНетДа (alternate)
СложностьПрощеМощнее

2. @keyframes — ключевые кадры

@keyframes — это «сценарий» анимации. Где и что происходит в каждый момент. 

@keyframes pulse {
    0% { transform: scale(1); }
    50% { transform: scale(1.2); }
    100% { transform: scale(1); }
}
Часть Что означает
@keyframes pulseИмя анимации
0%Начало
50%Середина
100%Конец
from = 0%, to = 100%. Можно писать from / to или проценты.

3. animation — применение

Применяешь анимацию к элементу через animation: 

.box {
    animation: pulse 1s infinite;
    /*          имя длит. повтор */
}

5. Простые анимации

pulse — пульсация

@keyframes pulse {
    0%, 100% { transform: scale(1); }

}

spin — вращение

@keyframes spin {

    to { transform: rotate(360deg); }

slide — движение

@keyframes slide {
    0% { transform: translateX(0); }
    100% { transform: translateX(200px); }

6. animation-direction — направление

Значение Что делает
normal (по умолчанию)От 0% к 100%
reverseОт 100% к 0%
alternateТуда-обратно (чётные — normal, нечётные — reverse)
alternate-reverseОбратно-туда

alternate — туда-обратно

.anim-slide {
    animation: slide 2s ease-in-out infinite alternate;
}
alternate — туда-обратно:
alternate

7. animation-fill-mode — после окончания

Значение Что делает
none (по умолчанию)Возвращается к исходному
forwardsОстаётся в конечном состоянии (100%)
backwardsОстаётся в начальном (0%) до начала
bothboth: backwards + forwards
 
.fade-in {
    animation: fadeIn 0.5s ease-out forwards;
}
fadeInUp с forwards — остаётся в конечном состоянии:

12. animation-play-state — пауза

    animation: spin 2s linear infinite;
}

.box.paused {
    animation-play-state: paused;
}

13. prefers-reduced-motion — доступность

@media (prefers-reduced-motion: reduce) {
    * {
        animation: none !important;
        transition: none !important;
    }
}
Важно для доступности: некоторые пользователи отключают анимации (эпилепсия, чувствительность). Уважай prefers-reduced-motion.

14. Частые ошибки

Ошибка Почему плохо
Забыть animation-name Анимация не запустится
Забыть animation-duration Длительность 0s — мгновенно
Анимировать width/height Тормозит. Лучше transform
Слишком много infinite Отвлекает, раздражает
Не учитывать prefers-reduced-motion Плохо для доступности
Анимация без forwards Возвращается в исходное после окончания

15. Что запомнить из урока

  • @keyframes — сценарий анимации.
  • animation — применение к элементу.
  • Обязательны: name и duration.
  • animation-direction — normal, reverse, alternate.
  • animation-iteration-count — infinite.
  • animation-fill-mode — forwards (остаться в конце).
  • animation-play-state — paused.
  • Лучше анимировать transform и opacity.
  • prefers-reduced-motion — для доступности.
  • Не злоупотребляй infinite.

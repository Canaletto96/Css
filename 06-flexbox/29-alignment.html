CSS Урок 29. Выравнивание

1. Четыре свойства выравнивания

Свойство Ось Для чего
justify-content Главная Распределяет элементы вдоль главной оси
align-items Поперечная Выравнивает элементы по поперечной оси
align-self Поперечная Переопределяет align-items для одного элемента
align-content Поперечная Выравнивает строки при переносе (только с flex-wrap: wrap)
Помни: главная ось — по умолчанию горизонталь. При flex-direction: column — вертикаль. Оси меняются местами.

Самый частый случай: align-items: center — для вертикального центрирования в строке. Это основа для шапок, меню, кнопок.

4. align-self — для одного элемента

Переопределяет align-items для конкретного элемента. 

.container {
    display: flex;
    align-items: center;
}

.special {
    align-self: flex-start;   /* ← только этот элемент */
}
align-self: у второго элемента — flex-start:

5. align-content — для строк при переносе

Работает только с flex-wrap: wrap и только если есть несколько строк. Выравнивает строки по поперечной оси.

Значение Что делает
stretch (по умолчанию)Строки растянуты
flex-startСтроки в начале
flex-endСтроки в конце
centerСтроки по центру
space-betweenПервая в начале, последняя в конце
space-aroundРавные промежутки
space-evenlyПолностью равные
 
.container {
    display: flex;
    flex-wrap: wrap;
    align-content: center;   /* ← строки по центру */
    height: 200px;
}

6. justify-content vs align-items

Свойство Ось Что выравнивает
justify-content Главная (→) Всю группу элементов вдоль оси
align-items Поперечная (↕) Каждый элемент по высоте
Аналогия:
  • justify-content — «как расставить книги на полке (слева, по центру, по краям)».
  • align-items — «на какой высоте поставить каждую книгу (внизу, по центру, вверху)».

11. Частые ошибки

Ошибка Почему плохо
Забыть, что justify-content — по главной оси При column — вертикаль, не горизонталь
align-content без flex-wrap: wrap Не работает
align-content с одной строкой Не работает — нужны минимум две строки
Ожидать, что align-items: center отцентрирует по главной оси Нет — по поперечной. Для главной — justify-content
Забыть align-self для конкретного элемента Все будут по align-items
Ожидать центрирования без height или align-items Нет контекста — нет выравнивания

12. Шпаргалка

/* Главная ось */
justify-content: flex-start;   /* по умолчанию */
justify-content: center;         /* центр */
justify-content: space-between;  /* первый слева, последний справа */

/* Поперечная ось */
align-items: stretch;            /* по умолчанию */
align-items: center;             /* центр */
align-items: flex-start;         /* в начале */

/* Один элемент */
align-self: center;              /* только для этого */

/* Строки при переносе */
flex-wrap: wrap;
align-content: center;           /* строки по центру */

13. Что запомнить из урока

  • justify-content — по главной оси. flex-start, center, space-between и др.
  • align-items — по поперечной оси. stretch, center, flex-start и др.
  • align-self — для одного элемента, переопределяет align-items.
  • align-content — для строк при переносе (с flex-wrap: wrap).
  • space-between — для шапки (логотип слева, меню справа).
  • align-items: center — для вертикального центрирования в строке.
  • column меняет оси — justify-content становится вертикальным.

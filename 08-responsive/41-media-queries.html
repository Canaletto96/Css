CSS Урок 41. Media queries

1. Что такое media query

Media query — это условие, при котором CSS-правила применяются. Например, «если экран меньше 768px — применить эти стили». 

@media (условие) {
    /* стили */
}

2. Синтаксис

@media (min-width: 768px) {
    .container {
        padding: 32px;
    }
}
Часть Что означает
@mediaНачало правила
(min-width: 768px)Условие
{ }Стили при выполнении условия

3. min-width — «от и больше»

@media (min-width: 768px) — «применить, если ширина окна ≥ 768px». 

.box {
    background: #e53935;   /* мобильный — по умолчанию */
}

@media (min-width: 768px) {
    .box {
        background: #1565c0;   /* планшет и больше */
    }
}

@media (min-width: 1024px) {
    .box {
        background: #43a047;   /* десктоп и больше */
    }
}
Измени ширину окна (красный → синий → зелёный):
Мобильный

4. max-width — «до и меньше»

@media (max-width: 768px) — «применить, если ширина окна ≤ 768px». 

.box {
    background: #43a047;   /* десктоп — по умолчанию */
}

@media (max-width: 1024px) {
    .box {
        background: #1565c0;   /* планшет и меньше */
    }
}

@media (max-width: 768px) {
    .box {
        background: #e53935;   /* мобильный и меньше */
    }
}
Измени ширину окна (зелёный → синий → красный):
Десктоп
Mobile-first vs desktop-first:
  • Mobile-first — min-width (от мобильного к десктопу).
  • Desktop-first — max-width (от десктопа к мобильному).
Рекомендую mobile-first — проще и лучше для SEO.

5. Операторы and, or, not

and — «и»

@media (min-width: 768px) and (max-width: 1024px) {
    /* применить, если ширина от 768 до 1024 */
}
Только планшет (768–1024px):
Не планшет

or — «или» (через запятую)

@media (max-width: 576px), (min-width: 1200px) {
    /* применить, если ширина до 576 ИЛИ от 1200 */
}
Мобильный или большой экран:
Средний экран

not — «не»

@media not screen {
    /* применить, если НЕ экран (например, печать) */
}

@media not (min-width: 768px) {
    /* применить, если НЕ от 768px (то есть меньше) */
}
not — редко используется. В большинстве случаев можно обойтись min-width / max-width.

6. Диапазоны (современный синтаксис)

С 2023 можно писать диапазоны без and: 

/* Новый синтаксис */
@media (768px = width = 1024px) {
    /* от 768 до 1024 */
}

/* Эквивалент старого */
@media (min-width: 768px) and (max-width: 1024px) {
    /* от 768 до 1024 */
}
Поддержка: новый синтаксис поддерживается во всех современных браузерах (Chrome 104+, Firefox 102+, Safari 16.4+). Но старый — безопаснее для совместимости.

7. Типы медиа

Тип Что означает
all (по умолчанию)Все устройства
screenЭкраны (монитор, телефон, планшет)
printПечать
speechScreen reader'ы
 
@media screen and (min-width: 768px) {
    /* только на экранах от 768px */
}

@media print {
    /* только при печати */
    .no-print { display: none; }
}
Для веба обычно screen не указывают — это значение по умолчанию. Просто @media (min-width: 768px).

8. Другие медиа-функции

Функция Что проверяет
width / heightШирина / высота окна
orientationportrait / landscape
prefers-color-schemelight / dark — тёмная тема
prefers-reduced-motionПользователь отключил анимации
hoverhover / none — есть ли мышь
pointerfine / coarse — точность указателя

Пример: тёмная тема

@media (prefers-color-scheme: dark) {
    body {
        background: #1a1a1a;
        color: #f0f0f0;
    }
}
Полезно: если у пользователя включена тёмная тема в системе — сайт автоматически станет тёмным. Это отличный UX.

9. Где писать media queries

В одном файле (рядом с правилами)

.card {
    padding: 16px;
}

@media (min-width: 768px) {
    .card {
        padding: 24px;
    }
}

В отдельном файле

<link rel="stylesheet" href="style.css">
<link rel="stylesheet" href="responsive.css" media="(min-width: 768px)">
Рекомендую — в одном файле, рядом с правилами. Так проще видеть, как элемент меняется.

10. Практика: адаптивная сетка

*, *::before, *::after {
    box-sizing: border-box;
}

.cards {
    display: grid;
    grid-template-columns: 1fr;   /* мобильный — 1 колонка */
    gap: 16px;
    padding: 16px;
}

@media (min-width: 576px) {
    .cards {
        grid-template-columns: repeat(2, 1fr);
    }
}

@media (min-width: 992px) {
    .cards {
        grid-template-columns: repeat(3, 1fr);
        gap: 24px;
        padding: 32px;
    }
}

@media (min-width: 1200px) {
    .cards {
        grid-template-columns: repeat(4, 1fr);
    }
}

11. Практика: скрыть/показать

.desktop-only {
    display: none;
}

@media (min-width: 992px) {
    .desktop-only {
        display: block;
    }
}

.mobile-only {
    display: block;
}

@media (min-width: 992px) {
    .mobile-only {
        display: none;
    }
}
Осторожно: скрывать важный контент на мобильных — плохо для SEO. Прячь только «дублирующий» контент (например, большое меню заменяется на бургер).

12. Частые ошибки

Ошибка Почему плохо
Забыть meta viewport Media queries не работают на мобильных
Использовать max-width для mobile-first Путаница. Для mobile-first — min-width
Писать @media screen всегда Не нужно — screen по умолчанию
Слишком много брейкпоинтов Сложно поддерживать
Использовать px для media queries Лучше em — уважает настройки пользователя (16px = 1em)
Скрывать важный контент Плохо для SEO

13. Что запомнить из урока

  • @media — условие для применения стилей.
  • min-width — «от и больше». Mobile-first.
  • max-width — «до и меньше». Desktop-first.
  • and — «и» (диапазон). or (запятая) — «или».
  • Новый синтаксис: (768px = width = 1024px).
  • Типы: screen, print. screen — по умолчанию.
  • prefers-color-scheme — тёмная тема.
  • prefers-reduced-motion — отключить анимации.
  • Mobile-first — min-width. Рекомендую.
  • Не скрывай важный контент на мобильных.

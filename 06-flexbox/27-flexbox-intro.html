CSS Урок 27. Flexbox — введение

1. Что такое Flexbox

Flexbox (Flexible Box Layout) — это способ раскладки, который выравнивает элементы в ряд или колонку и распределяет свободное место между ними.

Это одномерная раскладка: элементы выстраиваются по одной оси — горизонтально или вертикально.

Что решает Flexbox Пример
Горизонтальное менюСсылки в ряд
Карточки в рядГалерея, товары
ЦентрированиеПо X и Y
Распределение местаКнопки по краям
Прижатие к краюЛоготип слева, меню справа
До Flexbox это делали через float, inline-block, таблицы и «костыли». Flexbox — проще и мощнее.

2. Два участника: контейнер и элементы

Flexbox работает на двух уровнях:

Роль Что делает
Flex-контейнер Родитель с display: flex. Управляет раскладкой.
Flex-элементы Дети контейнера. Подчиняются правилам. 
.container {
    display: flex;   /* ← контейнер */
}

/* Дети .container автоматически становятся flex-элементами */
display: flex — дети выстроились в ряд:
Элемент 1
Элемент 2
Элемент 3
Ключевой момент: display: flex ставится на родителя. Дети становятся flex-элементами автоматически — им ничего не нужно.

3. Что происходит при display: flex

Когда ты пишешь display: flex на контейнере:

  1. Дети выстраиваются в ряд (по умолчанию — горизонтально).
  2. Дети сжимаются или растягиваются, чтобы влезть.
  3. Высота контейнера = высота самого высокого ребёнка.
  4. Отступы и ширина пересчитываются по-новому.
Без flex — блоки друг под другом:

Элемент 3
С flex — в ряд:

4. Главная ось и поперечная ось

Flexbox использует две оси. Понимание этого — ключ к Flexbox.

Ось Что это По умолчанию
Главная (main axis) Вдоль неё выстраиваются элементы Горизонтально (слева → направо)
Поперечная (cross axis) Перпендикулярна главной Вертикально (сверху → вниз)
Оси (по умолчанию):
1
2
3

Что зависит от осей

По главной оси По поперечной оси
justify-content align-items
Распределение элементов Выравнивание элементов
Главная мысль:
  • justify-content — по главной оси.
  • align-items — по поперечной оси.
Если поменять направление (flex-direction: column) — оси меняются местами.

5. flex-direction — направление

Меняет направление главной оси.

Значение Что означает
row (по умолчанию)Слева направо
row-reverseСправа налево
columnСверху вниз
column-reverseСнизу вверх
 
.container {
    display: flex;
    flex-direction: column;
}
flex-direction: column — вертикально:
Элемент 1
Элемент 2
Элемент 3

Как меняются оси

flex-direction Главная ось Поперечная ось
row→ горизонталь↕ вертикаль
column↕ вертикаль→ горизонталь
Частая ошибка: думать, что justify-content — всегда «горизонтально». Нет! Он по главной оси. Если flex-direction: column — justify-content будет выравнивать по вертикали.

6. Что можно делать с flex-элементами

Flex-элементы можно:

  • Выравнивать — по главной и поперечной оси.
  • Распределять — свободное место между ними.
  • Менять размер — растягивать, сжимать.
  • Менять порядок — через order.
  • Переносить — на новую строку.

Всё это — в следующих уроках.

7. Что display: flex НЕ делает

  • Не делает сетку — это одномерная раскладка. Для сетки — Grid.
  • Не работает на детях — только на родителе.
  • Не отменяет float у детей (игнорирует).
  • Не влияет на внуков — только на прямых детей.

Только прямые дети

<div class="flex-container">
    <div>Элемент 1</div>    <!-- flex-элемент -->
    <div>
        <div>Внук</div>      <!-- НЕ flex-элемент -->
    </div>
</div>
Внуки — не flex-элементы. Если нужен flex внутри — сделай внутренний контейнер display: flex.

8. Префиксы (историческое)

Раньше Flexbox требовал префиксы: 

/* Старый код (2012) */
.container {
    display: -webkit-box;
    display: -webkit-flex;
    display: -ms-flexbox;
    display: flex;
}
Сейчас не нужно: все современные браузеры поддерживают display: flex без префиксов. Префиксы — только для IE 10+. Не используй — это legacy.

13. Частые ошибки

Ошибка Почему плохо
display: flex на детях Flex ставится на родителя, не на детей
Думать, что justify-content — всегда горизонтально Зависит от flex-direction
Забыть gap и использовать margin gap проще и не даёт «лишних» отступов
Не использовать flex-wrap для многих элементов Элементы сожмутся в одну строку
Забыть min-width: 0 для длинных текстов Текст «ломает» flex-элемент
Использовать float внутри flex float игнорируется

14. Что запомнить из урока

  • Flexbox — одномерная раскладка (ряд или колонка).
  • display: flex — на родителя. Дети становятся flex-элементами автоматически.
  • Главная ось — вдоль неё выстраиваются элементы. По умолчанию горизонталь.
  • Поперечная ось — перпендикулярна главной. По умолчанию вертикаль.
  • justify-content — по главной оси.
  • align-items — по поперечной оси.
  • flex-direction — меняет направление. row (по умолчанию), column.
  • Только прямые дети — flex-элементы. Внуки — нет.
  • gap — расстояние между элементами. Лучше, чем margin.
  • Префиксы не нужны — современные браузеры поддерживают всё.

CSS Урок 31. gap и order

1. gap — расстояние между элементами

gap задаёт расстояние между flex-элементами. Работает по главной и поперечной оси. 

.container {
    display: flex;
    gap: 16px;   /* ← расстояние между элементами */
}
Свойство Что задаёт
gapИ между строками, и между колонками
row-gapТолько между строками
column-gapТолько между колонками

2. gap vs margin

До gap расстояние делали через margin у детей:

margin gap
Отступы по краям Есть (лишние) Нет
Где задавать У детей У контейнера
Синтаксис .item { margin: 8px; } .container { gap: 8px; }
Лишние отступы Да Нет 
/* Плохо: margin — лишние отступы по краям */
.container { display: flex; }
.item { margin: 8px; }

/* Хорошо: gap — без лишних отступов */
.container { display: flex; gap: 8px; }
Правило: для расстояния между flex-элементами — gap. margin — только если нужны отступы по краям.

3. order — порядок

order меняет визуальный порядок элементов, не меняя HTML.

Значение Что означает
0 (по умолчанию)Обычный порядок
1, 2, ...Больше — позже
-1Раньше всех
 
.item {
    order: 0;   /* по умолчанию */
}

.item-first {
    order: -1;   /* раньше всех */
}

.item-last {
    order: 1;    /* позже всех */
}

Пример: order

order: у второго -1, у третьего 1:
1
2 (order -1)
3
4 (order 1)

Визуальный порядок: 2 → 1 → 3 → 4. Но в HTML — 1, 2, 3, 4.

Важно: order меняет только визуальный порядок. Screen reader читает в HTML-порядке. Для доступности — не меняй порядок через order без причины.

8. order + flex-wrap

order работает и при переносе — элементы сортируются по order внутри контейнера. 

.container {
    display: flex;
    flex-wrap: wrap;
}

.item {
    order: 0;
}

.item-important {
    order: -1;   /* ← первым, даже если в HTML последний */
}
Важная карточка (order: -1) — первая:

10. Частые ошибки

Ошибка Почему плохо
Использовать margin вместо gap Лишние отступы по краям. gap — лучше
Ожидать, что order изменит HTML-порядок Меняется только визуальный. Screen reader читает по HTML
order без причины Плохо для доступности
gap без display: flex Не работает
Забыть flex-wrap при многих элементах Сожмутся в одну строку
gap с margin вместе Двойные отступы

11. Что запомнить из урока

  • gap — расстояние между flex-элементами. Работает по главной и поперечной оси.
  • row-gap и column-gap — отдельно.
  • gap лучше margin — нет лишних отступов по краям.
  • order — меняет визуальный порядок.
  • order: -1 — первым, 1 — позже.
  • order не меняет HTML — screen reader читает по HTML.
  • row-reverse — простой обратный порядок для всего контейнера.
  • gap работает в column — вертикальное расстояние.

CSS Урок 14. Отступы

1. margin vs padding — в чём разница

Оба задают отступы, но в разных местах:

padding margin
Где Внутри — между content и border Снаружи — между border и другими элементами
Входит в размер блока Да (при content-box) Нет
Фон Закрашивается Прозрачный
Может быть отрицательным Нет Да
Схлопывается Нет Да (вертикально)
При клике Входит в область клика Не входит — клик проходит мимо
Аналогия. Представь коробку с подарком:
  • Content — сам подарок.
  • Padding — поролон внутри (часть коробки).
  • Border — стенки коробки.
  • Margin — расстояние между коробками на полке.

2. Живое сравнение

Один блок с padding, другой с margin:

padding: 24px

border + padding + content
content

margin: 24px

border + content

Padding — увеличивает блок изнутри, фон закрашивается. Margin — отодвигает блок от соседей, фон прозрачный.

3. Shorthand padding

.box {
    padding: 20px;                    /* все стороны */
    padding: 10px 20px;               /* верх/низ 10, право/лево 20 */
    padding: 10px 20px 30px;          /* верх 10, право/лево 20, низ 30 */
    padding: 10px 20px 30px 40px;     /* верх 10, право 20, низ 30, лево 40 */
}

/* Отдельные стороны */
.box {
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 30px;
    padding-left: 40px;
}

Порядок: верх → право → низ → лево (по часовой).

4. Shorthand margin

.box {
    margin: 20px;                    /* все стороны */
    margin: 10px 20px;               /* верх/низ 10, право/лево 20 */
    margin: 10px 20px 30px;          /* верх 10, право/лево 20, низ 30 */
    margin: 10px 20px 30px 40px;     /* верх 10, право 20, низ 30, лево 40 */
}

Тот же порядок, что в padding.

5. margin: 0 auto — центрирование

Классический способ центрировать блок по горизонтали. 

.box {
    width: 300px;
    margin: 0 auto;
}
margin: 0 auto:
width: 200px, margin: 0 auto
Как это работает: auto в horizontal margin означает «взять оставшееся место и разделить пополам». Работает, только если у блока задана width (иначе он и так занимает всю ширину).

6. Отрицательный margin

margin может быть отрицательным — элемент «наезжает» на соседей. Полезно для наложения блоков. 

.pull-up {
    margin-top: -20px;
}

.overlap {
    margin-left: -10px;
}
Отрицательный margin-top:
первый блок
margin-top: -16px

7. Схлопывание margin (margin collapse)

Главная странность CSS. Вертикальные margin двух соседних блоков объединяются, а не складываются. 

.first {
    margin-bottom: 30px;
}

.second {
    margin-top: 20px;
}

/* Расстояние между ними = 30px (max), а не 50px! */
margin-bottom: 30px + margin-top: 20px = 30px:
первый: margin-bottom: 30px
второй: margin-top: 20px

Фактическое расстояние между блоками = 30px (максимум из двух), а не 50px.

Когда margin схлопываются

  • Вертикальные margin соседних блоков.
  • Родитель и первый/последний ребёнок (margin «протекает» наружу).
  • Пустые блоки (без содержимого и border/padding).

Когда НЕ схлопываются

  • Горизонтальные margin (left/right) — никогда.
  • Если между блоками есть border или padding.
  • Если между блоками есть содержимое (текст, другой элемент).
  • Если родитель — Flexbox или Grid.
  • Если у родителя overflow: hidden или display: flow-root.

Как бороться со схлопыванием

Способ Как
Использовать padding Вместо margin
Добавить border Даже прозрачный — отменяет схлопывание
display: flex На родителе — отменяет схлопывание
display: flow-root Современный способ — «создаёт BFC»
overflow: hidden Тоже создаёт BFC
gap вместо margin В Flexbox и Grid — gap не схлопывается
Современный подход: для сеток используй gap в Flexbox/Grid. Он не схлопывается и проще в управлении.

8. Схлопывание родителя и ребёнка

Ещё одна проблема: margin-top первого ребёнка «протекает» через родителя, если у родителя нет border, padding или overflow. 

.parent {
    background: #f0f0f0;
    /* нет border, padding, overflow */
}

.child {
    margin-top: 30px;   /* ← "вытечет" наружу родителя */
}

Решение

.parent {
    display: flow-root;   /* ← современный способ */
    /* или */
    overflow: hidden;
    /* или */
    padding-top: 1px;     /* костыль */
    /* или */
    border-top: 1px solid transparent;
}
Демо: margin-top ребёнка «вытекает» из родителя:
margin-top: 30px — «вытек» наверх
Правило: если margin-top ребёнка «не работает» — проверь, не «протекает» ли он через родителя. Добавь родителю display: flow-root.

9. Padding и клики

Padding входит в область клика, margin — нет. 

.btn {
    padding: 20px;
    margin: 20px;
}

Клик по padding сработает (это часть кнопки). Клик по margin — нет (это расстояние до кнопки).

Проверь (клик по padding срабатывает, по margin — нет):
← клик по padding = клик по кнопке

10. Практика: карточка

*, *::before, *::after {
    box-sizing: border-box;
}

.card {
    width: 300px;
    padding: 24px;          /* внутренний отступ */
    border: 1px solid #ddd;
    border-radius: 12px;
    margin-bottom: 16px;    /* отступ между карточками */
    background: #fff;
}

.card h3 {
    margin: 0 0 12px 0;     /* отступ между заголовком и текстом */
    color: #1565c0;
}

.card p {
    margin: 0;               /* убираем стандартный margin у параграфа */
    color: #666;
}
Карточки с отступами:

Заголовок

padding: 24px внутри. margin-bottom: 16px снаружи.

Вторая карточка

margin-bottom: 16px между карточками.

11. Практика: сетка на gap

Вместо margin у элементов — gap у родителя. Не схлопывается, проще в управлении. 

.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 16px;   /* ← вместо margin у элементов */
}

.card {
    padding: 24px;
    background: #fff;
    border-radius: 12px;
}

12. Частые ошибки

Ошибка Почему плохо
Путать margin и padding Margin снаружи (прозрачный), padding внутри (закрашен)
padding: -10px Невалидно. Отрицательный — только margin
Удивляться, что margin не работает Схлопывание. См. раздел 7
margin: 0 auto без width Не центрирует — блок и так всю ширину
Использовать margin для сеток Лучше gap в Flexbox/Grid
Думать, что margin входит в размер Нет. Margin — снаружи
Ставить margin всем элементам Лучше gap на родителе или margin только с одной стороны

13. Что запомнить из урока

  • padding — внутри, закрашивается фоном, входит в размер (при content-box).
  • margin — снаружи, прозрачный, не входит в размер.
  • padding не отрицательный, margin — может.
  • Порядок shorthand: верх → право → низ → лево.
  • margin: 0 auto центрирует блок (с width).
  • Схлопывание margin — вертикальные margin соседей объединяются по максимуму.
  • Горизонтальные margin не схлопываются.
  • Margin «протекает» через родителя без border/padding/overflow.
  • Решение: display: flow-root, overflow: hidden, gap вместо margin.
  • Padding входит в клик, margin — нет.
  • Для сеток — gap вместо margin у элементов.

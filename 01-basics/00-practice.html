Задания

Задание 1. Подключение CSS лёгкое

В этом файле CSS уже подключён — через тег <style> в <head>. Но в реальном проекте лучше выносить CSS в отдельный файл.

Что сделать:

  1. Создай рядом с этим файлом файл practice-style.css.
  2. Перенеси туда все свои стили (из блока «ТВОИ СТИЛИ»).
  3. Удали блок <style> со своими стилями из HTML.
  4. Подключи файл через <link rel="stylesheet" href="practice-style.css"> в <head>.
  5. Обнови страницу — стили должны остаться.
Проверка: открой DevTools (F12) → вкладка Network → обнови страницу. Должен появиться файл practice-style.css со статусом 200.

Задание 2. Базовые стили лёгкое

Что сделать:

  1. Сделай фон body светло-серым: #f0f0f0.
  2. Покрась h1.page-title в #1565c0.
  3. Покрась все p в #333.
Подсказка: используй селектор по тегу для p, по классу — для .page-title. body — селектор по тегу.

Задание 3. Класс и id лёгкое

В рабочей зоне есть параграф с классом .highlight и параграф с id special-p.

Что сделать:

  1. Сделай у .highlight жёлтый фон (#fff8e1) и отступ 8px.
  2. Сделай у #special-p синий цвет (#1565c0) и жирный шрифт (font-weight: 700).
Подсказка: класс — .highlight, id — #special-p. Это разные селекторы с разной специфичностью.

Задание 4. Потомок и ребёнок среднее

В рабочей зоне есть два .card. В первом — параграф-потомок (вложенный в div внутри .card).

Что сделать:

  1. Стилизуй всех потомков .card p — цвет #666.
  2. Стилизуй только прямых детей .card > p — левая граница 3px solid #1565c0 и отступ слева 8px.
  3. Проверь: во втором .card параграф прямой — граница есть. В первом — только у прямого, у вложенного в div — нет.
Подсказка: .card p — все потомки (дети, внуки, ...). .card > p — только прямые дети. Специфичность у них одинаковая, но > ограничивает выбор.

Задание 5. Ссылки и соседи среднее

Что сделать:

  1. Убери подчёркивание у ссылки (text-decoration: none).
  2. Покрась ссылку в #1565c0.
  3. Сделай h2 + p (параграф сразу после h2) курсивом и с левой границей 3px solid #ffb300.
  4. Проверь: второй параграф после h2 (не сосед) — не должен получить курсив.
Подсказка: h2 + p — только первый p сразу после h2.

Задание 6. Специфичность среднее

Представь, что у тебя есть правило p { color: red; } и .highlight { color: blue; }. Оба применяются к параграфу с классом .highlight.

Что сделать:

  1. Напиши два правила: p (цвет красный) и .highlight (цвет синий).
  2. Сделай так, чтобы .highlight победил (параграф с классом — синий).
  3. Теперь напиши третье правило #special-p (цвет зелёный).
  4. Проверь: если у элемента #special-p есть и класс .highlight, и id — какой цвет победит? (ответ: id).
Подсказка: специфичность: p = 0,0,0,1; .highlight = 0,0,1,0; #special-p = 0,1,0,0. Id всегда выше класса и тега.

Задание 7. Наследование среднее

Наследование — это когда свойства «переходят» от родителя к детям. color наследуется, border — нет.

Что сделать:

  1. Задай .card color: #1565c0.
  2. Проверь: все p внутри .card — синие (унаследовали).
  3. Добавь .card ещё border: 2px solid #43a047.
  4. Проверь: у p внутри .card — нет своей рамки (border не наследуется).
Подсказка: если бы border наследовался, у каждого p была бы своя рамка — выглядело бы странно. Поэтому он не наследуется.

Задание 8. Каскад и порядок сложное

Если два правила с одинаковой специфичностью задают одно свойство — побеждает то, что ниже.

Что сделать:

  1. Напиши два правила .highlight: первое — фон красный (#ffcdd2), второе — фон жёлтый (#fff8e1).
  2. Проверь: параграф с классом .highlight должен стать жёлтым (потому что второе правило ниже).
  3. Поменяй порядок правил местами — проверь, что теперь красный.
  4. Верни жёлтый (это правильный вариант).
Подсказка: это правило каскада — при равной специфичности побеждает последнее правило. Порядок в CSS имеет значение.

Задание 9. Комбинирование селекторов сложное

Что сделать:

  1. Стилизуй только прямых детей .card > p — цвет #333.
  2. Стилизуй только параграфы внутри вложенного div: .card div p — цвет #999, курсив.
  3. Стилизуй #special-p — красный, жирный.
  4. Проверь: параграф с id special-p — какой цвет? (должен быть красный, id победил).
  5. Добавь !important к .card p (цвет #666). Проверь: теперь все p внутри .card — серые, даже с id? (да, !important перебивает всё).
  6. Убери !important — верни нормальную специфичность.
Подсказка: это плохая практика — использовать !important для переопределения. Но важно понимать, как это работает. В реальном коде !important — крайняя мера.

🎯 Финальный мини-проект: страница-визитка

Собери отдельную страницу visitka.html (или используй рабочую зону) — простую визитку.

Что должно быть:

  • Шапка с именем (<h1>).
  • Абзац «О себе» — 2–3 предложения.
  • Список навыков (<ul>) — минимум 3 пункта.
  • Ссылка на email через mailto:.
  • Разделы — заголовки <h2>.

Что использовать (из блока 1):

  • Подключение CSS через <link> (отдельный файл).
  • Селекторы по тегу, классу, id.
  • Наследование: задай color и font-family для body.
  • Специфичность: проверь, что твои стили применяются (DevTools).
  • Каскад: не дублируй правила без причины.

Проверка:

  • Открой в браузере — страница читаемая.
  • DevTools → Network: style.css загружается (200).
  • DevTools → Elements: стили применяются, ничего не «перебито» неожиданно.
  • Валидатор validator.w3.org — нет ошибок HTML.

Бонус: если хочешь, добавь hover для ссылки (измени цвет при наведении) — это уже забегание вперёд, но полезно.

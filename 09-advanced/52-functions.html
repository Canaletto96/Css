CSS Урок 52. Функции

1. Что такое CSS-функции

Функции в CSS — это вычисления прямо в значениях. Позволяют смешивать единицы, ограничивать размеры, использовать переменные.

Функция Что делает
calc()Вычисления (сложение, вычитание, умножение, деление)
clamp(min, val, max)Зажать значение в диапазон
min(a, b)Меньшее из двух
max(a, b)Большее из двух
var(--name)Использовать CSS-переменную

2. calc() — вычисления

Позволяет смешивать единицы и делать вычисления: 

width: calc(100% - 80px);
height: calc(100vh - 60px);
font-size: calc(16px + 1vw);
padding: calc(1rem + 4px);
width: calc(100% - 80px):
calc(100% - 80px)

Операции в calc()

Операция Пример
Сложениеcalc(100% + 20px)
Вычитаниеcalc(100% - 20px)
Умножениеcalc(10px * 2)
Делениеcalc(100px / 2)
Пробелы обязательны вокруг + и -: calc(100% - 20px) ✅, calc(100%-20px) ❌. Вокруг * и / — не обязательны.

Практика: контейнер

.container {
    width: calc(100% - 40px);
    max-width: 1200px;
    margin: 0 auto;
}
Классический приём: width: calc(100% - 40px) — контейнер с отступами по 20px с каждой стороны.

Практика: высота на весь экран минус шапка

.main {
    height: calc(100vh - 60px);   /* 60px — высота шапки */
}

3. clamp() — зажать в диапазон

clamp(min, preferred, max) — значение не меньше min, не больше max, но адаптируется между ними. 

font-size: clamp(16px, 4vw, 32px);
/* не меньше 16px, не больше 32px, но 4vw между ними */
clamp(16px, 4vw, 32px) — сузь окно:
Адаптивный текст
Условие Размер
4vw < 16px16px (min)
16px ≤ 4vw ≤ 32px4vw (адаптив)
4vw > 32px32px (max)
Главное преимущество: без media queries. Одна строка — и размер адаптируется. Рекомендую для заголовков.

Практика: адаптивные заголовки

h1 {
    font-size: clamp(24px, 5vw, 48px);
}

h2 {
    font-size: clamp(20px, 3vw, 32px);
}

p {
    font-size: clamp(14px, 2vw, 18px);
}

Практика: адаптивные отступы

.section {
    padding: clamp(16px, 4vw, 64px);
}

4. min() — меньшее

min(a, b) — берёт меньшее из двух значений. 

width: min(100%, 400px);
/* блок не шире 400px и не шире 100% родителя */
width: min(100%, 400px) — сузь окно:
min(100%, 400px)
min(100%, 400px) — лучше, чем width: 400px. Блок не вылезет за экран.

Практика: контейнер

.container {
    width: min(100% - 32px, 1200px);
    margin: 0 auto;
}

5. max() — большее

max(a, b) — берёт большее из двух значений. 

width: max(200px, 50%);
/* блок не меньше 200px и не меньше 50% родителя */
width: max(200px, 50%) — сузь окно:
max(200px, 50%)

Практика: минимальная ширина

.sidebar {
    width: max(250px, 20%);
    /* сайдбар не меньше 250px */
}

6. var() — переменные

var(--name) — использовать CSS-переменную. Можно комбинировать с другими функциями. 

:root {
    --space: 16px;
}

.box {
    padding: calc(var(--space) * 2);
    width: min(var(--space) * 30, 100%);
}
calc(var(--space) * 2):
padding: calc(var(--space) * 2) = 32px

7. Комбинирование функций

Функции можно вкладывать друг в друга: 

/* clamp + calc */
font-size: clamp(16px, calc(14px + 1vw), 24px);

/* min + var */
width: min(var(--container), 100%);

/* clamp + var */
padding: clamp(var(--space-sm), 4vw, var(--space-lg));

/* max + min */
width: max(200px, min(50%, 400px));

8. Практика: адаптивная типографика

:root {
    --font-min: 16px;
    --font-max: 24px;
    --font-fluid: 2vw;
}

body {
    font-size: clamp(var(--font-min), var(--font-fluid), var(--font-max));
}

h1 {
    font-size: clamp(24px, 5vw, 48px);
    line-height: 1.1;
}

h2 {
    font-size: clamp(20px, 3vw, 32px);
    line-height: 1.2;
}

9. Практика: контейнер

.container {
    width: min(100% - 32px, 1200px);
    margin: 0 auto;
    padding: clamp(16px, 4vw, 32px);
}
Классический контейнер: не шире 1200px, не вылезает за экран (отступ 16px), отступы внутри адаптивные.

12. Частые ошибки

Ошибка Почему плохо
calc(100%-20px) без пробелов Не работает. Нужны пробелы вокруг - и +
clamp() без min или max Нужны все три значения
min(100%, 400px) vs max(100%, 400px) min — меньшее, max — большее. Не путай
width: 100vw вместо 100% Скроллбар → горизонтальная прокрутка
clamp() с одинаковыми min и max Не адаптируется — фиксированный размер
Слишком сложные calc() Сложно читать. Лучше — CSS-переменные

13. Что запомнить из урока

  • calc() — вычисления. Смешивает единицы. Пробелы вокруг + и -.
  • clamp(min, val, max) — зажать в диапазон. Адаптив без media queries.
  • min(a, b) — меньшее. Для «не больше X».
  • max(a, b) — большее. Для «не меньше X».
  • var(--name) — переменная. Комбинируется с другими функциями.
  • Для шрифтов — clamp(16px, 4vw, 32px).
  • Для контейнера — min(100% - 32px, 1200px).
  • Функции можно вкладывать — clamp(16px, calc(...), 24px).

CSS Урок 42. Относительные единицы

1. Зачем относительные единицы

Фиксированные px не адаптируются. Относительные единицы подстраиваются под:

  • Родителя — %, em.
  • Корня — rem.
  • Окна — vw, vh.
  • Контента — ch.

2. % — проценты

Считается от родителя.

.parent {
    width: 400px;
}

.child {
    width: 50%;       /* 200px (50% от 400px) */
    padding: 10%;     /* 40px (10% от ширины родителя!) */
}
Родитель 400px, ребёнок 50%:
50% (200px)
Важно: padding и margin в процентах считаются от ширины родителя, даже для padding-top!

3. rem — от корня

1rem = font-size корня (<html>), обычно 16px. Не зависит от родителя. 

html {
    font-size: 16px;
}

.parent {
    font-size: 24px;
}

.child {
    font-size: 1.5rem;   /* 24px — не зависит от родителя! */
    padding: 2rem;        /* 32px */
}
rem не зависит от вложенности:
Родитель: 24px
1.5rem = 24px (не зависит от родителя)
Рекомендую: для шрифтов и отступов — rem. Предсказуемый и доступный (уважает настройки пользователя).

4. vw и vh — от окна

1vw = 1% ширины окна.
1vh = 1% высоты окна. 

.full-screen {
    width: 100vw;      /* вся ширина окна */
    height: 100vh;     /* вся высота окна */
}

.half {
    width: 50vw;       /* половина ширины */
}
30vh (сузь окно по высоте):
30vh
Осторожно с 100vw: на некоторых системах 100vw шире окна на ширину скроллбара → горизонтальная прокрутка. Используй width: 100% вместо 100vw.

Новые единицы: dvh, svh, lvh

На мобильных 100vh может «ломаться» из-за адресной строки браузера. Решение — новые единицы:

Единица Что означает
dvhDynamic viewport — подстраивается под адресную строку
svhSmall viewport — минимальная высота (без адресной строки)
lvhLarge viewport — максимальная высота (с адресной строкой)
Рекомендую: 100dvh вместо 100vh — лучше для мобильных.

5. clamp() — «зажать» в диапазон

clamp(min, preferred, max) — значение не меньше min, не больше max, но адаптируется между ними. 

font-size: clamp(16px, 4vw, 32px);
/* не меньше 16px, не больше 32px, но 4vw между ними */
font-size: clamp(16px, 4vw, 32px) — сузь окно:
Адаптивный текст
Условие Размер
4vw < 16px16px (min)
16px ≤ 4vw ≤ 32px4vw (адаптив)
4vw > 32px32px (max)
Главное преимущество: без media queries. Одна строка — и размер адаптируется. Рекомендую для заголовков.

6. min() и max()

width: min(100%, 600px);   /* не больше 600px, но не шире 100% */
width: max(300px, 50%);     /* не меньше 300px, но не меньше 50% */
Функция Что делает
min(a, b)Берёт меньшее из a и b
max(a, b)Берёт большее из a и b
clamp(min, val, max)= max(min, min(val, max))
width: min(100%, 400px) — сузь окно:
min(100%, 400px)
min(100%, 600px) — лучше, чем width: 600px. Блок не вылезет за экран.

8. Практика: адаптивный заголовок

h1 {
    font-size: clamp(24px, 5vw, 48px);
}

h2 {
    font-size: clamp(20px, 3vw, 32px);
}

p {
    font-size: clamp(14px, 2vw, 18px);
}

9. Практика: адаптивный контейнер

.container {
    width: min(100% - 32px, 1200px);
    margin: 0 auto;
}
width: min(100% - 32px, 1200px):
Контейнер
Классический приём: width: min(100% - 32px, 1200px) — контейнер не шире 1200px и не вылезает за экран (отступ 16px с каждой стороны).

10. Практика: hero-блок

.hero {
    display: flex;
    align-items: center;
    justify-content: center;
    min-height: 100dvh;
    padding: clamp(16px, 4vw, 64px);
    text-align: center;
}

.hero h1 {
    font-size: clamp(32px, 6vw, 64px);
    margin: 0 0 clamp(8px, 2vw, 24px) 0;
}

.hero p {
    font-size: clamp(16px, 2.5vw, 24px);
}

11. Частые ошибки

Ошибка Почему плохо
width: 100vw на странице со скроллом Горизонтальная прокрутка
font-size в px Не адаптируется, плохо для доступности
100vh на мобильных Ломается из-за адресной строки. Используй 100dvh
clamp() без min и max Не работает — нужны все три значения
Слишком мелкий текст через vw На мобильных 2vw может быть < 12px. Используй clamp

12. Что запомнить из урока

  • % — от родителя. Для ширины.
  • rem — от корня. Для шрифтов и отступов.
  • vw/vh — от окна. Для полноэкранных блоков.
  • dvh — лучше для мобильных.
  • clamp(min, val, max) — адаптив без media queries.
  • min(a, b) — меньшее. Для контейнеров.
  • max(a, b) — большее.
  • width: min(100% - 32px, 1200px) — классический контейнер.
  • clamp для заголовков — clamp(24px, 5vw, 48px).
  • Осторожно с 100vw — может дать скролл.

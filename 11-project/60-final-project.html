4. Что использовать из курса

Основы

  • Сброс — modern reset (урок 53).
  • Переменные — :root { --primary: ... } (урок 51).
  • Типографика — clamp() для заголовков (урок 52).

Компоненты

  • Шапка — display: flex; justify-content: space-between (урок 32).
  • Hero — display: flex; align-items: center; justify-content: center (урок 29).
  • Карточки — display: grid; repeat(auto-fit, minmax(...)) (урок 44).
  • Подвал — display: flex; flex-direction: column (урок 32).

Адаптивность

  • Mobile-first — базовые стили для мобильных, @media (min-width: ...) (урок 41).
  • clamp() — для шрифтов и отступов (урок 52).
  • auto-fit — для сеток (урок 44).

Современное

  • Nesting — вложенность (урок 59).
  • :has() — родитель по ребёнку (урок 59).
  • Container Queries — адаптив по контейнеру (урок 45).

7. Чек-лист перед публикацией

  • Каркас: DOCTYPE, html lang, head с charset и viewport
  • Title — до 60 символов, уникальный
  • Meta description — 120–160 символов
  • Один h1 на страницу
  • Иерархия заголовков: h1 → h2 → h3 без пропусков
  • Семантические теги: header, nav, main, section, article, footer
  • Сброс стилей (modern reset)
  • box-sizing: border-box
  • CSS-переменные в :root
  • BEM-нейминг классов
  • Адаптивность: mobile-first, @media (min-width: ...)
  • clamp() для шрифтов
  • repeat(auto-fit, minmax(...)) для сеток
  • Hover-эффекты для интерактивных элементов
  • transition для плавности
  • Все <img> с alt
  • Все <img> с max-width: 100%
  • Все ссылки с осмысленным текстом
  • Все id уникальны
  • Все теги закрыты
  • Нет ошибок в W3C Validator
  • DevTools → Console: нет красных ошибок
  • DevTools → Network: нет 404
  • Lighthouse: хорошие оценки (зелёные)
  • Работает на телефоне (DevTools → режим устройства)
  • Работает с клавиатуры (Tab, Enter)

10. Финальное задание

Собери свой проект.

  1. Создай папку my-site/.
  2. Напиши index.html — с шапкой, hero, карточками, подвалом.
  3. Напиши CSS — с reset, переменными, BEM, адаптивом.
  4. Пройди чек-лист из раздела 7.
  5. Проверь валидатором (validator.w3.org).
  6. Проверь в DevTools (F12): Console, Network, Lighthouse.
  7. Проверь на телефоне (DevTools → режим устройства).
  8. Загрузи на GitHub Pages или Netlify.
  9. Получи ссылку, открой на телефоне.
  10. Если всё работает — ты прошёл курс CSS! 🎉

Дополнительно (по желанию):

  • Добавь вторую страницу (about.html) с общими стилями.
  • Сделай тёмную тему через prefers-color-scheme.
  • Добавь анимации (@keyframes).
  • Подключи WebP-картинки с fallback.
  • Используй :has() для карточек с картинками.

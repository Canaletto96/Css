CSS Урок 1. Что такое CSS

1. Что такое CSS

CSS (Cascading Style Sheets — «каскадные таблицы стилей») — это язык оформления HTML-документов. Он отвечает за то, как выглядит страница: цвета, шрифты, отступы, расположение элементов.

Аналогия. HTML — это каркас здания (стены, двери, окна). CSS — это отделка (обои, плитка, цвет стен, мебель). Без CSS дом стоит, но выглядит «серым».

HTML vs CSS

HTML CSS
Отвечает за Структуру и смысл Внешний вид
Пример <h1>Заголовок</h1> h1 { color: blue; }
Если убрать Страница исчезнет Страница станет «голой»

2. Как выглядит сайт без CSS

Браузер применяет к HTML стили по умолчанию (user agent stylesheet):

  • Заголовки — жирные, разного размера.
  • Ссылки — синие с подчёркиванием.
  • Параграфы — с отступами сверху и снизу.
  • Списки — с точками и отступами.

Но это минимум. Цвета, шрифты, сетки, кнопки — всё это CSS.

3. Как браузер применяет CSS

Когда ты открываешь HTML-файл, браузер:

  1. Читает HTML и строит DOM-дерево — структуру страницы.
  2. Читает CSS и строит CSSOM — модель стилей.
  3. Объединяет их в render tree — что и как рисовать.
  4. Рисует страницу на экране.
DOM (Document Object Model) — структура HTML.
CSSOM (CSS Object Model) — структура стилей.
Render tree — итоговая модель «что и как рисовать».

4. Синтаксис CSS

CSS-правило состоит из трёх частей:

селектор {
    свойство: значение;
}

Пример:

h1 {
    color: blue;
    font-size: 32px;
}

Разбор:

Часть Что это В примере
Селектор Кого стилизуем h1
Свойство Что меняем color, font-size
Значение На что меняем blue, 32px
Фигурные скобки Границы правила { }
Точка с запятой Конец объявления ;
Точка с запятой — обязательна после каждого свойства, кроме последнего (но лучше ставить всегда). Забыл — следующее свойство не применится.

5. Три способа подключить CSS

Способ 1: внешний файл (рекомендуется)

CSS в отдельном файле .css, подключается через <link>:

<!-- В <head> HTML -->
<link rel="stylesheet" href="style.css">
/* style.css */
h1 {
    color: blue;
}

Плюсы: один файл для всех страниц, кешируется, чище HTML.

Способ 2: встроенные стили (<style>)

CSS прямо в HTML, внутри <head>:

<head>
    <style>
        h1 {
            color: blue;
        }
    </style>
</head>

Плюсы: не нужен отдельный файл.
Минусы: не кешируется, смешивается с HTML, не работает для нескольких страниц.

Способ 3: инлайн-стили (style="")

CSS прямо в теге через атрибут style:

<h1 style="color: blue;">Заголовок</h1>

Плюсы: быстро, для теста.
Минусы: не кешируется, сложно поддерживать, смешивает всё.

Инлайн-стиль в действии:

Этот текст — синий, жирный, 20px (через style="")

Сравнение

Внешний файл <style> style=""
Переиспользование ✅ Все страницы ❌ Только эта ❌ Только тег
Кеширование ✅ Да ❌ Нет ❌ Нет
Чистота HTML ✅ Да ⚠️ Смешивается ❌ Очень смешивается
Когда использовать Основной способ Прототипы, письма Тест, JS-динамика
Правило: 99% CSS — во внешнем файле. <style> — для прототипов и email-писем. style="" — только для быстрых тестов и динамики через JS.

6. Комментарии в CSS

/* Это комментарий — браузер его игнорирует */

h1 {
    color: blue;   /* синий заголовок */
    /* font-size: 32px;  — пока закомментировано */
}

Синтаксис: /* ... */. Работает на нескольких строках.

Нельзя: // (это из JavaScript, в CSS не работает). Только /* */.

7. Что можно стилизовать

CSS умеет почти всё. Базовые категории:

Категория Примеры свойств
Текст color, font-size, font-weight, line-height
Отступы margin, padding
Рамки border, border-radius, box-shadow
Фон background-color, background-image
Размеры width, height, max-width
Расположение display, position, float
Flexbox/Grid flex, grid-template-columns
Анимация transition, animation, transform

8. CSS — это каскад

Слово Cascading («каскадные») — ключевое. Если одно свойство задано несколько раз, применяется по правилам каскада:

  • Специфичность — более конкретный селектор побеждает.
  • Порядок — при равной специфичности побеждает тот, что ниже.
  • !important — принудительно перебивает всё.

Подробно — в уроке 5. Пока просто знай: CSS — это каскад, не «последний победил».

h1 { color: red; }
h1 { color: blue; }   /* ← это применится, потому что ниже */

9. Что запомнить из урока

  • CSS — язык оформления. Отвечает за внешний вид, а не за структуру.
  • HTML + CSS = каркас + отделка. Без CSS сайт «голый».
  • Синтаксис: селектор { свойство: значение; }.
  • Три способа подключения: внешний файл (рекомендуется), <style>, style="".
  • Комментарии: /* ... */. Не //.
  • Точка с запятой после каждого свойства (кроме последнего, но лучше всегда).
  • Каскад — если свойство задано несколько раз, решает специфичность и порядок.
  • CSS = 99% во внешнем файле. <style> — для прототипов, style="" — для теста.

CSS Урок 44. Адаптивные сетки

1. Проблема: сетка ломается на мобильных

Сетка repeat(3, 1fr) на мобильном (375px) даст 3 узкие колонки — некрасиво и нечитаемо. 

.cards {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    /* на мобильном — 3 колонки по 125px */
}

До auto-fit делали через media queries:

Работает, но много кода. Можно проще.

2. repeat(auto-fit, minmax()) — «магия»

Одна строка — и сетка сама подстраивается под ширину экрана. 

.cards {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    gap: 16px;
}

Что это означает:

  1. repeat(auto-fit, ...) — «создай столько колонок, сколько поместится».
  2. minmax(200px, 1fr) — каждая колонка не меньше 200px, но растягивается на свободное место.

Как это работает: браузер смотрит, сколько колонок по 200px поместится. На широком экране — 4, на планшете — 2–3, на мобильном — 1. Автоматически. Без media queries.

3. auto-fit vs auto-fill

Оба значения «создают столько колонок, сколько поместится». Но ведут себя по-разному с пустыми колонками.

auto-fit auto-fill
Пустые колонки Схлопываются Остаются
Элементы Растягиваются на всю ширину Остаются «узкими»
Когда Карточки, галереи Фиксированная сетка

4. Что выбрать в minmax()

minmax(200px, 1fr) — минимальная ширина и максимальная. От этого зависит, сколько колонок поместится.

minmax(100px, 1fr)~11~3
minmax(150px, 1fr)~7~2
minmax(200px, 1fr)~5~1
minmax(300px, 1fr)~3~1

7. Практика: сетка с «выделенной» карточкой

.cards {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    gap: 16px;
}

.card.featured {
    grid-column: span 2;   /* ← занимает 2 колонки */
    grid-row: span 2;
}

Важно: span 2 с auto-fit может «сломать» сетку на мобильных. Используй @media для span: @media (min-width: 768px) { .featured { grid-column: span 2; } }.

8. Сравнение: media queries vs auto-fit

Media queries auto-fit
Код Много Одна строка
Контроль Полный Ограничен
Брейкпоинты Фиксированные Автоматические
Когда Сложные макеты Однотипные карточки
Правило: для однотипных карточек — auto-fit. Для сложных макетов — media queries.

9. Частые ошибки

Ошибка Почему плохо
auto-fill вместо auto-fit Остаются пустые колонки
minmax(100px, 1fr) для карточек Слишком много узких колонок
minmax(400px, 1fr) на мобильном Одна колонка, но шире экрана → скролл
Забыть box-sizing: border-box Padding «ломает» размеры
span 2 без @media Ломается на мобильных
Забыть gap Элементы слипаются

10. Что запомнить из урока

  • repeat(auto-fit, minmax(200px, 1fr)) — «магия» адаптивных сеток.
  • auto-fit — пустые колонки схлопываются.
  • auto-fill — пустые колонки остаются.
  • Для карточек — auto-fit.
  • minmax(200px, 1fr) — минимум 200px, растягивается.
  • Для карточек — minmax(250px, 1fr).
  • Для галереи — minmax(150px, 1fr).
  • span 2 с auto-fit — только с @media.
  • Для сложных макетов — media queries.

CSS Урок 9. Форматирование текста

2. font-family — шрифт

Задаёт семейство шрифтов. Можно указать несколько через запятую — браузер возьмёт первый доступный. 

body {
    font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
}

Порядок в списке

  1. Конкретные шрифты — если есть.
  2. Системные — system-ui, -apple-system.
  3. Фолбэк — sans-serif, serif, monospace.

Семейства шрифтов (фолбэки)

Фолбэк Пример
sans-serif Без засечек — этот текст
serif С засечками — как в книгах
monospace Монospace — для кода
cursive Рукописный
fantasy Декоративный
Разные шрифты:
system-ui — современный системный шрифт
Georgia — классический serif
Courier New — моноширинный
Comic Sans — рукописный

Шрифты с пробелами — в кавычках

font-family: "Times New Roman", serif;
font-family: "Segoe UI", sans-serif;
Совет: используй system-ui для основного текста — это нативный шрифт системы (SF Pro на Mac, Segoe UI на Windows, Roboto на Android). Выглядит «родным» и не требует загрузки.

3. font-size — размер

Размер шрифта. Используй rem, а не px — так пользователь сможет увеличить текст в настройках браузера. 

html {
    font-size: 16px;   /* базовый размер */
}

body {
    font-size: 1rem;      /* 16px */
}

h1 {
    font-size: 2.5rem;    /* 40px */
}

.small {
    font-size: 0.875rem;  /* 14px */
}

Значения font-size

Значение Что делает
16pxАбсолютно (плохо для доступности)
1remОт корня — рекомендую
1emОт родителя
100%От родителя (как em)
larger, smallerОтносительно родителя
x-small, small, medium, large, x-largeКлючевые слова
Разные размеры:
0.75rem = 12px
1rem = 16px (базовый)
1.5rem = 24px
2rem = 32px
3rem = 48px
Не используй px для шрифтов! Пользователь не сможет увеличить текст в настройках браузера (для слабовидящих). Всегда — rem.

Задаёт толщину шрифта.

Значение Что означает Соответствие
100ThinОчень тонкий
200Extra LightОчень светлый
300LightСветлый
400 / normalRegularОбычный (по умолчанию)
500MediumСредний
600Semi BoldПолужирный
700 / boldBoldЖирный

.normal { font-weight: 400; }
.bold   { font-weight: 700; }
.light  { font-weight: 300; }
Разная жирность:
font-weight: 300 — светлый
font-weight: 400 — обычный
font-weight: 600 — полужирный
font-weight: 700 — жирный
font-weight: 900 — чёрный
Важно: не все шрифты поддерживают все веса. Если у шрифта нет font-weight: 300, браузер подставит ближайший доступный (обычно 400). Для полного контроля нужны @font-face и подключение всех весов.

6. line-height — межстрочный интервал

Задаёт высоту строки. Это критично для читаемости. 

body {
    line-height: 1.6;   /* 1.6 × font-size = 25.6px при 16px */
}

Значения line-height

Значение Что означает
normalЗависит от шрифта (~1.2)
1.5Без единиц — множитель от font-size
1.5emОт font-size (но умножается при вложенности!)
24pxФиксированная высота
Рекомендую line-height: 1.5 или 1.6 для основного текста. Без единиц — множитель. Это лучший вариант: масштабируется с font-size, не умножается при вложенности.
Разный line-height:
line-height: 1 — строки слипаются. Этот текст читать тяжело. Особенно когда строк много.
line-height: 1.6 — комфортно. Этот текст легко читается. Строки не слипаются, но и не разлетаются.
line-height: 2.5 — слишком много воздуха. Строки разлетаются, теряется связь.

Почему line-height: 1.5 без единиц

/* ПЛОХО: 1.5em умножается при вложенности */
body {
    font-size: 16px;
    line-height: 1.5em;   /* 24px */
}

.big {
    font-size: 32px;
    /* line-height остаётся 24px — унаследовалось! */
    /* Строки слипаются */
}

/* ХОРОШО: 1.5 без единиц */
body {
    font-size: 16px;
    line-height: 1.5;   /* множитель */
}

.big {
    font-size: 32px;
    /* line-height = 32 × 1.5 = 48px — пересчиталось */
}
Демо: проблема с em:
line-height: 1.5em при font-size: 16px → 24px
font-size: 32px, но line-height унаследовался 24px — строки слипаются
line-height: 1.5 (без единиц) при font-size: 16px → 24px
font-size: 32px → line-height пересчитался = 48px — комфортно

7. letter-spacing — расстояние между буквами

.wide {
    letter-spacing: 0.1em;   /* больше пространства */
}

.tight {
    letter-spacing: -0.02em;  /* буквы ближе */
}
Результат:

letter-spacing: -0.05em — буквы слипаются

letter-spacing: normal — обычное

letter-spacing: 0.1em — с пробелами

ЗАГОЛОВОК С РАЗРЯДКОЙ

Применение: заголовки с разрядкой (0.1em) выглядят стильно. Но для основного текста — не трогай letter-spacing, он уже оптимизирован шрифтом.

8. text-transform — регистр

.upper   { text-transform: uppercase; }
.lower   { text-transform: lowercase; }
.capital { text-transform: capitalize; }
Результат:

uppercase — всё большими буквами

LOWERCASE — всё маленькими буквами

capitalize — каждое слово с большой

9. text-decoration — декор

.underline  { text-decoration: underline; }
.overline   { text-decoration: overline; }
.line-through { text-decoration: line-through; }
.none       { text-decoration: none; }
Результат:

Подчёркнутый

Надчёркнутый

Зачёркнутый

Ссылка без подчёркивания (text-decoration: none)

Осторожно: убирать text-decoration у ссылок — плохо для доступности. Пользователь не поймёт, что это ссылка. Оставь подчёркивание или замени на border-bottom.

10. Полный шрифтовой стек

/* Базовые стили для текста */
body {
    font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
    font-size: 1rem;         /* 16px */
    line-height: 1.6;
    color: #222;
}

h1 {
    font-size: 2.5rem;       /* 40px */
    font-weight: 700;
    line-height: 1.2;        /* для заголовков — плотнее */
}

h2 {
    font-size: 2rem;         /* 32px */
    line-height: 1.3;
}

p {
    margin-bottom: 1em;
}

.small {
    font-size: 0.875rem;     /* 14px */
    color: #666;
}

code {
    font-family: "SF Mono", Consolas, Monaco, monospace;
    font-size: 0.9em;        /* чуть меньше основного */
    background: #eee;
    padding: 2px 6px;
    border-radius: 4px;
}
Правило: line-height для заголовков — меньше (1.2–1.3), для текста — больше (1.5–1.7). Заголовки плотнее, текст «дышит».

11. Частые ошибки

Ошибка Почему плохо
font-size: 16px для основного текста Пользователь не увеличит (доступность). Используй rem
line-height: 1.5em Умножается при вложенности. Используй 1.5 без единиц
font-family: Arial без фолбэка Если Arial нет — браузер возьмёт что попало. Добавь sans-serif
font-family: Times New Roman без кавычек Пробел в имени — нужны кавычки
text-decoration: none на ссылках Плохо для доступности
Слишком мелкий текст (12px) Плохо читается
Слишком длинные строки Оптимально 45–75 символов (max-width: 65ch)

12. Что запомнить из урока

  • font-family — список шрифтов через запятую. Последний — фолбэк (sans-serif).
  • system-ui — нативный системный шрифт. Рекомендую для основного текста.
  • font-size — используй rem, не px.
  • font-weight — 100–900 или normal/bold.
  • font-style — normal, italic, oblique.
  • line-height — без единиц (1.5) — множитель, не умножается при вложенности.
  • line-height для текста — 1.5–1.7, для заголовков — 1.2–1.3.
  • letter-spacing — для разрядки заголовков, не для текста.
  • text-transform — uppercase, lowercase, capitalize.
  • text-decoration — подчёркивание/зачёркивание. Не убирай у ссылок.
  • Шрифты с пробелами — в кавычках: "Segoe UI".

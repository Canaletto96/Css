CSS Урок 38. Выравнивание в Grid

1. Четыре свойства выравнивания

Свойство Что выравнивает
justify-items Элементы внутри ячеек по горизонтали
align-items Элементы внутри ячеек по вертикали
justify-content Всю сетку по горизонтали
align-content Всю сетку по вертикали
Разница:
  • *-items — выравнивают элементы внутри их ячеек.
  • *-content — выравнивают всю сетку внутри контейнера.

4. place-items — сокращение

place-items = align-items + justify-items. 

.container {
    place-items: center;             /* и по X, и по Y */
    /* place-items: center start;    — align-items: center, justify-items: start */
}

5. justify-content — вся сетка по горизонтали

Выравнивает всю сетку внутри контейнера, если сетка меньше контейнера.

Значение Что делает
start (по умолчанию)В начале
endВ конце
centerПо центру
space-betweenПо краям + промежутки
space-aroundРавные промежутки
space-evenlyПолностью равные
 
.container {
    display: grid;
    grid-template-columns: 100px 100px 100px;   /* фиксированная ширина */
    justify-content: center;                      /* ← сетка по центру */
}

Важно: justify-content работает, только если сетка уже контейнера. Если колонки растянуты на всю ширину (например, 1fr 1fr 1fr) — эффекта не будет.

6. align-content — вся сетка по вертикали

Аналогично — для вертикали. Работает, если сетка ниже контейнера. 

.container {
    display: grid;
    grid-template-rows: 50px 50px;
    align-content: center;   /* ← сетка по центру по вертикали */
    height: 300px;
}

11. Частые ошибки

Ошибка Почему плохо
Путать *-items и *-content *-items — элементы, *-content — сетка
justify-content: center с 1fr Не работает — сетка и так на всю ширину
align-content без height контейнера Не работает — нет свободного места
place-items без display: grid Не работает
Забыть gap Элементы слипаются

12. Что запомнить из урока

  • justify-items — элементы в ячейках по горизонтали.
  • align-items — элементы в ячейках по вертикали.
  • place-items: center — и по X, и по Y. Самый частый.
  • justify-content — вся сетка по горизонтали (если уже контейнера).
  • align-content — вся сетка по вертикали (если ниже контейнера).
  • place-content: center — и по X, и по Y.
  • stretch — по умолчанию для *-items.
  • Разница: *-items — элементы, *-content — сетка.
  • place-items: center — центрирование через Grid.

CSS Урок 36. Области Grid

1. Что такое области

Области (areas) — это именованные ячейки сетки. Ты даёшь имя каждой зоне и потом «рисуешь» макет прямо в CSS.

Это самый наглядный способ для макетов страниц.

.layout {
    display: grid;
    grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
}

2. grid-template-areas — «рисование» макета

Свойство задаётся строками. Каждая строка — в кавычках. Внутри — имена зон через пробел. 

grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";

Это 3 строки × 2 колонки:

Колонка 1 Колонка 2
Строка 1headerheader
Строка 2sidebarmain
Строка 3footerfooter

3. grid-area — привязка элемента к области

Каждому элементу задаёшь имя области через grid-area: 

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }
Макет: header / sidebar / main / footer:
header
sidebar
main
footer

4. Правила областей

Правило Почему
Все строки — одинаковой длины Иначе ошибка
Имена — без пробелов Пробел — разделитель зон
Одна зона — прямоугольник Нельзя «Г-образную» форму
. — пустая ячейка Если нужно оставить пусто

Пример с пустой ячейкой

grid-template-areas:
    "header header"
    ". main"
    "footer footer";

Левая ячейка второй строки — пустая.

Пустая ячейка (`.`):
header
main
footer

5. grid-template-areas + grid-template-columns

Области не задают размеры. Нужно дополнительно указать grid-template-columns и grid-template-rows. 

.layout {
    display: grid;
    grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
    grid-template-columns: 200px 1fr;
    grid-template-rows: auto 1fr auto;
    gap: 16px;
    min-height: 100vh;
}
Порядок: grid-template-areas задаёт карту, а grid-template-columns / grid-template-rows — размеры. Они работают вместе.

6. Адаптивность с областями

Главная сила областей — легко менять макет на разных экранах: 

/* Мобильный — одна колонка */
.layout {
    grid-template-areas:
        "header"
        "main"
        "sidebar"
        "footer";
    grid-template-columns: 1fr;
}

/* Десктоп — две колонки */
@media (min-width: 768px) {
    .layout {
        grid-template-areas:
            "header header"
            "sidebar main"
            "footer footer";
        grid-template-columns: 200px 1fr;
    }
}
Мобильный макет (одна колонка):
header
main
sidebar
footer

7. Практика: макет сайта

*, *::before, *::after {
    box-sizing: border-box;
}

.layout {
    display: grid;
    grid-template-areas:
        "header header header"
        "sidebar main aside"
        "footer footer footer";
    grid-template-columns: 200px 1fr 200px;
    grid-template-rows: auto 1fr auto;
    gap: 16px;
    min-height: 100vh;
    padding: 16px;
    background: #fafafa;
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.aside { grid-area: aside; }
.footer { grid-area: footer; }
Трёхколоночный макет:
header
sidebar
main
aside
footer

8. Практика: карточки с «выделенной»

.cards {
    display: grid;
    grid-template-areas:
        "featured featured side"
        "featured featured side2";
    grid-template-columns: 1fr 1fr 200px;
    gap: 16px;
}

.featured { grid-area: featured; }
.side { grid-area: side; }
.side2 { grid-area: side2; }
Featured 2×2 + боковые:
featured (2×2)
side
side2

9. Области vs линии

Области (areas) Линии (columns/rows)
Наглядность Высокая — видно макет Низкая — нужно считать линии
Сложность Проще Сложнее
Гибкость Для «прямоугольных» макетов Для любых
Когда использовать Макеты страниц Отдельные элементы
Совет: для макетов страниц — области. Для отдельных элементов внутри — линии или span. Можно комбинировать.

10. Частые ошибки

Ошибка Почему плохо
Разная длина строк Ошибка — все строки должны быть одинаковой длины
Пробел в имени зоны Пробел — разделитель. Используй дефис
Забыть grid-template-columns Размеры не заданы
«Г-образная» область Область должна быть прямоугольником
Забыть grid-area у элемента Элемент не попадёт в область

11. Что запомнить из урока

  • grid-template-areas — «карта» макета. Каждая строка в кавычках.
  • grid-area у элемента — привязка к области.
  • Все строки должны быть одинаковой длины.
  • Область — прямоугольник. Нельзя «Г-образную».
  • . — пустая ячейка.
  • Размеры — отдельно через grid-template-columns / rows.
  • Главная сила — адаптивность. Легко менять макет на разных экранах.
  • Для макетов — области. Для элементов — линии / span.

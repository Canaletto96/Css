CSS Урок 30. Размеры flex

1. Три свойства для размеров

Свойство Что делает
flex-grow Как растягиваться, если есть свободное место
flex-shrink Как сжиматься, если места не хватает
flex-basis Базовый размер до растяжения/сжатия
flex Сокращение: grow + shrink + basis

2. flex-grow — растяжение

Определяет, как элемент растягивается, если в контейнере есть свободное место.

Значение Что означает
0 (по умолчанию)Не растягивается
1Растягивается пропорционально
2Растягивается в 2 раза сильнее, чем с 1
 
.container {
    display: flex;
    width: 600px;
}

.item {
    flex-grow: 0;   /* по умолчанию */
}

flex-grow: 0 (по умолчанию)

flex-grow: 1 у всех

Разные значения

flex-grow: 1, 2, 1 — второй в 2 раза шире:
grow: 1
grow: 2
grow: 1
Как работает: flex-grow — это доля от свободного места. Если у всех 1 — все получат одинаково. Если у одного 2 — он получит в 2 раза больше, чем остальные.

3. flex-shrink — сжатие

Определяет, как элемент сжимается, если места не хватает.

Значение Что означает
1 (по умолчанию)Сжимается
0Не сжимается — сохраняет размер
2Сжимается сильнее
 
.item {
    flex-shrink: 1;   /* по умолчанию */
}

.item.fixed {
    flex-shrink: 0;   /* ← не сжимается */
}

Пример: один не сжимается

flex-shrink: 0 у второго — сохраняет размер:
shrink: 1
shrink: 0
shrink: 1

Первый и третий сжались, второй — нет.

Когда использовать flex-shrink: 0:
  • Иконки — не должны сжиматься.
  • Кнопки — сохраняют размер.
  • Логотипы — фиксированная ширина.

4. flex-basis — базовый размер

Начальный размер элемента до растяжения или сжатия. По умолчанию — auto. 

.item {
    flex-basis: 200px;      /* начальная ширина 200px */
    /* flex-basis: auto;    — по умолчанию, зависит от content */
    /* flex-basis: 30%;     — 30% от родителя */
}
flex-basis: 100px, 200px, 150px:

200px
150px

flex-basis vs width

width flex-basis
Работает Всегда Только в flex-контейнере
Приоритет Ниже Выше (перебивает width)
Когда использовать Вне flex Для flex-элементов
Правило: flex-basis перебивает width. Если оба заданы — используется flex-basis.

5. flex — сокращение

Объединяет flex-grow, flex-shrink и flex-basis: 

.item {
    flex: 0 1 auto;      /* по умолчанию: grow shrink basis */
    /* flex: 1;          — grow: 1, shrink: 1, basis: 0 */
    /* flex: 1 1 200px;  — grow: 1, shrink: 1, basis: 200px */
    /* flex: auto;       — 1 1 auto */
    /* flex: none;       — 0 0 auto */
}

6. Как работает flex-grow + flex-basis

Пошагово:

  1. Базовый размер — все элементы получают flex-basis (или width, или auto).
  2. Свободное место — сколько осталось в контейнере.
  3. Распределение — свободное место делится пропорционально flex-grow.
/* Контейнер 600px, 3 элемента по flex: 1 */
/* Каждый получит: (600 - 0) / 3 = 200px */

/* Контейнер 600px, 3 элемента по flex: 2, 1, 1 */
/* Сумма grow = 4. Свободное место = 600. */
/* Элемент 1: 600 × 2/4 = 300px */
/* Элемент 2: 600 × 1/4 = 150px */
/* Элемент 3: 600 × 1/4 = 150px */

9. Практика: медиа-объект

.media {
    display: flex;
    gap: 16px;
    align-items: flex-start;
}

.media-avatar {
    flex: 0 0 64px;   /* фиксированный размер, не сжимается */
    width: 64px;
    height: 64px;
    border-radius: 50%;
}

.media-body {
    flex: 1;   /* занимает всё оставшееся */
    min-width: 0;   /* ← чтобы текст не «ломал» флекс */
}
Медиа-объект (аватар + текст):
И

Иван Иванов

Длинный текст, который обтекает аватар и занимает всё оставшееся место в контейнере.

min-width: 0 — важный трюк. Без него длинный текст «ломает» flex-элемент (он не может стать меньше содержимого).

11. Частые ошибки

Ошибка Почему плохо
Забыть min-width: 0 для flex-элементов с длинным текстом Текст «ломает» флекс — элемент не сжимается
flex: 1 вместо flex: 0 0 auto для кнопок Кнопки растянутся на всю ширину
Использовать width вместо flex-basis flex-basis перебивает width
Забыть flex-shrink: 0 для иконок Иконки сожмутся до нуля
Ожидать, что flex: 1 сделает одинаковую высоту flex — по главной оси. Высота — align-items

12. Шпаргалка

/* Равные доли */
.item {
    flex: 1;
}

/* Пропорционально */
.item-1 { flex: 1; }
.item-2 { flex: 2; }   /* в 2 раза больше */
.item-3 { flex: 1; }

/* Фиксированный размер, не сжимается */
.item {
    flex: 0 0 200px;
}

/* Не растягивается, но сжимается */
.item {
    flex: 0 1 auto;
}

/* Растягивается, не сжимается */
.item {
    flex: 1 0 auto;
}

/* Не растягивается и не сжимается */
.item {
    flex: none;   /* = 0 0 auto */
}

/* Полная запись */
.item {
    flex: 1 1 200px;   /* grow shrink basis */
}

13. Что запомнить из урока

  • flex-grow — как растягиваться. 0 — нет, 1 — пропорционально.
  • flex-shrink — как сжиматься. 1 — да, 0 — нет.
  • flex-basis — базовый размер. Перебивает width.
  • flex — сокращение: grow shrink basis.
  • flex: 1 — равные доли. Самый частый.
  • flex: 0 0 200px — фиксированный размер.
  • min-width: 0 — для длинных текстов в flex.
  • flex-shrink: 0 — для иконок, кнопок.
  • flex-basis width — при конфликте.

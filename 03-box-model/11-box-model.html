CSS Урок 11. Блочная модель

1. Что такое блочная модель

Блочная модель (box model) — это способ, которым браузер рассчитывает размеры и положение каждого элемента на странице.

Каждый элемент — это прямоугольник, состоящий из четырёх слоёв:

margin
border
padding
content
(width × height)
Слой Что это Свойства
Content Содержимое: текст, картинка, вложенные элементы width, height
Padding Внутренний отступ (от содержимого до рамки) padding
Border Рамка вокруг padding border
Margin Внешний отступ (от рамки до других элементов) margin
Аналогия. Представь коробку с подарком:
  • Content — сам подарок.
  • Padding — поролон внутри коробки (защита).
  • Border — стенки коробки.
  • Margin — расстояние от коробки до других коробок на полке.

2. Живой пример

Блок с width: 200px, padding: 20px, border: 5px, margin: 30px:
content: 200px
+ padding: 20px × 2 = 40px
+ border: 5px × 2 = 10px
= 250px общая ширина

Важно: width: 200px — это ширина только content! Если добавить padding и border, общая ширина станет больше.

3. width и height

Задают размеры content area (по умолчанию).

.box {
    width: 300px;
    height: 200px;
}
width: 300px, height: 100px, background:
300 × 100

Значение Что означает

4. padding — внутренний отступ

Пространство между содержимым и рамкой. Увеличивает размер блока (по умолчанию). 

.box {
    padding: 20px;              /* все стороны */
    padding: 10px 20px;         /* верх/низ 10, право/лево 20 */
    padding: 10px 20px 30px;    /* верх 10, право/лево 20, низ 30 */
    padding: 10px 20px 30px 40px; /* верх право низ лево */
}

/* Или отдельно */
.box {
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 30px;
    padding-left: 40px;
}
Разный padding:

Порядок в shorthand

Верх → Право → Низ → Лево (по часовой стрелке).

Мнемоника: «Верх Право Низ Лево» — «ТРБЛ» (по часовой).
Или «Top Right Bottom Left» — TRBL — «Trouble» (проблема).

Отрицательный padding?

Нельзя! padding: -10px; — невалидно. Padding не может быть отрицательным. Только margin.

5. border — рамка

Рамка вокруг padding. Состоит из трёх свойств:

        ширина  стиль  цвет */
}

6. margin — внешний отступ

Пространство вне рамки, до других элементов. Не входит в размер блока. 

.box {
    margin: 20px;               /* все стороны */
    margin: 10px 20px;          /* верх/низ 10, право/лево 20 */
    margin: 0 auto;             /* по центру (если есть width) */
    margin: -10px;              /* отрицательный — работает! */
}
margin: 16px:
margin: 16px (отступ снаружи)
margin: 16px

Центрирование через margin

.box {
    width: 300px;
    margin: 0 auto;   /* блок по центру родителя */
}
margin: 0 auto:
width: 200px, margin: 0 auto
Почему margin: 0 auto центрирует: auto в horizontal margin означает «взять оставшееся место и разделить пополам». Работает только если у блока задана width (иначе он и так занимает всю ширину).

Отрицательный margin

margin может быть отрицательным — элемент «сдвинется» в обратную сторону, наезжая на соседей. 

.pull-up {
    margin-top: -20px;   /* сдвинуть вверх на 20px */
}

7. Схлопывание margin (margin collapse)

Странная особенность CSS: вертикальные margin схлопываются, если два блока идут подряд. 

.first {
    margin-bottom: 30px;
}

.second {
    margin-top: 20px;
}

Расстояние между ними будет 30px, а не 50px! Браузер берёт максимум, а не сумму.

margin-bottom: 30px + margin-top: 20px = 30px (не 50px):
первый: margin-bottom: 30px
второй: margin-top: 20px (расстояние между ними = 30px)

Когда margin НЕ схлопываются

  • Горизонтальные margin (left/right) — никогда.
  • Если у одного из блоков есть border или padding между ними.
  • В Flexbox и Grid — никогда (внутри контейнера).
  • Если между блоками есть содержимое (не пустая строка).
Схлопывание — одна из самых частых причин «почему отступ не работает». Если увидел, что margin не даёт нужного расстояния — проверь, не схлопывается ли он с соседом.

Как бороться со схлопыванием

  • Использовать padding вместо margin.
  • Добавить border (даже прозрачный) между блоками.
  • Использовать display: flex на родителе — отменяет схлопывание.
  • Использовать gap вместо margin (в Flexbox/Grid).

8. Как браузер считает общий размер

По умолчанию (box-sizing: content-box):

общая ширина = width + padding-left + padding-right + border-left + border-right
общая высота = height + padding-top + padding-bottom + border-top + border-bottom
margin НЕ входит в размер блока!

Пример:

.box {
    width: 200px;
    padding: 20px;
    border: 5px solid;
    margin: 30px;
}

/* Общая ширина = 200 + 20 + 20 + 5 + 5 = 250px */
/* Общая высота зависит от содержимого */
/* margin = 30px снаружи (не входит в размер) */
Проблема: если ты хочешь блок ровно 300px, а добавил padding и border, он станет больше 300px. Это ломает сетки. Решение: box-sizing: border-box — в уроке 12.

10. Частые ошибки

Ошибка Почему плохо
Думать, что width = общая ширина width — только content. Padding и border добавляются
Путать padding и margin Padding — внутри, margin — снаружи
Пытаться сделать padding: -10px Невалидно. Отрицательный — только margin
Удивляться, что margin не работает Схлопывание margin. См. раздел 7
margin: 0 auto без width Не центрирует — блок и так занимает всю ширину
Забыть border-style Без стиля рамки нет (по умолчанию none)
Использовать width вместо max-width Не адаптируется к маленьким экранам

11. Что запомнить из урока

  • Блочная модель — 4 слоя: content, padding, border, margin.
  • width/height — размер content (по умолчанию).
  • padding — внутренний отступ, входит в размер блока.
  • border — рамка, входит в размер блока.
  • margin — внешний отступ, НЕ входит в размер блока.
  • Порядок shorthand: верх → право → низ → лево (по часовой).
  • padding не может быть отрицательным, margin — может.
  • Общая ширина = width + padding + border (по умолчанию).
  • margin: 0 auto центрирует блок (с width).
  • Схлопывание margin — вертикальные margin соседних блоков объединяются по максимуму.
  • Для точных размеров — box-sizing: border-box (урок 12).

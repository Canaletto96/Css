CSS Урок 18. Градиенты

1. Что такое градиент

Градиент — это плавный переход между цветами. В CSS это функция, которая создаёт изображение (как фон), а не отдельный файл.

Градиент — это background-image, а не background-color. Поэтому его можно задавать через background или background-image: 

.box {
    background: linear-gradient(90deg, #1565c0, #42a5f5);
    /* или */
    background-image: linear-gradient(90deg, #1565c0, #42a5f5);
}
Зачем: градиент не требует загрузки картинки — браузер сам его «рисует». Это быстрее, адаптивнее и чётче на любом экране (даже Retina).

2. Три вида градиентов

Функция Что делает
linear-gradient() Переход вдоль линии (линейный)
radial-gradient() Переход от центра к краям (радиальный)
conic-gradient() Переход по кругу (конический)

3. linear-gradient — линейный

Синтаксис:

linear-gradient(угол, цвет1, цвет2, ...)

Базовый пример

    background: linear-gradient(90deg, #1565c0, #42a5f5);
}

Стопы (позиции цветов)

Можно указать, где должен быть цвет — в процентах или пикселях:

.box {
    background: linear-gradient(90deg, #1565c0 0%, #1565c0 50%, #42a5f5 50%, #42a5f5 100%);
    /* Первые 50% — синий, вторые 50% — голубой. Резкая граница */
}
Резкая граница (стопы):
50/50
Стопы — позиции, где цвет «фиксируется». Если два цвета имеют одинаковую позицию — граница становится резкой. Это используется для «полосок», «шахматки» и других эффектов.

Переход от центра к краям (как круги на воде).

Базовый пример

.box {
    background: radial-gradient(#1565c0, #42a5f5);
}

5. conic-gradient — конический

Переход по кругу — как стрелки часов или «круговой прогресс».

conic-gradient(от угла, цвет1, цвет2, ...)
conic-gradient:
по кругу
from 90deg

Применение conic-gradient: круговые прогресс-бары, «пироги» в диаграммах, конические «фонарики», шахматные узоры.

6. Repeating-градиенты

7. Прозрачность в градиентах

В градиентах можно использовать rgba() или transparent для плавного перехода в прозрачность. 

.overlay {
    background: linear-gradient(to bottom, transparent, rgba(0, 0, 0, 0.8));
}
Overlay поверх картинки:
Текст поверх overlay
Трюк: transparent — это rgba(0,0,0,0). В некоторых браузерах переход от transparent к цвету даёт «серый» вместо прозрачности. Решение: использовать rgba(255, 255, 255, 0) или rgba(0, 0, 0, 0).

8. Несколько градиентов на одном фоне

Через запятую можно задать несколько градиентов — они накладываются друг на друга (как слои). 

.box {
    background:
        linear-gradient(to right, rgba(21, 101, 192, 0.7), transparent),
        linear-gradient(to bottom, rgba(229, 57, 53, 0.5), transparent),
        #fafafa;
}

11. Частые ошибки

Ошибка Почему плохо
background-color: linear-gradient(...) Градиент — это image, не color. Используй background или background-image
transparent в градиенте от цвета Может дать «серый» вместо прозрачности. Используй rgba(0,0,0,0)
Забыть deg или to Угол не работает
Использовать градиент для текста без background-clip Текст не видно. Нужен -webkit-background-clip: text
Градиент без стопов Переход плавный по всему блоку — может быть некрасиво

12. Что запомнить из урока

  • Градиент — это background-image, не background-color.
  • linear-gradient — вдоль линии. Углы: 90deg, to right, 135deg.
  • radial-gradient — от центра. Формы: circle, ellipse.
  • conic-gradient — по кругу. Для прогресс-баров, «пирогов».
  • Стопы — позиции цветов. Одинаковые стопы → резкая граница.
  • Repeating-градиенты — для полосок, узоров.
  • Прозрачность — через rgba() или transparent.
  • Несколько градиентов — через запятую, накладываются.
  • Overlay — градиент поверх картинки для затемнения.
  • Градиентный текст — background-clip: text + color: transparent.

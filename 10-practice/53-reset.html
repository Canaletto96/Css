CSS Урок 53. Сброс стилей

1. Проблема: разные браузеры — разные стили

Каждый браузер применяет свои стили по умолчанию (user agent stylesheet). Chrome, Firefox, Safari, Edge — разные отступы, размеры, шрифты у одинаковых тегов.

Элемент Chrome Firefox Safari
<body> margin: 8px margin: 8px margin: 8px
<h1> font-size: 2em font-size: 2em Может отличаться
<button> Свой стиль Свой стиль Свой стиль
<input> Свой стиль Другой Третий
Проблема: сайт выглядит по-разному в разных браузерах. Особенно заметно на <button>, <input>, <select>, <textarea>.

2. Что такое сброс стилей

Сброс стилей (reset / normalize) — это CSS-файл, который убирает или выравнивает стили браузера, чтобы начать «с чистого листа».

Подход Что делает
reset.css Убирает ВСЁ: margin, padding, border, list-style
normalize.css Выравнивает стили браузеров, но сохраняет полезное

3. reset.css — «убрать всё»

Классический reset (Eric Meyer, 2000-е) убирает все стили браузера: 

/* reset.css (классический) */
* {
    margin: 0;
    padding: 0;
    border: 0;
    font-size: 100%;
    font: inherit;
    vertical-align: baseline;
}

body {
    line-height: 1;
}

ol, ul {
    list-style: none;
}

table {
    border-collapse: collapse;
    border-spacing: 0;
}

Плюсы и минусы reset.css

Плюсы Минусы
Полный контроль Приходится всё задавать заново
Одинаково во всех браузерах Теряются полезные стили (h1 больше не жирный)
Чистый старт Много кода для базовых стилей

4. normalize.css — «выровнять, но сохранить»

normalize.css (Nicolas Gallagher, 2011) — «умный» сброс. Он выравнивает стили браузеров, но сохраняет полезные:

  • h1 остаётся жирным и крупным.
  • ul остаётся с маркерами.
  • button остаётся кнопкой.
  • Но — одинаково во всех браузерах.
/* normalize.css (фрагмент) */
html {
    line-height: 1.15;
    -webkit-text-size-adjust: 100%;
}

body {
    margin: 0;
}

h1 {
    font-size: 2em;
    margin: 0.67em 0;
}

button,
input {
    font-family: inherit;
    font-size: 100%;
    line-height: 1.15;
    margin: 0;
}

normalize.css — лучший выбор для большинства проектов. Сохраняет полезное, выравнивает различия.

5. Как подключить

Через CDN

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/normalize.css@8.0.1/normalize.css">
<link rel="stylesheet" href="style.css">

Локально

<!-- Сначала reset, потом свои стили -->
<link rel="stylesheet" href="css/normalize.css">
<link rel="stylesheet" href="css/style.css">
Порядок важен: normalize.css — первым. Свои стили — после. Иначе reset перебьёт твои стили.

6. Современный reset (рекомендую)

Сейчас normalize.css уже не так актуален — браузеры стали ближе. Современный reset — минимальный, но эффективный: 

/* modern-reset.css */
*,
*::before,
*::after {
    box-sizing: border-box;
}

body {
    margin: 0;
    font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
    line-height: 1.6;
    -webkit-font-smoothing: antialiased;
}

img,
picture,
video,
canvas,
svg {
    display: block;
    max-width: 100%;
}

input,
button,
textarea,
select {
    font: inherit;
}

p,
h1,
h2,
h3,
h4,
h5,
h6 {
    overflow-wrap: break-word;
}

7. Что делает современный reset

Правило Зачем
box-sizing: border-box Padding не увеличивает ширину (урок 12)
body { margin: 0 } Убирает отступ 8px у body
img { display: block } Убирает зазор под картинкой
img { max-width: 100% } Картинка не вылезает за экран
input, button { font: inherit } Кнопки/поля наследуют шрифт
overflow-wrap: break-word Длинные слова не вылезают

8. Полный современный reset

/* ============================================================
   Modern CSS Reset (Andy Bell, 2023)
   ============================================================ */

*, *::before, *::after {
    box-sizing: border-box;
}

* {
    margin: 0;
}

body {
    line-height: 1.5;
    -webkit-font-smoothing: antialiased;
}

img, picture, video, canvas, svg {
    display: block;
    max-width: 100%;
}

input, button, textarea, select {
    font: inherit;
}

p, h1, h2, h3, h4, h5, h6 {
    overflow-wrap: break-word;
}

#root, #__next {
    isolation: isolate;
}
Этот reset — 16 строк. Он убирает главные проблемы, но оставляет полезные стили (h1 — жирный, ul — с маркерами).

9. Что НЕ надо сбрасывать

Не сбрасывай:
  • Размеры заголовков — h1 должен быть крупным.
  • Маркеры списков — ul должен быть с точками.
  • Стили кнопок — button должна выглядеть как кнопка.
  • Отступы параграфов — p должен иметь отступы.
Иначе — придётся всё задавать заново.

10. Практика: свой reset

Создай файл reset.css и подключи его первым:

/* reset.css */
*, *::before, *::after {
    box-sizing: border-box;
}

* {
    margin: 0;
}

body {
    font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
    line-height: 1.6;
    -webkit-font-smoothing: antialiased;
}

img, picture, video, canvas, svg {
    display: block;
    max-width: 100%;
}

input, button, textarea, select {
    font: inherit;
}

p, h1, h2, h3, h4, h5, h6 {
    overflow-wrap: break-word;
}
<!-- index.html -->
<link rel="stylesheet" href="reset.css">
<link rel="stylesheet" href="style.css">

11. Сравнение подходов

reset.css normalize.css Modern reset
Стили браузера Убирает всё Выравнивает Убирает главное
Полезное Теряется Сохраняется Сохраняется
Размер Много Средний 16 строк
Рекомендация Legacy Хорошо Да

12. Частые ошибки

Ошибка Почему плохо
Подключить reset после своих стилей Reset перебьёт твои стили
Использовать * { margin: 0; padding: 0; } Теряются полезные отступы
Забыть box-sizing: border-box Padding «ломает» размеры
Сбрасывать h1 до font-size: 1em Заголовок перестаёт быть заголовком
Сбрасывать ul без list-style Список теряет маркеры

13. Что запомнить из урока

  • Сброс стилей — убрать/выровнять стили браузера.
  • reset.css — убирает всё. Много кода, теряет полезное.
  • normalize.css — выравнивает, сохраняет полезное.
  • Современный reset — 16 строк, минимальный.
  • box-sizing: border-box — обязательно.
  • body { margin: 0 } — убирает отступ 8px.
  • img { display: block; max-width: 100% } — картинки.
  • input, button { font: inherit } — наследуют шрифт.
  • Подключать первым — до своих стилей.
  • Не сбрасывать полезное: размеры заголовков, маркеры списков.

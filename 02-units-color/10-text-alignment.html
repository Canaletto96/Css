CSS Урок 10. Выравнивание текста

1. text-align — горизонтальное выравнивание

Выравнивает строчный контент (текст, inline-элементы) внутри блочного элемента по горизонтали. 

.left    { text-align: left; }     /* по левому краю (по умолчанию) */
.center  { text-align: center; }   /* по центру */
.right   { text-align: right; }    /* по правому краю */
.justify { text-align: justify; }  /* по обоим краям */
Все значения:
left: Этот текст выровнен по левому краю. Обычный вариант для большинства текстов. Читается слева направо.
center: Этот текст выровнен по центру. Хорошо для заголовков и коротких фраз.
right: Этот текст выровнен по правому краю. Используется редко — для цен, дат.
justify: Этот текст выровнен по обоим краям. Строки растягиваются на всю ширину блока. Используется в газетах и книгах. Но в вебе осторожно — могут быть «дыры» между словами.

Когда что использовать

Значение Когда
leftОсновной текст (по умолчанию)
centerЗаголовки, короткие фразы, кнопки
rightЦены, даты, подписи справа
justifyКниги, длинные статьи (осторожно)
Не используй justify для коротких текстов! На узких блоках между словами появляются огромные «дыры». Также justify плохо работает с кириллицей (нет переносов по умолчанию). Для длинных текстов — добавь hyphens: auto.

Выравнивание вложенных элементов

text-align применяется к содержимому блока, а не к самому блоку. Чтобы выровнять сам блок — используй margin (урок 14) или Flexbox (урок 27+). 

/* ПЛОХО: не выровняет блок */
.box {
    text-align: center;   /* выровняет текст внутри, не блок */
}

/* ХОРОШО: выровнять блок */
.box {
    width: 300px;
    margin: 0 auto;       /* блок по центру */
    text-align: center;   /* текст внутри — по центру */
}

2. vertical-align — вертикальное выравнивание

Выравнивает строчные (inline) элементы по вертикали относительно строки. 

.top     { vertical-align: top; }
.middle  { vertical-align: middle; }
.bottom  { vertical-align: bottom; }
.baseline { vertical-align: baseline; }   /* по умолчанию */
.super   { vertical-align: super; }
.sub     { vertical-align: sub; }
Разные значения vertical-align (в строке с текстом):
Текст baseline top middle bottom super sub ещё текст.
Значение Что делает
baselineПо базовой линии текста (по умолчанию)
topПо верху строки
middleПо середине строки
bottomПо низу строки
text-topПо верху текста
text-bottomПо низу текста
superНадстрочный (как степень)
subПодстрочный (как индекс)
px, em, %Сдвиг от baseline
Важно: vertical-align работает только для inline и inline-block элементов. Для block — не работает! 
/* ПЛОХО: div — block, vertical-align не сработает */
div {
    display: block;
    vertical-align: middle;   /* ← игнорируется */
}

/* ХОРОШО: inline-block */
span {
    display: inline-block;
    vertical-align: middle;   /* ← работает */
}

Частое применение: иконка + текст

<button>
    <svg style="vertical-align: middle;">...</svg>
    Текст кнопки
</button>
Иконка выровнена по тексту:
Современный способ: для выравнивания элементов в строке лучше использовать Flexbox (align-items: center). vertical-align — для inline и таблиц. Подробно — в уроке 27+.

3. text-indent — отступ первой строки

Отступ первой строки параграфа. Как в книгах.

p {
    text-indent: 2em;   /* отступ первой строки 2em */
}
text-indent: 2em:

Это параграф с отступом первой строки. Как в книгах — начало абзаца сдвинуто вправо. Остальные строки выровнены по левому краю.

Второй параграф тоже с отступом первой строки. Можно задавать в em, rem, px или %.

Когда: книги, статьи, длинные тексты. Для веба — реже, чем margin между параграфами.

4. white-space — обработка пробелов

Управляет тем, как браузер обрабатывает пробелы и переносы внутри элемента.

Значение Что делает
normalСхлопывает пробелы, переносит строки (по умолчанию)
nowrapНе переносит строки — всё в одну
preСохраняет всё как в <pre>
pre-wrapСохраняет пробелы + переносит длинные строки
pre-lineСхлопывает пробелы, но сохраняет переносы
break-spacesКак pre-wrap, но и в конце строк
Сравнение:
normal: много пробелов схлопываются.
nowrap: длинная строка не переносится и вылезает за край — нужна горизонтальная прокрутка.
pre: пробелы сохраняются и переносы
pre-wrap: пробелы сохраняются, и длинные строки переносятся.

Применение white-space

  • nowrap — кнопки, чтобы текст не переносился.
  • pre — код, стихи, ASCII-арт.
  • pre-wrap — код с переносами, но чтобы влезал.
  • normal — обычный текст.

5. word-break и overflow-wrap

Управляют переносом длинных слов (URL, длинные термины), которые не влезают в блок.

Свойство Значения Что делает
overflow-wrap normal, break-word, anywhere Перенос длинных слов, если не влезают
word-break normal, break-all, keep-all Разрешить перенос в любом месте
hyphens none, manual, auto Автоматические переносы с дефисом 
.url {
    overflow-wrap: break-word;   /* перенос длинного URL */
}

.code {
    word-break: break-all;       /* перенос в любом месте */
}

.text {
    hyphens: auto;               /* автоматические переносы */
}
Длинный URL без переноса:
https://example.com/very/long/path/that/does/not/fit/in/the/container/and/overflows
С overflow-wrap: break-word:
https://example.com/very/long/path/that/does/not/fit/in/the/container/and/overflows

6. text-overflow — обрезка текста

Показывает, что текст обрезан, через ... (многоточие).

.truncate {
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
}
Обрезка с многоточием:
Очень длинный текст, который не влезает в блок и обрезается многоточием.
Три свойства вместе: white-space: nowrap + overflow: hidden + text-overflow: ellipsis. Без overflow: hidden — не работает.

7. direction и unicode-bidi

Для языков с письмом справа налево (арабский, иврит):

.rtl {
    direction: rtl;
    unicode-bidi: bidi-override;
}
direction: rtl:
Это текст справа налево. Начало справа.

Подробно — в HTML-курсе (атрибут dir).

8. Полный стек выравнивания

body {
    text-align: left;
}

h1, h2, h3 {
    text-align: center;
}

.price {
    text-align: right;
}

.article p {
    text-align: justify;
    hyphens: auto;
}

.btn {
    white-space: nowrap;
}

.truncate {
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
}

.url {
    overflow-wrap: break-word;
}

9. Частые ошибки

Ошибка Почему плохо
text-align: center для выравнивания блока Выравнивает содержимое, не блок. Для блока — margin: 0 auto
text-align: justify для коротких текстов Огромные «дыры» между словами
vertical-align на block-элементах Не работает — только для inline
text-overflow: ellipsis без overflow: hidden Не работает
text-indent на всех p В вебе чаще используют margin между параграфами
word-break: break-all без причины Ломает слова посреди — плохо читается
Забыть hyphens: auto при justify Большие расстояния между словами

10. Что запомнить из урока

  • text-align — left, center, right, justify.
  • text-align: center — выравнивает содержимое, не блок.
  • Для блока по центру — margin: 0 auto.
  • justify — только для длинных текстов, с hyphens: auto.
  • vertical-align — только для inline и inline-block.
  • text-indent — отступ первой строки (как в книгах).
  • white-space — обработка пробелов: normal, nowrap, pre, pre-wrap.
  • overflow-wrap: break-word — перенос длинных URL.
  • text-overflow: ellipsis — многоточие при обрезке (с overflow: hidden).
  • Для современного выравнивания — Flexbox и Grid, не vertical-align.

CSS Урок 26. Центрирование

1. Три задачи центрирования

Задача Что центрируем
ГоризонтальноеПо оси X
ВертикальноеПо оси Y
ПолноеИ по X, и по Y

Для каждой задачи — свои способы. От простого к сложному.

2. Горизонтальное центрирование

Способ 1: text-align: center

Для строчного содержимого (текст, inline-элементы).

.box {
    text-align: center;
}
text-align: center:

Текст по центру

Ссылка по центру
Не работает для блочных элементов (div, p). Только для содержимого внутри.

Способ 2: margin: 0 auto

Для блочного элемента с заданной width.

.box {
    width: 300px;
    margin: 0 auto;
}
margin: 0 auto:
margin: 0 auto
Как работает: auto в горизонтальных margin означает «взять оставшееся место и разделить пополам». Работает, только если у блока есть width (иначе он и так занимает всю ширину).

Способ 3: Flexbox

.parent {
    display: flex;
    justify-content: center;
}
flex + justify-content: center:
flex: center
Универсальный способ: работает для любых элементов, не требует width. Рекомендую.

Способ 4: Grid

.parent {
    display: grid;
    justify-content: center;
}
grid + justify-content: center:
grid: center

Способ 5: position: absolute

.parent {
    position: relative;
}

.box {
    position: absolute;
    left: 50%;
    transform: translateX(-50%);
}
absolute + left 50% + translateX -50%:
absolute: center

3. Вертикальное центрирование

Способ 1: Flexbox

.parent {
    display: flex;
    align-items: center;
    height: 200px;
}
flex + align-items: center:
flex: align-items

Лучший способ для вертикального центрирования.

Способ 2: Grid

.parent {
    display: grid;
    align-items: center;
    height: 200px;
}
grid + align-items: center:
grid: align-items

Способ 3: position: absolute

.parent {
    position: relative;
}

.box {
    position: absolute;
    top: 50%;
    transform: translateY(-50%);
}
absolute + top 50% + translateY -50%:
absolute: center

Способ 4: table-cell (legacy)

.parent {
    display: table-cell;
    vertical-align: middle;
    height: 200px;
}
Не используй: устаревший способ. Работает, но Flexbox проще.

4. Полное центрирование (X + Y)

Способ 1: Flexbox (лучший)

.parent {
    display: flex;
    align-items: center;
    justify-content: center;
    height: 300px;
}
flex + align-items + justify-content:
flex: полное

Самый простой и универсальный способ.

Способ 2: Grid (самый короткий)

.parent {
    display: grid;
    place-items: center;
    height: 300px;
}
grid + place-items: center:
grid: place-items

Самый короткий: одна строка — и по X, и по Y.

Способ 3: position: absolute + transform

.parent {
    position: relative;
}

.box {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}
absolute + top/left 50% + translate(-50%, -50%):
absolute: полное

Способ 4: position: absolute + inset + margin: auto

.parent {
    position: relative;
}

.box {
    position: absolute;
    inset: 0;
    width: 200px;
    height: 100px;
    margin: auto;
}
absolute + inset 0 + margin auto:
absolute: inset+margin
Преимущество: не нужен transform, можно анимировать width/height без искажений. Но нужны width и height.

5. Сравнение способов

Способ Горизонталь Вертикаль Полное
text-align: center ✅ (только inline) ❌ ❌
margin: 0 auto ✅ ❌ ❌
Flexbox ✅ ✅ ✅
Grid ✅ ✅ ✅ (1 строка)
absolute + transform ✅ ✅ ✅
absolute + inset + margin ✅ ✅ ✅ (нужны размеры)

6. Что выбрать

Задача Лучший способ
Текст по центру text-align: center
Блок по центру (с width) margin: 0 auto
Элемент в flex-контейнере align-items + justify-content
Полное центрирование display: grid; place-items: center
Центрирование поверх (модалка) position: absolute + transform
Современный стандарт: для полного центрирования — display: grid; place-items: center. Одна строка, работает везде.

10. Частые ошибки

Ошибка Почему плохо
text-align: center для блока Центрирует содержимое, не блок. Для блока — margin: 0 auto
margin: 0 auto без width Не работает — блок и так на всю ширину
vertical-align: middle для div Не работает — только для inline/table-cell
position: absolute без relative родителя Центрируется относительно <body>
absolute + transform для анимации размеров Искажает. Для анимации — inset + margin: auto
Забыть min-height для полного центрирования Нечего центрировать — высота 0

11. Шпаргалка

/* Горизонтальное */
text-align: center;              /* inline */
margin: 0 auto;                  /* block с width */
justify-content: center;         /* flex */

/* Вертикальное */
align-items: center;             /* flex */

/* Полное — самый короткий */
display: grid;
place-items: center;

/* Полное — flex */
display: flex;
align-items: center;
justify-content: center;

/* Полное — absolute */
position: absolute;
top: 50%;
left: 50%;
transform: translate(-50%, -50%);

/* Полное — absolute + inset */
position: absolute;
inset: 0;
width: 200px;
height: 100px;
margin: auto;

12. Что запомнить из урока

  • Горизонтальное — text-align (inline), margin: 0 auto (block), justify-content (flex).
  • Вертикальное — align-items: center (flex).
  • Полное — display: grid; place-items: center (самый короткий).
  • Полное (flex) — align-items + justify-content.
  • Полное (absolute) — top: 50%; left: 50%; transform: translate(-50%, -50%).
  • margin: 0 auto — только с width.
  • text-align: center — только для inline-содержимого.
  • Не используй vertical-align для блочных — не работает.
  • Для модалок — display: grid; place-items: center.
  • Для hero — flex или grid.

CSS Урок 24. Координаты

1. Что такое координаты

Координаты — это четыре свойства: top, right, bottom, left. Они задают отступ от края контейнера.

Работают только если у элемента position — relative, absolute, fixed или sticky. У static — игнорируются.

Свойство Что задаёт
topОтступ от верхнего края
rightОтступ от правого края
bottomОтступ от нижнего края
leftОтступ от левого края

2. Базовый пример: absolute + координаты

.parent {
    position: relative;
    height: 300px;
}

.child {
    position: absolute;
    top: 20px;
    left: 40px;
    /* прижат к левому верхнему углу, но с отступами */
}
absolute + top: 20px, left: 40px:
top: 20px; left: 40px;

3. Прижатие к углам

Если задать только одно из top/bottom — элемент прижат к этому краю. То же с left/right. 

/* Правый верхний угол */
.box1 {
    position: absolute;
    top: 10px;
    right: 10px;
}

/* Левый нижний угол */
.box2 {
    position: absolute;
    bottom: 10px;
    left: 10px;
}
4 угла:
top/left
top/right
bottom/left
bottom/right

4. Растягивание через координаты

Если задать два противоположных координаты (top + bottom или left + right) — элемент растянется между ними. 

.box {
    position: absolute;
    top: 20px;
    bottom: 20px;
    left: 20px;
    right: 20px;
    /* займёт всё пространство родителя с отступами 20px */
}
Растягивание через все 4 координаты:
top:20 / right:20 / bottom:20 / left:20

Прижатие к ширине родителя

.bar {
    position: absolute;
    left: 0;
    right: 0;   /* ← растянуто по всей ширине */
    bottom: 0;
    height: 40px;
}
Полоса внизу (left: 0; right: 0):
left: 0; right: 0 — во всю ширину

5. Центрирование

Способ 1: через transform

.center {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}
Центрирование через transform:
по центру

Способ 2: через inset и margin: auto

.center {
    position: absolute;
    inset: 0;              /* top: 0; right: 0; bottom: 0; left: 0 */
    width: 200px;
    height: 100px;
    margin: auto;          /* ← центрирует */
}
Центрирование через inset + margin: auto:
inset: 0; margin: auto
Преимущество способа 2: не нужен transform, можно анимировать width/height без искажений.

6. inset — сокращение

inset — это shorthand для top: right: bottom: left. Работает так же, как margin: 

.box {
    inset: 10px;                    /* все 10px */
    inset: 10px 20px;               /* верх/низ 10, право/лево 20 */
    inset: 10px 20px 30px;          /* верх 10, право/лево 20, низ 30 */
    inset: 10px 20px 30px 40px;     /* верх право низ лево */
}
inset: 10px 20px (верх/низ 10, право/лево 20):
inset: 10px 20px

7. relative + координаты

С relative координаты сдвигают элемент относительно его обычного места. Место в потоке сохраняется. 

.box {
    position: relative;
    top: 20px;
    left: 30px;
    /* сдвинут, но место под него осталось */
}
relative: top: 20px; left: 30px:
обычный блок
relative: top 20, left 30
обычный блок (место relative сохранено)
Когда relative + координаты:
  • Сдвинуть элемент на пару пикселей (hover-эффект).
  • Создать контекст для absolute детей (главное — без координат).
  • Не используй для сложной раскладки — лучше Flexbox/Grid.

8. fixed + координаты

С fixed координаты работают относительно окна браузера. 

/* Шапка сверху */
.header {
    position: fixed;
    top: 0;
    left: 0;
    right: 0;
}

/* Кнопка в правом нижнем углу */
.chat {
    position: fixed;
    bottom: 20px;
    right: 20px;
}
Совет: для «прижать к верху на всю ширину» используй left: 0; right: 0 (или inset: 0 0 auto 0), а не width: 100% (последнее может дать скроллбар).

9. sticky + координаты

Со sticky координаты задают, к какому краю «прилипнуть». Обязательно нужен хотя бы один. 

.sticky {
    position: sticky;
    top: 20px;   /* прилипнет, когда верх элемента будет в 20px от верха окна */
}
Не работает без координат: position: sticky без top (или bottom/left/right) — не «прилипнет».

10. Что происходит с размерами

Если задать два противоположных координаты (top + bottom или left + right) — размер по этой оси вычисляется. 

.box {
    position: absolute;
    top: 20px;
    bottom: 20px;
    /* высота = родитель - 40px */
}

.box {
    position: absolute;
    left: 0;
    right: 0;
    /* ширина = родитель */
}
Внимание: если задан height или width — координаты не растянут элемент. Растягивание работает, только когда размер по этой оси не задан (auto).

11. Практика: карточка с иконкой в углу

}

13. Частые ошибки

Ошибка Почему плохо
Координаты без position Не работают
top + bottom + height Растягивание не работает — размер задан
Задать top, но не задать left у absolute Элемент «зависает» в неожиданном месте
left: 0; right: 0 + width: 100% Может дать горизонтальный скроллбар
sticky без top Не «прилипает»
absolute без relative родителя Координаты относительно <body>, а не родителя

14. Что запомнить из урока

  • top, right, bottom, left — координаты. Работают только с position ≠ static.
  • Одна координата → прижатие к краю.
  • Две противоположные → растягивание между ними.
  • inset — shorthand для всех четырёх.
  • Центрирование: top: 50%; left: 50%; transform: translate(-50%, -50%).
  • Центрирование 2: inset: 0; margin: auto; width; height.
  • relative + координаты — сдвиг, место сохранено.
  • fixed + координаты — относительно окна.
  • sticky + координаты — «прилипание». Нужен хотя бы один.
  • Растягивание работает, только если размер (width/height) — auto.

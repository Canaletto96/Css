2. background-color — цвет фона

.box {
    background-color: #1565c0;
    /* или */
    background-color: rgb(21, 101, 192);
    /* или */
    background-color: hsl(210, 80%, 42%);
}
Разные цвета фона:
background-color — самый простой фон. Значения: любой цвет (HEX, RGB, HSL, named). По умолчанию — transparent.

3. background-image — картинка или градиент

Задаёт фоновое изображение или градиент.

/* Картинка по URL */
.box {
    background-image: url("image.jpg");
}

/* Градиент */
.box {
    background-image: linear-gradient(135deg, #1565c0, #42a5f5);
}

/* Несколько фонов */
.box {
    background-image: url("overlay.png"), url("bg.jpg");
}
Градиент как фон:
URL в кавычках: url("image.jpg"). Кавычки не обязательны, но с ними надёжнее (особенно если в пути есть пробелы).

4. background-repeat — повтор

По умолчанию картинка повторяется, чтобы заполнить весь блок.

Значение Что делает

no-repeatНе повторять
repeat-xТолько по горизонтали
repeat-yТолько по вертикали
spaceПовторять с равными промежутками
roundПовторять с масштабированием
repeat (по умолчанию) — картинка повторяется:

5. background-size — размер

Как масштабировать фоновую картинку.

Значение Что делает
auto (по умолчанию)Оригинальный размер
coverЗаполнить весь блок, обрезая края
containВписать целиком, могут быть пустые места
100px 50pxШирина 100px, высота 50px
50% autoШирина 50%, высота пропорционально
100% 100%Растянуть на весь блок (искажает)
background-size: cover — заполняет весь блок:
background-size: contain — вписывается целиком:
cover vs contain:
  • cover — заполнить весь блок (края могут обрезаться).
  • contain — вписать целиком (могут быть пустые места).
Для фоновых фотографий — cover. Для логотипов — contain.

7. background-attachment — прикрепление

Прокручивается ли фон вместе с контентом.

Значение Что делает
scroll (по умолчанию)Прокручивается с контентом
fixedФон «прибит» к окну — не прокручивается
localПрокручивается с содержимым элемента (для overflow)
 
.parallax {
    background-image: url("bg.jpg");
    background-attachment: fixed;
    background-size: cover;
}
Осторожно с fixed: на мобильных работает плохо (может тормозить). Используй только для десктопа или через @media отключай.

8. Несколько фонов

Можно задать несколько фонов через запятую. Каждый — со своими настройками.

.box {
    background-image:
        url("overlay.png"),
        url("bg.jpg");
    background-position:
        top left,
        center;
    background-repeat:
        no-repeat,
        no-repeat;
    background-size:
        100px 100px,
        cover;
}
Два фона: красная точка сверху-слева, синяя снизу-справа:
Порядок: первый фон — сверху, последний — снизу. Как слои в Photoshop.

9. Shorthand background

Сокращённая запись всех свойств:

.box {
    background: #1565c0 url("bg.jpg") no-repeat center / cover;
    /*          ↑      ↑              ↑        ↑        ↑
            цвет   картинка       повтор   позиция   размер */
}
Часть Что
#1565c0background-color
url("bg.jpg")background-image
no-repeatbackground-repeat
centerbackground-position
/ coverbackground-size (через /)
Осторожно с background: он сбрасывает все свойства фона, которые не указаны. Если хочешь только изменить цвет — используй background-color, а не background.

10. background-clip — обрезка

Где заканчивается фон — на границе content, padding или border.

Значение Что делает
border-box (по умолчанию)Фон до границы border
padding-boxФон до границы padding
content-boxФон только под содержимым
textФон внутри текста (текст как «маска»)
 
.text-gradient {
    background: linear-gradient(135deg, #1565c0, #e53935);
    -webkit-background-clip: text;
    background-clip: text;
    color: transparent;
}
background-clip: text — градиент внутри текста:

Градиентный текст

Крутой эффект: background-clip: text + color: transparent — текст становится «градиентным». Требует префикс -webkit- в некоторых браузерах.

11. Практика: hero-блок с фоном

*, *::before, *::after {
    box-sizing: border-box;
}

.hero {
    height: 400px;
    background-image: url("hero.jpg");
    background-size: cover;
    background-position: center;
    background-repeat: no-repeat;
    display: flex;
    align-items: center;
    justify-content: center;
    border-radius: 12px;
    position: relative;
}

.hero::before {
    content: "";
    position: absolute;
    inset: 0;
    background: rgba(0, 0, 0, 0.4);
    border-radius: 12px;
}

.hero h1 {
    position: relative;
    color: white;
    font-size: 2.5rem;
    text-align: center;
}

12. Частые ошибки

Ошибка Почему плохо
Забыть no-repeat Картинка повторяется, выглядит как «плитка»
background-size: 100% 100% Искажает пропорции картинки
background-attachment: fixed на мобильных Тормозит
background вместо background-color Сбрасывает все остальные свойства фона
URL без кавычек с пробелами Не работает
background-clip: text без color: transparent Эффект не виден

13. Что запомнить из урока

  • background-color — цвет заливки.
  • background-image — картинка или градиент через url().
  • background-repeat — repeat (по умолчанию), no-repeat.
  • background-size — cover (заполнить), contain (вписать).
  • background-position — center, left top, проценты, пиксели.
  • background-attachment — scroll, fixed (осторожно на мобильных).
  • Несколько фонов — через запятую, первый сверху.
  • background — shorthand. Сбрасывает всё!
  • background-clip: text + color: transparent — градиентный текст.
  • Для фоновых фото — cover. Для логотипов — contain.

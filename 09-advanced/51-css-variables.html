CSS Урок 51. CSS-переменные

1. Что такое CSS-переменные

CSS-переменные (custom properties) — это значения, которые можно переиспользовать в CSS. Как переменные в JS, но для стилей. 

:root {
    --primary: #1565c0;
    --radius: 8px;
}

.button {
    background: var(--primary);
    border-radius: var(--radius);
}
Зачем:
  • Переиспользование — цвет в одном месте.
  • Легко менять — изменить одно значение → обновится везде.
  • Темы — светлая / тёмная.
  • Динамика — можно менять через JS.

2. Синтаксис

Объявление — --имя: значение;

--primary: #1565c0;
--radius: 8px;
--font: system-ui, sans-serif;
--shadow: 0 4px 12px rgba(0, 0, 0, 0.1);
Часть Что означает
--Обязательный префикс
имяЛюбое имя (без пробелов)
:Разделитель
значениеЛюбое CSS-значение
Префикс -- обязателен. Без него — не переменная, а обычное свойство (которого нет в CSS).

Использование — var(--имя)

.button {
    background: var(--primary);
    border-radius: var(--radius);
}

3. :root — где объявлять

:root — это корень документа (<html>). Переменные в :root доступны везде. 

:root {
    --primary: #1565c0;
    --text: #222;
}
Кнопки, использующие переменные:
Почему :root: переменные в :root доступны всему документу. Это «глобальные» переменные. Можно объявлять и в других селекторах — тогда они будут «локальными».

4. Локальные переменные

Переменные можно объявлять в любом селекторе. Тогда они доступны только внутри этого элемента и его детей. 

.card {
    --card-padding: 20px;
    --card-bg: #fff;
    padding: var(--card-padding);
    background: var(--card-bg);
}

/* Вне .card — переменные недоступны */
Локальные переменные в .theme-demo:
Светлая тема (--theme-bg: #fff)
Тёмная тема (--theme-bg: #1a1a2e)
Сила: один класс .theme-demo — разные темы, потому что переменные переопределены в .dark.

5. Каскад переменных

Переменные наследуются. Если объявить в родителе — доступны детям. Если переопределить в ребёнке — у ребёнка будет новое значение. 

:root {
    --color: blue;
}

.parent {
    --color: red;   /* переопределяем для родителя и детей */
}

.child {
    color: var(--color);   /* red (от родителя) */
}

.sibling {
    color: var(--color);   /* blue (от :root) */
}
Каскад:
.sibling — синий (от :root)
.parent с --primary: #e53935 — красный
.child — тоже красный (унаследовал)

6. var() с fallback

Если переменная не задана — можно указать запасное значение: 

.button {
    color: var(--text-color, #222);   /* если --text-color нет — #222 */
}

/* Fallback тоже может быть var() */
.button {
    color: var(--text-color, var(--default-color, #222));
}
Fallback (переменная не задана):
Цвет через var(--nonexistent, var(--secondary)) — красный

7. Изменение через JavaScript

CSS-переменные можно менять из JS — это делает их мощными для динамики. 

// Читать
const color = getComputedStyle(document.documentElement)
    .getPropertyValue('--primary');

// Менять
document.documentElement.style.setProperty('--primary', '#e53935');

// Или на конкретном элементе
element.style.setProperty('--primary', '#43a047');

9. Практика: тема через переменные

/* Светлая тема (по умолчанию) */
:root {
    --bg: #fafafa;
    --text: #222;
    --card-bg: #fff;
}

/* Тёмная тема */
[data-theme="dark"] {
    --bg: #1a1a2e;
    --text: #f0f0f0;
    --card-bg: #16213e;
}

body {
    background: var(--bg);
    color: var(--text);
}

.card {
    background: var(--card-bg);
}

12. Частые ошибки

Ошибка Почему плохо
Забыть -- при объявлении Не переменная, а невалидное свойство
Забыть var() при использовании background: --primary; — не работает
Объявлять всё в :root без причины Загрязняет глобальную область. Для компонентов — локально
Использовать переменные для всего Для одноразовых значений — px проще
Забыть про fallback Если переменная не задана — свойство «сломается»

13. Что запомнить из урока

  • CSS-переменные — --имя: значение;.
  • Использование — var(--имя).
  • :root — для глобальных переменных.
  • Локальные — в любом селекторе.
  • Каскад — переменные наследуются, можно переопределять.
  • Fallback — var(--имя, запасное).
  • JS — setProperty('--имя', 'значение').
  • Темы — переопределить переменные в [data-theme="dark"].
  • Для чего: цвета, размеры, отступы, тени, шрифты, z-index.
  • Не для всего — для одноразовых значений не нужно.

CSS Урок 47. Псевдоэлементы

1. Что такое псевдоэлементы

Псевдоэлемент — это «виртуальный» элемент, которого нет в HTML. Начинается с :: (два двоеточия). 

.box::before { content: "→"; }    /* вставить перед содержимым */
.box::after { content: "←"; }     /* вставить после */
p::first-letter { font-size: 2em; }  /* первая буква */
Псевдокласс vs псевдоэлемент:
  • Псевдокласс — :hover (одно :).
  • Псевдоэлемент — ::before (два ::).

2. ::before и ::after — вставка контента

Самые важные псевдоэлементы. Позволяют вставить контент до или после содержимого элемента без HTML. 

.element::before {
    content: "текст";   /* ← обязательное свойство */
    /* другие стили */
}

.element::after {
    content: "текст";
}
Обязательное свойство: content. Без него ::before и ::after не работают. Если не нужен текст — content: "".

Пример: кавычки вокруг цитаты

.quote::before { content: "«"; }
.quote::after { content: "»"; }

3. ::first-letter — первая буква

Стилизует первую букву блока. Классика для статей («буквица»). 

p::first-letter {
    font-size: 3em;
    font-weight: bold;
    float: left;
    margin-right: 8px;
}
Буквица:

Этот параграф начинается с большой буквы. Остальной текст идёт обычным шрифтом. Так делают в книгах и журналах для красоты.

Ограничение: работает только для блочных элементов (p, div, h1). Для span (inline) — не работает.

4. ::first-line — первая строка

Стилизует первую строку текста. Ширина строки зависит от ширины блока — если окно изменится, «первая строка» может измениться. 

p::first-line {
    font-weight: bold;
    color: #1565c0;
}
Первая строка выделена:

Эта первая строка выделена жирным и синим. Остальной текст идёт обычным шрифтом. Сузь окно — первая строка изменится, потому что в неё войдёт разное количество слов.

5. ::selection — выделение

Стилизует выделенный текст (когда пользователь выделяет мышью). 

::selection {
    background: #ffeb3b;
    color: #000;
}
Выдели текст:

Выдели этот текст — увидишь жёлтый фон. Так делают для брендирования.

9. Практика: анимированное подчёркивание

.link {
    position: relative;
    text-decoration: none;
}

.link::after {
    content: "";
    position: absolute;
    bottom: -2px;
    left: 0;
    width: 0;
    height: 2px;
    background: currentColor;
    transition: width 0.3s;
}

.link:hover::after {
    width: 100%;
}

10. Практика: кастомный чекбокс

.custom-checkbox input[type="checkbox"] {
    display: none;
}

.custom-checkbox label::before {
    content: "";
    width: 20px;
    height: 20px;
    border: 2px solid #1565c0;
    border-radius: 4px;
    display: inline-block;
}

.custom-checkbox input:checked + label::before {
    content: "✓";
    background: #1565c0;
    color: white;
    text-align: center;
    line-height: 20px;
}

11. ::before и ::after — правила

Важно:
  • content обязателен — без него не работает.
  • Нельзя использовать на <img>, <input>, <br> — у них нет содержимого.
  • Нельзя клонировать HTML-контент — только текст и стили.
  • Screen reader может прочитать content — используй aria-hidden.
  • Не для важного контента — ::before не индексируется Google.

12. Частые ошибки

Ошибка Почему плохо
Забыть content Псевдоэлемент не работает
Использовать ::before для важного контента Google не индексирует, screen reader может не прочитать
::before на <img> Не работает — у img нет содержимого
Забыть display: block для ::after с размерами Псевдоэлемент не отображается
Путать : и :: Псевдокласс vs псевдоэлемент

13. Что запомнить из урока

  • Псевдоэлемент — ::before (два ::).
  • ::before — вставить до содержимого.
  • ::after — вставить после.
  • content — обязателен для ::before / ::after.
  • ::first-letter — первая буква (буквица).
  • ::first-line — первая строка.
  • ::selection — выделенный текст.
  • ::placeholder — placeholder в input.
  • ::marker — маркер списка.
  • Не используй для важного контента — не индексируется.

CSS Урок 3. Синтаксис CSS

1. Анатомия CSS-правила

Любое CSS-правило состоит из четырёх частей:

h1 {
    color: blue;
    font-size: 32px;
}
Часть Что это В примере
Селектор Кого стилизуем h1
Свойство Что меняем color, font-size
Значение На что меняем blue, 32px
Фигурные скобки Границы правила { }
Точка с запятой Конец объявления ;

2. Объявление (declaration)

Объявление — это одна пара свойство: значение; внутри блока. 

h1 {
    color: blue;         /* ← это объявление */
    font-size: 32px;     /* ← это второе объявление */
    text-align: center;  /* ← третье */
}

В одном правиле может быть сколько угодно объявлений. Каждое — с новой строки (для читаемости).

3. Точка с запятой

Обязательна после каждого объявления. Если забыть — следующее объявление не применится.

Ошибка: 
h1 {
    color: blue        /* ← нет ; */
    font-size: 32px;
}
Браузер прочитает это как color: blue font-size: 32px — невалидное значение. Оба свойства не применятся.

Исключение: последнее объявление в блоке может быть без ;. Но лучше ставить всегда — меньше ошибок при добавлении новых.

4. Пробелы и переносы строк

CSS игнорирует лишние пробелы и переносы. Эти три записи эквивалентны: 

/* Вариант 1: сжато */
h1{color:blue;font-size:32px;}

/* Вариант 2: с пробелами */
h1 { color: blue; font-size: 32px; }

/* Вариант 3: с переносами (рекомендуется) */
h1 {
    color: blue;
    font-size: 32px;
}

Рекомендуется вариант 3 — читается легче, легче искать ошибки, удобно для git.

5. Регистр

CSS не чувствителен к регистру для свойств и значений, но чувствителен для селекторов (если это класс или id). 

/* Эквивалентны: */
h1 { COLOR: BLUE; }
h1 { color: blue; }

/* НЕ эквивалентны: */
.my-class { color: red; }   /* класс .my-class */
.my-Class { color: red; }   /* класс .my-Class — другой! */

Правило: свойства и значения — строчными (стандарт). Селекторы — как в HTML.

6. Несколько селекторов — одно правило

Через запятую можно применить одно правило к нескольким селекторам:

h1, h2, h3 {
    color: #333;
    font-family: system-ui, sans-serif;
}

Это применится и к h1, и к h2, и к h3.

7. Вложенность правил

Правила не вкладываются друг в друга (как в Sass/LESS). Каждое правило — самостоятельное. 

/* ПРАВИЛЬНО */
h1 {
    color: blue;
}
h1 span {
    color: red;
}

/* НЕПРАВИЛЬНО (это из Sass, не работает в чистом CSS) */
h1 {
    color: blue;
    span {
        color: red;
    }
}
Современный CSS (с 2023) поддерживает вложенность: h1 { & span { color: red; } }. Но пока это не везде. Пока используй обычную запись.

8. Комментарии

/* Это комментарий */

h1 {
    color: blue;          /* синий заголовок */
    /* font-size: 32px;   — пока закомментировано */
}
Что Синтаксис
Однострочный /* текст */
Многострочный /* строка 1
строка 2 */
Внутри правила color: blue; /* комментарий */
Нельзя использовать // (это JavaScript). Только /* */.

9. Сокращённая запись (shorthand)

Многие свойства имеют сокращённую запись — когда одно свойство заменяет несколько.

Пример: margin

/* Подробно (4 свойства) */
.box {
    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 10px;
    margin-left: 20px;
}

/* Сокращённо (1 свойство) */
.box {
    margin: 10px 20px 10px 20px;   /* верх право низ лево */
}

/* Ещё короче */
.box {
    margin: 10px 20px;   /* верх/низ 10px, право/лево 20px */
}

Правила сокращения margin:

Запись Значение
margin: 10px; Все стороны 10px
margin: 10px 20px; Верх/низ 10px, право/лево 20px
margin: 10px 20px 30px; Верх 10px, право/лево 20px, низ 30px
margin: 10px 20px 30px 40px; Верх 10, право 20, низ 30, лево 40 (по часовой)

Мнемоника: «Верх — Право — Низ — Лево» = «ТРБЛ» (по часовой стрелке).

Другие частые shorthand

Shorthand Заменяет
padding padding-top, -right, -bottom, -left
border border-width, border-style, border-color
background background-color, -image, -position и др.
font font-style, font-weight, font-size, font-family

10. Частые ошибки синтаксиса

Ошибка Пример Правильно
Забыть ; color: blue color: blue;
Забыть { } h1 color: blue; h1 { color: blue; }
Забыть : color blue; color: blue;
Использовать // // комментарий /* комментарий */
Использовать = вместо : color = blue; color: blue;
Пробел в имени свойства font size: 16px; font-size: 16px;
Забыть единицу измерения font-size: 32; font-size: 32px; (кроме 0)
Кавычки в неверном месте color: "blue"; color: blue;
Вложенные правила h1 { span { color: red; } } h1 span { color: red; }

11. Как браузер обрабатывает ошибки

CSS — устойчив к ошибкам. Если браузер встречает ошибку, он пропускает её и идёт дальше. 

h1 {
    color: blue;
    color: wrong-value;   /* ← невалидное значение — пропущено */
    font-size: 32px;      /* ← это применится! */
}

Результат: color: blue и font-size: 32px применятся. Строка с ошибкой — проигнорируется.

Плюс: одна ошибка не ломает всю страницу.
Минус: ошибку можно не заметить. Проверяй в DevTools (F12 → Elements → Styles) — там видно, какие правила применились, а какие перечёркнуты.

12. Стиль кода

Хорошие практики оформления CSS:

/* ✅ ХОРОШО */
h1 {
    color: blue;
    font-size: 32px;
    margin-bottom: 16px;
}

/* ❌ ПЛОХО: всё в одну строку */
h1 { color: blue; font-size: 32px; margin-bottom: 16px; }

/* ❌ ПЛОХО: без отступов */
h1 {
color: blue;
font-size: 32px;
}

Правила:

  • Открывающая { — на строке селектора.
  • Свойства — с новой строки, с отступом 2 или 4 пробела.
  • После : — один пробел.
  • После ; — конец строки.
  • Закрывающая } — на новой строке.
  • Между правилами — пустая строка (для читаемости).

13. Что запомнить из урока

  • Правило = селектор + { свойство: значение; }.
  • Точка с запятой обязательна после каждого объявления (кроме последнего, но лучше всегда).
  • Пробелы и переносы CSS игнорирует — пиши для читаемости.
  • Регистр: свойства и значения — строчными. Селекторы — как в HTML.
  • Несколько селекторов через запятую — одно правило для всех.
  • Комментарии — /* */, не //.
  • Shorthand — сокращённая запись: margin: 10px 20px вместо четырёх свойств.
  • Порядок в margin/padding: верх → право → низ → лево (по часовой).
  • Ошибки браузер пропускает — проверяй в DevTools.
  • Стиль: каждое свойство с новой строки, с отступом.

CSS Урок 8. Цвет

1. Способы задать цвет

В CSS есть 5 способов задать цвет:

Способ Пример Когда
Named (именованные) red, blue, rebeccapurple Быстро, для теста
HEX #ff0000, #f00 Основной способ
RGB / RGBA rgb(255, 0, 0), rgba(255, 0, 0, 0.5) Когда нужна прозрачность
HSL / HSLA hsl(0, 100%, 50%), hsla(0, 100%, 50%, 0.5) Интуитивно, для тем
currentColor currentColor Наследует color родителя

2. Именованные цвета (named colors)

CSS знает 148 именованных цветов. Самые частые:

Основные:
red
blue
green
yellow
black
white
orange
purple
gray
transparent

Также есть странные имена: rebeccapurple, papayawhip, tomato, dodgerblue.

Плюс: читаемо.
Минус: только 148 цветов. Для дизайна — мало.

3. HEX — шестнадцатеричный

Самый популярный способ. Цвет записывается как #RRGGBB, где каждая пара — красный, зелёный, синий (00–FF). 

#ff0000   /* красный */
#00ff00   /* зелёный */
#0000ff   /* синий */
#ffffff   /* белый */
#000000   /* чёрный */

Сокращённая запись

Если каждая пара — одинаковые символы, можно сократить:

#ff0000   →   #f00
#00ff00   →   #0f0
#ffffff   →   #fff
#000000   →   #000
#aabbcc   →   #abc

HEX с прозрачностью (8 знаков)

Современный формат #RRGGBBAA — последняя пара задаёт прозрачность:

#ff0000ff   /* красный, непрозрачный */
#ff000080   /* красный, 50% прозрачности */
#ff000000   /* красный, полностью прозрачный */
HEX с прозрачностью:
#ff0000
#ff000080
#ff000040
#ff00001a

Как читать HEX

HEX R G B Цвет
#ff0000 255 0 0 Красный
#00ff00 0 255 0 Зелёный
#0000ff 0 0 255 Синий
#ffff00 255 255 0 Жёлтый
#ff00ff 255 0 255 Маджента
#00ffff 0 255 255 Циан
#808080 128 128 128 Серый
Совет: HEX — основной способ. Все дизайнеры дают цвета в HEX. Используй его по умолчанию.

4. RGB — красный, зелёный, синий

Каждый канал — от 0 до 255. Смешивая три канала, получаешь цвет. 

rgb(255, 0, 0)       /* красный */
rgb(0, 255, 0)       /* зелёный */
rgb(0, 0, 255)       /* синий */
rgb(255, 255, 255)   /* белый */
rgb(0, 0, 0)         /* чёрный */
rgb(128, 128, 128)   /* серый */
RGB-каналы:
R: 255
G: 0
B: 0

= rgb(255, 0, 0) =

Современный синтаксис

С 2020 можно писать без запятых:

rgb(255 0 0)
rgb(255 0 0 / 0.5)    /* с прозрачностью */
Старый синтаксис (rgb(255, 0, 0)) работает везде. Новый (rgb(255 0 0 / 0.5)) — только в современных браузерах. Используй старый для совместимости.

5. RGBA — RGB с прозрачностью

rgba() — то же, что rgb(), но добавляет альфа-канал (прозрачность) от 0 до 1. 

rgba(255, 0, 0, 1)      /* красный, непрозрачный */
rgba(255, 0, 0, 0.5)    /* красный, 50% прозрачности */
rgba(255, 0, 0, 0)      /* красный, полностью прозрачный */
RGBA с разной прозрачностью (на фоне полосок):
1.0
0.75
0.5
0.25
0.1

RGBA vs opacity

rgba() opacity
Что делает прозрачным Только цвет (фон, текст) Всё: фон, текст, границы, тени
Наследуется Нет Да (дети тоже прозрачные)
Когда Полупрозрачный фон Полупрозрачный блок целиком

6. HSL — оттенок, насыщенность, светлота

HSL (Hue, Saturation, Lightness) — интуитивно понятный способ:

  • Hue (оттенок) — 0–360°. 0 = красный, 120 = зелёный, 240 = синий.
  • Saturation (насыщенность) — 0–100%. 0% = серый, 100% = насыщенный.
  • Lightness (светлота) — 0–100%. 0% = чёрный, 50% = нормальный, 100% = белый.
hsl(0, 100%, 50%)      /* чистый красный */
hsl(120, 100%, 50%)    /* чистый зелёный */
hsl(240, 100%, 50%)    /* чистый синий */
hsl(0, 0%, 50%)        /* серый */
hsl(0, 0%, 0%)         /* чёрный */
hsl(0, 0%, 100%)       /* белый */
HSL-круг (оттенки 0–360):
hsl(0, 100%, 50%)
hsl(60, 100%, 50%)
hsl(120, 100%, 50%)
hsl(180, 100%, 50%)
hsl(240, 100%, 50%)
hsl(300, 100%, 50%)
Изменение насыщенности (S) и светлоты (L):
S: 100%, L: 50%
S: 50%, L: 50%
S: 100%, L: 80%
S: 100%, L: 20%
S: 0%, L: 50%
с прозрачностью

HSLA

hsla(0, 100%, 50%, 0.5)   /* красный с 50% прозрачности */

Или в современном синтаксисе: hsl(0 100% 50% / 0.5).

Почему HSL удобен

В HSL легко сделать оттенки одного цвета, меняя только насыщенность или светлоту: 

/* Один цвет, разные состояния */
:root {
    --primary: hsl(210, 80%, 50%);
    --primary-hover: hsl(210, 80%, 40%);
    --primary-light: hsl(210, 80%, 80%);
    --primary-dark: hsl(210, 80%, 20%);
}
Палитра из одного цвета:
L: 20%
L: 40%
L: 50%
L: 80%
Рекомендую: для дизайн-систем — HSL. Для точного цвета — HEX. Для прозрачности — RGBA или HEX с альфой.

7. currentColor

currentColor — это значение color текущего элемента. Полезно, когда нужно согласовать цвета: 

.card {
    color: #1565c0;
    border: 2px solid currentColor;   /* рамка того же цвета, что текст */
}

.card:hover {
    color: #e53935;                    /* меняется только color */
    /* рамка автоматически станет красной */
}
currentColor — рамка повторяет цвет текста:
Этот блок имеет color: #1565c0 и border: 2px solid currentColor. Рамка автоматически того же цвета.

8. Функции цвета

Некоторые функции для работы с цветом:

Функция Что делает
rgb(), rgba() Цвет в RGB
hsl(), hsla() Цвет в HSL
color-mix() Смешать два цвета (новое) 
color-mix(in srgb, red 50%, blue 50%)   /* смесь красного и синего */

Поддержка пока не везде. Но полезно знать.

10. Частые ошибки

Ошибка Почему плохо
#f60 вместо #ff6600 Работает, но читается хуже
color: #ff0000f 5 знаков — невалидно. Нужно 3 или 6 (или 8 для альфы)
rgb(255, 0, 0, 0.5) 4-й аргумент работает только в современном синтаксисе. Используй rgba()
hsl(0, 100, 50) Забыть % для S и L
rgba(255, 0, 0, 50%) Альфа — от 0 до 1, не проценты (кроме нового синтаксиса)
Слишком низкий контраст Плохо для доступности (минимум 4.5:1)

11. Что запомнить из урока

  • 5 способов: named, HEX, RGB, HSL, currentColor.
  • HEX — основной. #ff0000 или #f00. 8 знаков — с альфой.
  • RGB — 0–255 для каждого канала.
  • RGBA — то же + прозрачность 0–1.
  • HSL — hue (0–360), saturation (0–100%), lightness (0–100%).
  • HSLA — HSL + прозрачность.
  • currentColor — наследует color элемента.
  • rgba() — прозрачный только цвет.
  • opacity — прозрачный весь элемент.
  • HSL удобен для создания палитр одного цвета.
  • HEX — для точного цвета из дизайна.
  • RGBA/HSLA — для прозрачности.

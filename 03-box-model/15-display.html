CSS Урок 15. display

1. Что такое display

display определяет как элемент ведёт себя в потоке: занимает ли всю ширину, может ли стоять в строке с другими элементами, можно ли задавать размеры.

Основные значения:

Значение Что означает
blockБлочный — вся ширина, новая строка
inlineСтрочный — по содержимому, в строке
inline-blockГибрид — в строке, но можно задавать размеры
noneСкрыть полностью (убрать из потока)
flexFlexbox-контейнер (урок 27)
gridGrid-контейнер (урок 33)
table, table-cellКак таблица (редко)
contents«Растворить» элемент, оставив детей

2. display: block — блочный

Занимает всю ширину родителя. Начинается с новой строки. Можно задавать width, height, все margin и padding. 

.box {
    display: block;
    width: 200px;
    height: 100px;
    margin: 16px;
    padding: 20px;
}

По умолчанию block:

  • <div>, <p>, <h1>–<h6>
  • <ul>, <ol>, <li>
  • <section>, <article>, <header>, <footer>, <nav>, <main>
  • <form>, <fieldset>, <table>
  • <blockquote>, <pre>, <hr>
Три блока display: block — каждый на новой строке:

Блок 2
Блок 3

3. display: inline — строчный

Занимает только ширину содержимого. Стоит в строке с другими. Нельзя задавать width, height, вертикальные margin. 

.text {
    display: inline;
    /* width: 200px;  ← не работает */
    /* height: 100px; ← не работает */
    /* margin-top: 20px; ← не работает */
    /* padding-top: 20px; ← работает визуально, но не сдвигает строки */
}

По умолчанию inline:

  • <span>, <a>, <strong>, <em>, <b>, <i>
  • <code>, <small>, <mark>, <sub>, <sup>
  • <br>, <img> (по факту inline, но с размерами)
  • <input>, <button>, <select> (по факту inline-block)
Три inline-элемента — в одной строке:

Текст до. inline 1 inline 2 inline 3 Текст после.

4. display: inline-block — гибрид

Стоит в строке (как inline), но можно задавать размеры (как block). 

.card {
    display: inline-block;
    width: 120px;
    height: 60px;
    padding: 8px;
    margin: 4px;
}
inline-block — в строке, но с размерами:
inline-block 1
inline-block 2
inline-block 3

Когда использовать inline-block

  • Кнопки в ряд.
  • Карточки в сетке (до Grid).
  • Иконки рядом с текстом.
  • Навигация горизонтальная (до Flexbox).
Современный подход: для рядов элементов используй Flexbox (display: flex), а не inline-block. Flexbox проще и мощнее. inline-block — для случаев, когда нужен именно строчный элемент с размерами.

Проблема inline-block: пробелы

Между inline-block элементами появляется пробел (от переноса строки в HTML). Это может ломать сетку. 

<div class="card">1</div>
<div class="card">2</div>   <!-- пробел между ними -->

Решение: убрать пробел в HTML, или использовать font-size: 0 на родителе, или — Flexbox.

5. display: none — скрыть

Полностью убирает элемент из потока. Он не занимает места, не виден, не доступен для screen reader'ов. 

.hidden {
    display: none;
}

6. display: flex и display: grid

Современные способы раскладки. Подробно — в уроках 27–39. 

.flex-container {
    display: flex;   /* включает Flexbox */
}

.grid-container {
    display: grid;   /* включает Grid */
}
Кратко:
  • Flexbox — для одномерных раскладок (ряд или колонка).
  • Grid — для двумерных (строки и колонки одновременно).
  • inline-block — legacy, заменяется Flexbox.
  • table — legacy, заменяется Grid.

7. display: contents — «растворить»

Элемент «исчезает» из layout, но дети остаются. Полезно, когда обёртка мешает раскладке. 

.wrapper {
    display: contents;
}
display: contents на обёртке (дети ведут себя как прямые дети родителя):
Ребёнок 1
Ребёнок 2

Обёртка с display: contents «исчезла» — дети ведут себя как прямые дети flex-контейнера.

9. Как узнать display элемента

В DevTools (F12) → Elements → выбери элемент → вкладка Computed. Найди display.

Или в Console:

getComputedStyle(document.querySelector('div')).display
// "block"

10. Изменение display — не всегда хорошо

Семантика важнее. Если ты меняешь display тега, подумай, не сломает ли это смысл:
  • <h1> с display: inline — перестанет быть блочным заголовком.
  • <a> с display: block — станет блочной ссылкой (иногда нужно).
  • <button> с display: block — станет на всю ширину.
Менять display — можно, но осознанно.

12. Частые ошибки

Ошибка Почему плохо
Задавать width у inline Не работает. Нужен inline-block или block
Использовать display: none для скрытия при hover Нельзя анимировать. Нужен opacity + visibility
Забывать пробелы в inline-block Сетка «съезжает» из-за пробелов между элементами
Использовать table для раскладки Legacy. Grid/Flexbox лучше
Менять display тега без причины Ломает семантику
display: inline + vertical-align Работает, но лучше inline-block или flex

13. Что запомнить из урока

  • display — определяет поведение элемента в потоке.
  • block — вся ширина, новая строка. Можно задавать размеры.
  • inline — по содержимому, в строке. Нельзя задавать width/height.
  • inline-block — в строке, но можно задавать размеры. Legacy-способ для сеток.
  • none — скрыть полностью (убрать из потока).
  • visibility: hidden — скрыть, но место остаётся.
  • flex — современный способ для рядов. Используй его.
  • grid — современный способ для сеток.
  • contents — «растворить» обёртку, оставив детей.
  • По умолчанию: div, p, h1 — block; span, a — inline; button, input — inline-block.
  • Не меняй display без причины — можно сломать семантику.

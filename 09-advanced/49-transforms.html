CSS Урок 49. Трансформации

1. Что такое transform

Transform — это преобразование элемента: сдвиг, поворот, масштаб, наклон. Не влияет на layout — другие элементы остаются на своих местах. 

.box {
    transform: translate(20px, 0);   /* сдвинуть вправо */
}

.box {
    transform: rotate(45deg);        /* повернуть */
}

.box {
    transform: scale(1.5);           /* увеличить */
}

.box {
    transform: skewX(20deg);         /* наклонить */
}
Почему transform хорош:
  • Не влияет на layout — другие элементы не сдвигаются.
  • Оптимизируется на GPU — плавно.
  • Можно комбинировать несколько преобразований.

2. translate — сдвиг

Сдвигает элемент по X и Y.

/* X и Y */
transform: translate(20px, 10px);

/* Только X */
transform: translateX(20px);

/* Только Y */
transform: translateY(-10px);

/* Проценты (от размера элемента) */
transform: translate(50%, 50%);

/* Одна ось */
transform: translateX(50%);

3. scale — масштаб

Увеличивает или уменьшает элемент.

/* Одинаково по X и Y */
transform: scale(1.5);   /* увеличить в 1.5 раза */
transform: scale(0.5);   /* уменьшить в 2 раза */

/* Разные X и Y */
transform: scale(1.5, 0.5);

/* Одна ось */
transform: scaleX(2);
transform: scaleY(0.5);
Наведи (scale):
scale 1.3
scale 0.7
Важно: scale не меняет layout. Элемент визуально увеличивается, но соседи остаются на местах. Может «наезжать» на другие элементы.

4. rotate — поворот

Поворачивает элемент на угол (по часовой стрелке).

transform: rotate(45deg);     /* на 45 градусов */
transform: rotate(-90deg);    /* на -90 (против часовой) */
transform: rotate(1turn);      /* полный оборот */
transform: rotate(0.5turn);    /* полоборота */
Наведи (rotate):
rotate 45
rotate -45

5. skew — наклон

Наклоняет элемент — как «скошенный» прямоугольник.

transform: skewX(20deg);      /* наклон по X */
transform: skewY(10deg);      /* наклон по Y */
transform: skew(20deg, 10deg); /* оба */
Наведи (skew):
skewX
skewY
Осторожно: skew искажает текст. Для текста — используй rotate.

6. Несколько трансформаций

Можно комбинировать через пробел:

transform: translate(10px, -10px) rotate(15deg) scale(1.2);
Наведи (комбинация):
combo
Порядок важен: rotate(45deg) translate(20px) ≠ translate(20px) rotate(45deg). Трансформации применяются слева направо — как «слои».

7. transform-origin — точка отсчёта

Задаёт точку, относительно которой происходит преобразование. По умолчанию — 50% 50% (центр). 

transform-origin: center;           /* центр (по умолчанию) */
transform-origin: top left;         /* верхний левый угол */
transform-origin: bottom right;     /* нижний правый */
transform-origin: 0 0;              /* левый верхний */
transform-origin: 50% 100%;         /* центр по X, низ по Y */
transform-origin: 20px 80px;        /* точные координаты */

8. Практика: hover-карточка

.card {
    transition: transform 0.3s, box-shadow 0.3s;
}

.card:hover {
    transform: translateY(-8px) scale(1.02);
    box-shadow: 0 12px 32px rgba(0, 0, 0, 0.15);
}

9. Практика: 3D-карточка

С perspective можно делать 3D-эффекты. 

.card-3d {
    perspective: 1000px;   /* ← глубина 3D */
}

.card-3d-inner {
    transition: transform 0.5s;
    transform-style: preserve-3d;
}

.card-3d-inner:hover {
    transform: rotateY(15deg) rotateX(10deg);
}
Наведи на карточку (3D):
3D-карточка
perspective — «глубина» 3D. Чем меньше значение — тем сильнее эффект. perspective: 1000px — норма.

11. Частые ошибки

Ошибка Почему плохо
Использовать transform для layout Layout не меняется — соседи остаются на местах
Забыть transition Трансформация «прыгает»
Путать порядок в комбинациях rotate + translate ≠ translate + rotate
Забыть transform-origin Вращение вокруг центра, а не угла
Только transform, без perspective 3D-эффект не работает

12. Что запомнить из урока

  • transform — преобразование элемента. Не влияет на layout.
  • translate — сдвиг. translateX, translateY.
  • scale — масштаб. scale(1.5), scaleX(2).
  • rotate — поворот. rotate(45deg).
  • skew — наклон. skewX(20deg).
  • Комбинация — через пробел: translate() rotate() scale().
  • Порядок важен — применяются слева направо.
  • transform-origin — точка отсчёта.
  • 3D: perspective, rotateX, rotateY.
  • Для hover — transform: translateY(-4px);.

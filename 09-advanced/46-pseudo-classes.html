CSS Урок 46. Псевдоклассы

1. Что такое псевдоклассы

Псевдокласс — это состояние элемента или уточнение селектора. Начинается с : (одно двоеточие). 

a:hover { color: red; }      /* :hover — при наведении */
li:nth-child(2) { }          /* :nth-child — второй по порядку */
input:focus { }              /* :focus — в фокусе */
Псевдокласс vs псевдоэлемент:
  • Псевдокласс — :hover (одно :).
  • Псевдоэлемент — ::before (два ::).

3. Псевдоклассы позиции

Псевдокласс Что выбирает
:first-childПервый ребёнок
:last-childПоследний ребёнок
:nth-child(n)N-й ребёнок
:nth-child(odd)Нечётные (1, 3, 5...)
:nth-child(even)Чётные (2, 4, 6...)
:nth-child(3n)Каждый третий (3, 6, 9...)
:nth-child(2n+1)Нечётные (= odd)
:only-childЕдинственный ребёнок
:first-of-typeПервый элемент своего типа
:last-of-typeПоследний своего типа

:nth-child — по порядку

li:nth-child(odd) { background: #e3f2fd; }
li:nth-child(even) { background: #fff; }
li:nth-child(3) { color: red; }
li:first-child { border-top: 2px solid #1565c0; }
li:last-child { border-bottom: 2px solid #1565c0; }
Список с разными стилями:
  • Первый (odd)
  • Второй (even)
  • Третий (nth-child 3)
  • Четвёртый (even)
  • Пятый (odd, last-child)

Формулы nth-child

Формула Что выбирает
:nth-child(3)3-й
:nth-child(2n)Чётные (2, 4, 6)
:nth-child(2n+1)Нечётные (1, 3, 5)
:nth-child(3n)Каждый третий (3, 6, 9)
:nth-child(n+3)Все, начиная с 3-го
:nth-child(-n+3)Первые 3
Полезно: :nth-child(2n) = :nth-child(even). :nth-child(2n+1) = :nth-child(odd).

4. :not() — исключение

Выбирает всё, кроме указанного. 

li:not(.active) {
    color: #999;
}
Все li, кроме .active:
  • Активный (синий)
  • Неактивный (серый)
  • Активный
  • Неактивный

Комбинирование :not()

li:not(:first-child):not(:last-child) {
    /* только средние элементы */
}

input:not([type="submit"]) {
    /* все input, кроме submit */
}

5. :is() — группировка

Упрощает длинные селекторы. :is(a, b, c) = «a или b или c». 

/* Без :is */
h2 a, h3 a, h4 a {
    color: #1565c0;
}

/* С :is */
:is(h2, h3, h4) a {
    color: #1565c0;
}

Специфичность :is(): берётся самый специфичный из аргументов. :is(#id, .class) = #id.

6. :where() — как :is(), но без специфичности

:where() работает как :is(), но имеет специфичность 0. Легко переопределить. 

:where(h2, h3) { color: blue; }
h2 { color: red; }   /* ← победит, потому что специфичность h2 выше :where */

/* А с :is() — :is(h2, h3) победил бы */

7. :has() — «родитель по ребёнку»

Новинка 2023. Позволяет выбрать элемент, у которого есть указанный ребёнок. 

.card:has(img) {
    border-left: 4px solid #43a047;
}
Карточка с картинкой — зелёная рамка:
Карточка с картинкой
Карточка без картинки
Возможности :has():
  • .card:has(img) — карточка с картинкой.
  • form:has(:invalid) — форма с ошибкой.
  • h2:has(+ p) — заголовок, после которого идёт параграф.
Поддержка: Chrome 105+, Safari 15.4+, Firefox 121+.

9. Порядок псевдоклассов для ссылок

Правило LVHA (LoVe HAte) — порядок важен: 

a:link { }      /* L — ссылка */
a:visited { }   /* V — посещена */
a:hover { }     /* H — наведение */
a:active { }    /* A — нажатие */
Порядок: :link → :visited → :hover → :active. Если перепутать — часть не сработает (каскад).

10. Частые ошибки

Ошибка Почему плохо
Убирать :focus без замены Ломает клавиатурную навигацию
Путать :nth-child и :nth-of-type Первый считает всех детей, второй — только своего типа
Нарушать порядок LVHA Часть состояний ссылок не работает
:has() без fallback Старые браузеры не поддерживают
:nth-child(0) Ничего не выбирает (нумерация с 1)
Слишком сложные селекторы Сложно читать. Лучше — классы

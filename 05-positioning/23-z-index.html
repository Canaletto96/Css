CSS Урок 23. z-index

1. Что такое z-index

z-index — это «ось Z»: порядок наложения элементов друг на друга. Кто выше — тот «ближе к пользователю». 

.box {
    position: relative;
    z-index: 1;    /* ← чем больше, тем выше */
}
z-index работает только с position, отличным от static. У static (по умолчанию) — z-index не действует.

2. Базовый пример

Три блока с разным z-index:
z: 1
z: 2
z: 3

Зелёный (z: 3) — сверху. Красный (z: 1) — снизу.

3. z-index: auto и z-index: 0

Значение Что означает
auto (по умолчанию)Не создаёт контекст наложения. Элемент в порядке HTML.
0Создаёт контекст. Участвует в наложении.
1, 2, 100Больше — выше.
-1Ниже всех остальных.
Не пиши z-index: 9999, если не понимаешь. Скорее всего, проблема в stacking context (ниже). 9999 — «костыль», который не работает.

4. Главная проблема: stacking context

Stacking context (контекст наложения) — это «группа» элементов, внутри которой z-index работает изолированно.

Если родитель создал stacking context — его дети не могут «вылезти» выше всех элементов снаружи. Даже с z-index: 9999.

Что создаёт stacking context

Свойство Значение
positionrelative / absolute / fixed / sticky + z-index ≠ auto
opacity< 1
transform≠ none
filter≠ none
perspective≠ none
isolationisolate
will-changetransform, opacity и др.
flex / grid + z-indexу ребёнка — тоже создаёт

Пример проблемы

.parent {
    position: relative;
    z-index: 1;        /* ← создаёт stacking context */
}

.child {
    position: absolute;
    z-index: 9999;     /* ← не поможет вылезти выше .other */
}

.other {
    position: relative;
    z-index: 2;        /* ← выше .parent, а значит и всех его детей */
}
Проблема: child с z-index: 9999 внутри parent с z-index: 1
parent: z-index: 1
child: z-index: 9999
other: z-index: 2 — сверху, несмотря на z-index: 9999 у child
Почему: .parent создаёт stacking context. Всё, что внутри него (включая .child с 9999), находится «внутри» .parent на уровне 1. .other с z-index: 2 — выше всего .parent, включая всех его детей.

5. Как «вылезти» из stacking context

Нельзя «вылезти» из stacking context. Решения:

  1. Убрать stacking context у родителя — не задавать z-index, opacity < 1, transform и т.д.
  2. Переместить элемент в DOM выше — вне проблемного родителя.
  3. Использовать position: fixed — выносит элемент из контекста.
  4. Пересмотреть архитектуру — может, не нужен z-index?

6. Ось Z в порядке наложения

Порядок наложения (от нижнего к верхнему):

  1. Фон элемента.
  2. Отрицательный z-index (например, -1).
  3. Обычные блочные элементы.
  4. Поплавковые (float).
  5. Строчные (inline) элементы.
  6. z-index: 0 и auto позиционированные.
  7. Положительный z-index.

Подробнее — в спецификации CSS. Главное: положительный z-index — сверху.

7. Классический случай: модальное окно

.modal-overlay {
    position: fixed;
    inset: 0;
    background: rgba(0, 0, 0, 0.5);
    z-index: 1000;
}

.modal {
    position: fixed;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
    z-index: 1001;   /* ← выше overlay */
}
Правило: overlay — 1000, модальное окно — 1001. Не 9999. Главное — относительный порядок, а не абсолютные числа.

8. Шкала z-index (рекомендация)

Чтобы не путаться, задай «слои» в проекте:

/* CSS-переменные для слоёв */
:root {
    --z-dropdown: 100;
    --z-sticky: 200;
    --z-fixed: 300;
    --z-modal-backdrop: 400;
    --z-modal: 500;
    --z-popover: 600;
    --z-tooltip: 700;
}

.dropdown { z-index: var(--z-dropdown); }
.modal { z-index: var(--z-modal); }
.tooltip { z-index: var(--z-tooltip); }
Почему переменные: вместо 9999 — осмысленные значения. Легче поддерживать, понимать, менять.

9. Отрицательный z-index

z-index: -1 — элемент за фоном родителя (если родитель не создаёт stacking context). Полезно для декоративных фонов.

.parent {
    position: relative;
}

.background {
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
    z-index: -1;   /* ← за содержимым */
    background: linear-gradient(...);
}

10. Практика: карточка с бейджем и overlay

.card {
    position: relative;
    z-index: 1;
    transition: transform 0.2s, box-shadow 0.2s;
}

.card:hover {
    transform: translateY(-4px);
    box-shadow: 0 8px 24px rgba(0, 0, 0, 0.15);
    z-index: 2;   /* ← чтобы тень не перекрывалась соседями */
}

.badge {
    position: absolute;
    top: -8px;
    right: -8px;
    z-index: 3;   /* ← бейдж выше карточки */
}

11. Частые ошибки

Ошибка Почему плохо
z-index: 9999 для всего Не работает из-за stacking context. «Костыль»
z-index без position Не работает
opacity < 1 на родителе Создаёт stacking context — дети не «вылезут»
transform на родителе Тоже создаёт stacking context
Отрицательный z-index без position: relative родителя Элемент уйдёт за <body>
Забыть z-index для overlay Модальное окно будет «под» контентом

12. Что запомнить из урока

  • z-index — порядок наложения. Больше — выше.
  • Работает только с position, отличным от static.
  • Stacking context — «группа», внутри которой z-index изолирован.
  • Родитель с opacity, transform, z-index создаёт контекст.
  • Ребёнок не может «вылезти» из stacking context родителя.
  • 9999 не помогает — проблема в контексте, не в числе.
  • Шкала z-index: 100, 200, 300, 400, 500 — осмысленные слои.
  • Отрицательный z-index — за родителем (для фона).
  • CSS-переменные для z-index — удобно и читабельно.

CSS Урок 35. Позиционирование в Grid

1. Линии сетки (grid lines)

Сетка Grid — это линии, между которыми находятся ячейки. Линии нумеруются с 1. 

grid-template-columns: repeat(3, 1fr);
/* Линии:      1        2        3        4
   Колонки:      [ 1fr ][ 1fr ][ 1fr ] */
3 колонки = 4 линии:
1
2
3
Важно: линии нумеруются с 1, а не с 0. Для 3 колонок — 4 линии (1 — левый край, 4 — правый).

2. grid-column — позиция по колонкам

Задаёт, с какой линии по какую элемент занимает колонки. 

.item {
    grid-column: 1 / 3;   /* от линии 1 до линии 3 (2 колонки) */
}
grid-column: 1 / 3 — занимает 2 колонки:
1 / 3
3
4
5

3. grid-row — позиция по строкам

Задаёт, с какой линии по какую элемент занимает строки. 

.item {
    grid-row: 1 / 3;   /* от линии 1 до линии 3 (2 строки) */
}
grid-row: 1 / 3 — занимает 2 строки:
1 / 3
2
3
4

4. span — «занять N ячеек»

Вместо линий можно указать span — «растянуть на N ячеек». 

.item {
    grid-column: span 2;   /* занять 2 колонки */
}

.item {
    grid-row: span 2;      /* занять 2 строки */
}
grid-column: span 2:
span 2
2
3
4

grid-column: 1 / 3 vs grid-column: span 2

Запись Что означает
grid-column: 1 / 3 От линии 1 до линии 3 (позиция + размер)
grid-column: span 2 Занять 2 колонки (только размер)
Разница: 1 / 3 — фиксированная позиция. span 2 — автоматическая позиция, но занимает 2 ячейки.

5. grid-column: 1 / -1 — «на всю ширину»

-1 — это последняя линия сетки. Запись 1 / -1 означает «от первой до последней линии». 

.header {
    grid-column: 1 / -1;   /* на всю ширину */
}
grid-column: 1 / -1 — на всю ширину:
Header (1 / -1)
1
2
3
Footer (1 / -1)
Правило: 1 / -1 — «на всю ширину». Работает при любом количестве колонок. Не нужно знать, сколько их.

6. grid-area — сокращение

grid-area — сокращение для grid-row-start, grid-column-start, grid-row-end, grid-column-end. 

/* Полная запись */
.item {
    grid-row-start: 1;
    grid-column-start: 1;
    grid-row-end: 3;
    grid-column-end: 4;
}

/* Через grid-area */
.item {
    grid-area: 1 / 1 / 3 / 4;   /* row-start / col-start / row-end / col-end */
}
grid-area: 1 / 1 / 3 / 3 — занимает 2×2:
2×2
3
4
Порядок в grid-area: row-start / column-start / row-end / column-end. Сложно запомнить — но полезно.

7. Практика: макет страницы

.layout {
    display: grid;
    grid-template-columns: 200px 1fr;
    grid-template-rows: auto 1fr auto;
    gap: 16px;
    min-height: 100vh;
}

.header { grid-column: 1 / -1; }
.sidebar { grid-column: 1; grid-row: 2; }
.main { grid-column: 2; grid-row: 2; }
.footer { grid-column: 1 / -1; }
Макет: header + sidebar + main + footer:
Header (1 / -1)
Sidebar
Main
Footer (1 / -1)

8. Практика: сетка с «выделенной» карточкой

.cards {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 16px;
}

.card.featured {
    grid-column: span 2;   /* ← занимает 2 колонки */
    grid-row: span 2;      /* ← занимает 2 строки */
}
Featured карточка занимает 2×2:
Featured (2×2)
2
3
4
5

9. Практика: «сломанная» сетка

.grid {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 8px;
}

.item:nth-child(1) { grid-column: 1 / 3; }
.item:nth-child(2) { grid-column: 3 / 5; }
.item:nth-child(3) { grid-column: 1 / 2; }
.item:nth-child(4) { grid-column: 2 / 5; }
Разные размеры:
1 / 3
3 / 5
1 / 2
2 / 5

10. Линии с конца (-1, -2)

Линии можно считать с конца: -1 — последняя, -2 — предпоследняя. 

.item {
    grid-column: -3 / -1;   /* 2 последние колонки */
}
grid-column: -3 / -1 — 2 последние колонки:
1
2
-3 / -1
Где полезно: когда не знаешь точное число колонок, но хочешь «прижать к правому краю». Например, -2 / -1 — последняя колонка.

11. Частые ошибки

Ошибка Почему плохо
Считать линии с 0 Линии нумеруются с 1
grid-column: 1 / 3 для «1 колонки» Это 2 колонки (от 1 до 3)
1 / -1 для «первой колонки» Это «на всю ширину». Для первой — 1 / 2
Забыть gap Элементы слипаются
Забыть grid-auto-rows при grid-row: span 2 Строки могут «схлопнуться»
Путать grid-column: 1 / 3 и grid-column: 1 / 4 1/3 — 2 колонки, 1/4 — 3 колонки

12. Что запомнить из урока

  • Линии сетки нумеруются с 1. Для 3 колонок — 4 линии.
  • grid-column: start / end — позиция по колонкам.
  • grid-row: start / end — позиция по строкам.
  • grid-column: 1 / 3 — занимает 2 колонки (от 1 до 3).
  • grid-column: span 2 — занять 2 колонки.
  • 1 / -1 — «на всю ширину». Работает при любом числе колонок.
  • grid-area: row-start / col-start / row-end / col-end — сокращение.
  • Отрицательные линии — с конца: -1 — последняя.
  • grid-column: span 2 vs 1 / 3 — span только размер, без позиции.

CSS Урок 6. Наследование

1. Что такое наследование

Наследование (inheritance) — это механизм, при котором некоторые CSS-свойства автоматически передаются от родителя к дочерним элементам.

Пример:

body {
    color: #333;
    font-family: system-ui, sans-serif;
}

Ты задал цвет и шрифт только для <body>. Но все элементы внутри (<p>, <h1>, <span>...) получат тот же цвет и шрифт — по наследству.

Аналогия. Наследование — как «семейные черты»: дети наследуют цвет глаз от родителей, но не их одежду. Так и в CSS: цвет текста и шрифт наследуются, а border и margin — нет.

2. Какие свойства наследуются

Наследуются в основном свойства, связанные с текстом и шрифтом:

Свойство Что задаёт
colorЦвет текста
font-familyШрифт
font-sizeРазмер шрифта
font-weightЖирность
font-styleКурсив
line-heightМежстрочный интервал
letter-spacingРасстояние между буквами
text-alignВыравнивание текста
text-transformРегистр (CAPS / lowercase)
text-indentОтступ первой строки
visibilityВидимость
cursorКурсор
list-styleСтиль списка

НЕ наследуются свойства, связанные с блоком и позиционированием:

Свойство Что задаёт
marginВнешние отступы
paddingВнутренние отступы
borderРамка
backgroundФон
width, heightРазмеры
displayТип отображения
positionПозиционирование
top, left и др.Координаты
floatОбтекание
box-shadowТень
opacityПрозрачность
Почему так: если бы border наследовался, у каждого <span> внутри <p> появилась бы рамка. Это выглядело бы странно. А цвет текста — логично наследовать: «весь текст в блоке одного цвета».

4. Как это работает в DevTools

Открой F12 → Elements → выбери элемент. В панели Styles наследованные свойства показываются серым с пометкой Inherited from ....

Это лучший способ увидеть, что унаследовано, а что задано явно.

5. Управление наследованием

Есть 4 ключевых слова для управления наследованием:

Ключевое слово Что делает
inherit Принудительно наследовать от родителя
initial Установить значение по умолчанию (из спецификации)
unset Сбросить: inherit если свойство наследуемое, иначе initial
revert Откатить к стилю браузера

inherit — принудительное наследование

Иногда свойство не наследуется, но ты хочешь, чтобы наследовалось. Например, border: 

.parent {
    border: 2px solid red;
}

.child {
    border: inherit;   /* ← принудительно наследует рамку родителя */
}
Пример inherit:

Родитель с рамкой.

Этот блок получил рамку по наследству (через border: inherit).

initial — значение по умолчанию

Сбрасывает свойство к значению из спецификации CSS, независимо от родителя. 

.parent {
    color: red;
}

.child {
    color: initial;   /* ← чёрный (значение по умолчанию для color) */
}
Пример initial:

Этот параграф — синий (наследованный).

А этот — чёрный (сброшен через initial).

unset — умный сброс

Работает как inherit, если свойство наследуемое, и как initial, если нет. 

.child {
    color: unset;       /* → inherit (наследуемое) */
    border: unset;      /* → initial (не наследуемое) */
}

revert — вернуть стиль браузера

Откатывает к стилю браузера по умолчанию (user agent). Полезно, если ты «сбросил» стили через reset, но хочешь вернуть стандартное поведение: 

/* Reset сломал внешний вид кнопки */
button {
    all: unset;
}

/* Но эта кнопка должна выглядеть как обычная */
button.normal {
    all: revert;   /* ← вернёт стиль браузера */
}

6. Универсальное свойство all

all применяет значение ко всем свойствам сразу: 

.child {
    all: inherit;    /* наследует ВСЁ от родителя */
    all: initial;    /* сбрасывает ВСЁ к умолчанию */
    all: unset;      /* сбрасывает ВСЁ разумно */
    all: revert;     /* откатывает ВСЁ к стилям браузера */
}
Осторожно с all: он сбрасывает всё, включая display, position. Может сломать layout. Используй осознанно.

7. Наследование и font-size

font-size — наследуемое свойство. Это важно для единиц em и rem (урок 7): 

html {
    font-size: 16px;
}

body {
    /* наследует 16px от html */
}

p {
    /* наследует 16px от body */
}

.small {
    font-size: 0.875em;   /* 14px (16 × 0.875) */
}

.tiny {
    font-size: 0.75em;    /* 12px (16 × 0.75) */
}
Почему это важно: если родитель изменил font-size, дети получат новое значение. Это основа для адаптивной типографики.

8. Наследование и rem vs em

Единица Относительно Наследуется?
px Абсолютно Нет
em Родительского font-size Да (зависит от родителя)
rem <html> Нет (всегда от корня)
% Родителя Да (для шрифта)

Подробно — в уроке 7.

9. Частые ошибки

Ошибка Почему плохо
Думать, что border наследуется Нет. Каждый блок имеет свою рамку
Думать, что margin наследуется Нет. У каждого элемента свои отступы
Использовать all: unset на всём Сломает display, position
Путать inherit и initial inherit — от родителя, initial — значение по умолчанию
Забывать, что font-size наследуется Влияет на em у детей

10. Что запомнить из урока

  • Наследование — передача свойств от родителя к детям.
  • Наследуются: color, font-*, line-height, text-align, cursor, visibility, list-style.
  • НЕ наследуются: margin, padding, border, background, width, height, display, position.
  • inherit — принудительно наследовать.
  • initial — значение по умолчанию.
  • unset — inherit или initial в зависимости от свойства.
  • revert — откатить к стилю браузера.
  • all — применить ко всем свойствам сразу (осторожно!).
  • font-size наследуется — влияет на em.
  • DevTools показывает наследованные стили серым.

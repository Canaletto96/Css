CSS Урок 28. Основная ось

1. Три свойства для управления осью

Свойство Что делает
flex-direction Направление главной оси (ряд / колонка)
flex-wrap Переносить ли элементы на новую строку
flex-flow Сокращение: flex-direction + flex-wrap

2. flex-direction — направление

Определяет, куда выстраиваются элементы.

Значение Что означает Главная ось
row (по умолчанию)Слева направо→
row-reverseСправа налево←
columnСверху вниз↓
column-reverseСнизу вверх↑
 
.container {
    display: flex;
    flex-direction: row;       /* по умолчанию */
    /* flex-direction: row-reverse; */
    /* flex-direction: column; */
    /* flex-direction: column-reverse; */
}

3

row-reverse

flex-direction: row-reverse — справа налево:

Важно: row-reverse меняет визуальный порядок, но не порядок в HTML. Screen reader читает в исходном порядке. Для доступности не меняй порядок через reverse — используй order.

column

flex-direction: column — сверху вниз:
1
2

column-reverse

Как меняются оси

flex-direction justify-content align-items
rowгоризонтальвертикаль

Частая ошибка: думать, что justify-content — всегда горизонталь. Нет! Он по главной оси. При column — по вертикали.

3. flex-wrap — перенос

По умолчанию элементы сжимаются, чтобы влезть в одну строку. flex-wrap позволяет переносить их на новую.

Значение Что делает
nowrap (по умолчанию)Все в одну строку, сжимаются
wrapПереносить на новую строку
wrap-reverseПереносить, но в обратном порядке

nowrap (по умолчанию)

nowrap — всё в одну строку, сжимаются:
Один
Два
Три
Четыре
Пять
Шесть

Элементы сжались, чтобы влезть в одну строку (или вылезли за край).

wrap

wrap — переносятся на новую строку:
Один
Два
Три
Четыре
Пять
Шесть

Элементы переносятся, сохраняя размеры.

wrap-reverse

wrap-reverse — переносятся в обратном порядке:
Один
Два
Три
Четыре
Пять
Шесть

Последняя строка — сверху, первая — снизу.

flex-wrap: wrap — почти всегда, когда элементов много. Без него они сожмутся или вылезут.

4. flex-flow — сокращение

Объединяет flex-direction и flex-wrap в одно свойство: 

.container {
    flex-flow: row wrap;          /* row + wrap */
    /* или */
    flex-flow: column nowrap;
    /* или */
    flex-flow: row-reverse wrap-reverse;
}
Порядок: сначала flex-direction, потом flex-wrap. Но можно и в любом порядке — браузер разберётся.

5. Практика: карточки с переносом

.cards {

8. gap и flex-wrap

gap работает и по главной, и по поперечной оси. При переносе — и между строками. 

.container {
    display: flex;
    flex-wrap: wrap;
    gap: 16px;              /* и между элементами, и между строками */
    /* или */
    column-gap: 8px;        /* только между колонками */
    row-gap: 16px;          /* только между строками */
}
Совет: используй gap, а не margin у детей. gap не даёт «лишних» отступов по краям.

9. Частые ошибки

Ошибка Почему плохо
Забыть flex-wrap: wrap для многих элементов Элементы сожмутся или вылезут
flex-direction: column + align-items: stretch + height Дети растянутся на всю высоту — может быть некрасиво
Использовать reverse для смены порядка Ломает доступность. Лучше order
Забыть gap Элементы «слипаются»
Использовать margin вместо gap Лишние отступы по краям

10. Что запомнить из урока

  • flex-direction — направление главной оси: row, row-reverse, column, column-reverse.
  • row — по умолчанию. column — вертикально.
  • flex-wrap — перенос: nowrap (по умолчанию), wrap, wrap-reverse.
  • flex-wrap: wrap — почти всегда для многих элементов.
  • flex-flow — сокращение: row wrap.
  • justify-content — по главной оси. При column — по вертикали.
  • align-items — по поперечной. При column — по горизонтали.
  • gap — работает между строками и колонками.
  • reverse — меняет визуальный порядок, но не для доступности.

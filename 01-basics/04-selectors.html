CSS Урок 4. Селекторы

1. Что такое селектор

Селектор — это «кого стилизуем». Он говорит браузеру, к каким элементам применить правило. 

селектор {
    свойство: значение;
}

Пример: h1 { color: blue; } — «все <h1> сделай синими».

2. Обзор селекторов

Селектор Пример Кого выбирает
Тег p Все <p>
Класс .card Все элементы с class="card"
id #header Один элемент с id="header"
Универсальный * Все элементы
Группировка h1, h2, h3 Все h1, h2, h3
Потомок div p Все p внутри div (на любом уровне)
Ребёнок div > p Только p, которые прямые дети div
Сосед h2 + p Первый p сразу после h2
Все соседи h2 ~ p Все p после h2 (на том же уровне)
Атрибут input[type="text"] Все input с type="text"

3. Селектор по тегу

Выбирает все элементы с этим тегом.

p {
    color: #333;
}

h1 {
    font-size: 32px;
}
Все <p> в этом демо — синие:

Когда: базовые стили для всех элементов одного типа.

4. Селектор по классу (.имя)

Выбирает все элементы с этим классом. Класс может быть у многих элементов.

.card {
    border: 1px solid #ddd;
    padding: 16px;
}
<div class="card">Карточка 1</div>
<div class="card">Карточка 2</div>
Все .demo-box — с рамкой:
Карточка 1
Карточка 2
Карточка 3

Когда: основный способ стилизации. Один класс — много элементов.

Несколько классов у одного элемента

<div class="card highlight">...</div>
.card + .highlight:
Обычная карточка
Выделенная карточка

5. Селектор по id (#имя)

Выбирает один элемент с этим id. id уникален на странице.

#header {
    background: #333;
    color: white;
}
<header id="header">...</header>
Элемент с id="demo-id":

Обычный параграф.

Параграф с id="demo-id" — зелёный фон.

Ещё один обычный параграф.

Не используй id для стилизации!
  • Высокая специфичность — сложно переопределить.
  • id уникален — нельзя применить к группе.
  • Лучше — класс.
id — для якорей (#section), JS (getElementById), label.

6. Универсальный селектор *

Выбирает все элементы.

* {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}

Когда: сброс стилей (reset), box-sizing.

Не используй * для сложных стилей — это применяется ко всему, включая <html>, <body>, <head>.

7. Группировка селекторов (через запятую)

Одно правило — для нескольких селекторов:

h1, h2, h3, h4 {
    font-family: system-ui, sans-serif;
    color: #333;
}
Все заголовки — одного цвета:

Заголовок h3

Заголовок h4

Заголовок h5

Это то же самое, что:

h1 { font-family: system-ui, sans-serif; color: #333; }
h2 { font-family: system-ui, sans-serif; color: #333; }
h3 { font-family: system-ui, sans-serif; color: #333; }
h4 { font-family: system-ui, sans-serif; color: #333; }

Но короче и удобнее.

8. Селектор потомка (через пробел)

Выбирает элементы внутри другого, на любом уровне вложенности.

div p {
    color: green;
}

«Все <p>, которые находятся внутри <div> — на любом уровне».

<div>
    <p>Прямой ребёнок</p>
    <section>
        <p>Внук — тоже подходит!</p>
    </section>
</div>
Все p внутри .demo — зелёные:

Прямой ребёнок

Внук — тоже зелёный

9. Селектор ребёнка (через >)

Выбирает только прямых детей (первый уровень вложенности).

div > p {
    color: red;
}

«Только <p>, которые являются прямыми детьми <div>».

Только прямые дети — красные:

Прямой ребёнок — красный

Внук — обычный

Потомок vs ребёнок

Селектор Что выбирает
div p Все p внутри div (дети, внуки, правнуки...)
div > p Только прямые дети (первый уровень)

10. Селектор соседа (через +)

Выбирает первый элемент, который идёт сразу после указанного.

h2 + p {
    color: blue;
}

«Первый <p>, который идёт сразу после <h2> на том же уровне».

Первый p после h2 — синий:

Заголовок

Первый параграф — синий (сосед h3)

Второй параграф — обычный

Третий параграф — обычный

11. Селектор всех соседей (через ~)

Выбирает все элементы, которые идут после указанного (на том же уровне).

h2 ~ p {
    color: purple;
}
Все p после h3 — фиолетовые:

Заголовок

Первый — фиолетовый

Второй — фиолетовый

Третий — фиолетовый

Сосед vs все соседи

Селектор Что выбирает
h2 + p Только первый p сразу после h2
h2 ~ p Все p после h2 на том же уровне

12. Селектор по атрибуту ([атрибут])

Выбирает элементы с определённым атрибутом или значением.

/* Все элементы с атрибутом title */
[title] {
    cursor: help;
}

/* Все input с type="text" */
input[type="text"] {
    border: 1px solid #ccc;
}

/* Ссылки с href, начинающимся с "https" */
a[href^="https"] {
    color: green;
}

/* Ссылки с href, заканчивающимся на ".pdf" */
a[href$=".pdf"] {
    color: red;
}

/* Ссылки с href, содержащим "example" */
a[href*="example"] {
    color: orange;
}
Ссылки с разными href:

https://example.com — зелёная

file.pdf — красная

/page — оранжевая

Виды атрибутных селекторов

Синтаксис Что выбирает
[attr] Есть атрибут
[attr="value"] Точное совпадение
[attr^="value"] Начинается с
[attr$="value"] Заканчивается на
[attr*="value"] Содержит
[attr~="value"] Одно из слов в списке через пробел
[attr|="value"] Точно или начинается с value-

13. Комбинирование селекторов

Селекторы можно комбинировать для точного выбора.

/* Все p внутри .card */
.card p {
    color: #666;
}

/* Прямые дети .card */
.card > * {
    margin-bottom: 8px;
}

/* Класс .card И .highlight */
.card.highlight {
    background: yellow;
}

/* Все ссылки внутри nav, у которых есть href с https */
nav a[href^="https"] {
    color: green;
}
.card.highlight — оба класса:
.card + .highlight
Только .card (без highlight)
.card.highlight (без пробела) — элемент, у которого оба класса.
.card .highlight (с пробелом) — элемент с .highlight внутри элемента с .card.

14. Специфичность (кратко)

Если два правила конфликтуют, побеждает более специфичный:

Селектор Специфичность
* 0
p 1 (тег)
.card 10 (класс)
#header 100 (id)
p.card 11 (тег + класс)
#header .card 110 (id + класс)

Подробно — в уроке 5.

15. Частые ошибки

Ошибка Почему плохо
Использовать id для стилизации Высокая специфичность, нельзя переопределить
.card .highlight вместо .card.highlight Первый — потомок, второй — оба класса
div p для всех p Избыточно — достаточно p
Пробел после . в классе . card — не селектор
Забыть > для ребёнка Выберет всех потомков, а не только детей
h2 + p для всех p Выберет только первый после h2. Для всех — ~
Слишком глубокая вложенность div > section > ul > li > a Хрупко, ломается при изменении HTML

16. Что запомнить из урока

  • Селектор — «кого стилизуем».
  • Тег: p — все <p>.
  • Класс: .card — все с class="card".
  • id: #header — один с id="header". Не для стилей!
  • Универсальный: * — все.
  • Группировка: h1, h2 — через запятую.
  • Потомок: div p — все p внутри div.
  • Ребёнок: div > p — только прямые дети.
  • Сосед: h2 + p — первый p после h2.
  • Все соседи: h2 ~ p — все p после h2.
  • Атрибут: [type="text"], [href^="https"].
  • .card.highlight — оба класса (без пробела).
  • .card .highlight — потомок (с пробелом).
